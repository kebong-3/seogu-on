# v0.2 검증 기록

## 수행한 검증

JavaScript 문법검사, 정적 빌드, Node 단위시험 **128개 통과**. 실제 행정동 18개 도형 및 내부 대표점 검증, Polygon 구멍·공유 경계점·범위 필터, CSV 파싱, 날짜·0/결측, 출처·좌표·ID, 다중 페이지·부분수집·키 비노출·호스트 제한, 갱신 실패 시 기존본 보존, KMA 격자·한국시간·기준시각 대조, 지오코딩 후보 상태, 비동기 지도 초기화 전 2D/3D 카메라 상태 보존을 검사했습니다. 테스트 입력자료는 시험용으로 표시하고 공개 자료 파일에 넣지 않았습니다.

실제 공개자료 수신은 GitHub Actions에서 수행했습니다. 공개 표준 다운로드의 전국 제공행을 순회하고 서구 후보를 선택한 뒤 18개동 도형으로 대조했습니다. `DATA_QUALITY_REPORT.json`에 제외 항목을 기록했습니다. 학교 대표위치의 원 좌표는 변경하지 않았습니다.

## 기존 Production 사이트에서 확인한 값

version0.1.0 / MapLibre, zoom14.5 / pitch57 / 현재 읽은 building source 도형315개 / 입체 레이어 visible / JavaScript pageerror0. 이는 당시 화면 범위의 도형 수이지 서구 전체 건물 수가 아닙니다. VWorld 설정 bool은 false였습니다. OSM 입체 건물이 이미 있으므로 ‘기존 지도에 3D 기능이 전혀 없었다’고 판단하지 않았습니다.

## 실행한 오프라인 화면·자료 연결시험

Chromium에서 **18개 컴포넌트 통합검사 통과**. 실제 앱 코드와 325개 공개자료 JSON으로 18동 선택, 지도 어댑터와 표의 건수 일치, 5개 자료층 개별 해제, 주소 검수 32행, CSV 추가, 행정동 통계·사업기간, 390px 모바일·오버플로·JS 오류를 검사했습니다. `COMPONENT_RESULTS.json`은 이 실행 결과입니다.

**지도 어댑터와 네트워크는 명시적인 시험용 대체물입니다.** 외부 MapLibre/WebGL 타일, 실제 브이월드 인증 또는 개선판의 실제 운영 배포를 검증한 결과가 아닙니다. `tests/component-browser.py`는 Python Playwright가 필요하며 외부 지도 없이 `page.set_content`로 실행합니다. 브라우저 보안·조직 정책을 해제하지 않습니다.

## 외부 지도까지 포함하는 브라우저 통합시험 — 실행 대기

`tests/browser-v02.py`는 외부 지도 수신 가능한 환경에서 실행합니다. 실제 OpenFreeMap 도형·18개동·325개 공개자료, 선택과 표의 집계 일치, 가까이 보기·건물 클릭·테마·자료층 전환·모바일·CSV를 시험합니다. 상류 API 실패는 명시적인 모의 응답으로 시험하며 인증된 API 성공으로 해석하지 않습니다. 수행 결과는 별도 `docs/BROWSER_RESULTS.json` 또는 Actions 결과 아티팩트의 `results.json`에 기록합니다. 파일이 없으면 수행 완료로 해석하지 마세요.

## 아직 실제 계정으로 검증하지 않은 범위

사용자 키를 통한 브이월드 도메인 인증·3D 모델 수신·주소→좌표 실응답, 공공데이터포털 인증된 시설 API 4종과 KMA 실수신, Vercel Production 환경변수 수정·개선판 운영 배포는 별도입니다. 코드와 모의 응답 시험은 실제 인증·서구 전수·최신성 검증을 대신하지 않습니다.

## 운영 한계

실제 침수·일조·교통 예측, 실시간 재난 관제, 주민·민원 시스템, 최신 동별 인구·예산 자동연계, 공동 DB·권한·정기 자동갱신은 이번 검증 대상이 아닙니다. 서버 인스턴스 캐시·요청 제한은 전역 영구 저장이나 전역 보안 통제가 아닙니다. 기관 공식 서비스 전환 전 자료·보안·접근권한 검수가 필요합니다.
