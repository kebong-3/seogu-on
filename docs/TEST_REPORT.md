## 단위검사 내용

거리의 대칭성과 자기거리0, 반경 폴리곤 폐합, 달력 날짜·월 유효성, 기간 중첩, 월별 결측/0 분리, 동일대상 증감, 혼합지표 합산 중단, 합성자료 재현성, 시설 필터, 대표점 기반 사업 근접, HTML/CSV escape, GeoJSON 스키마·좌표 범위·출처·중복·최대 개수·월별 숫자, URL 호스트 제한·리디렉션·응답시간/크기·API 설정누락·오류정규화·비밀키 미노출 등을 검사했습니다.

외부 fetch는 단위검사에서 모의 응답으로 대체했습니다. 지도 어댑터 2개 검사는 MapLibre 5.6.1의 공개 인터페이스에 맞춘 모의 객체를 사용했습니다. 해당 버전에는 없는 supported() 호출을 제거하고 Map 생성자의 WebGL 초기화 오류를 처리하도록 수정했습니다. 실제 지도 API가 같은 응답을 준다는 것을 검증한 것이 아닙니다.

## 브라우저 검사 내용

초기 시설48개/합성값3732, 시연 경고, 종류별 필터48→36, 이름검색, 월 선택과 패널 동기화, 2D/3D 상태, 테마전환, 지도 클릭과 반경설정, 가상시설 배치/삭제, A/B 조건 저장과 JSON, 대표점 사업설명, 시설표/선택, CSV/HTML 검토표의 출처와 시연 경고, 키 미설정 안내, Point GeoJSON 가져오기, 결측/0, 이름의 HTML 무해화, 390×844 모바일 가로 넘침 여부/분석패널/지도설정/분류변경, 처리되지 않은 JavaScript 오류 없음 등을 검사했습니다.

세부 결과는 `browser-test-results.json`에 저장했습니다. 브라우저의 `set_content`로 단일 HTML을 넣어 가상 도시 렌더러를 검사했으며, HTTP 탐색·외부 타일·VWorld SDK는 검증 범위가 아닙니다. 스크린샷은 1600×1000 밝은/어두운 모드 및390×844 모바일 디자인 미리보기입니다.

## 재현 명령

```bash
npm run check
npm test
npm run build
node scripts/make-preview.mjs
# 선택: Python Playwright 및 시스템 Chromium이 설치된 환경
python tests/browser-smoke.py
```

미리보기 생성 명령은 저장소 폴더의 한 단계 위에 `seo-on-design-preview.html`을 만듭니다. 선택적 브라우저 검사는 그 파일을 읽고 같은 상위폴더에 스크린샷을 만듭니다. `CHROMIUM_PATH` 환경변수로 브라우저 실행파일을 바꿀 수 있습니다. 이 Python 검사는 Vercel 빌드의 필수가 아닙니다.
