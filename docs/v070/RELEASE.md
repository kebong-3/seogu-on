# 서구:온 v0.7.0 변경·검증 기록

## 변경 범위

- 18개 동 카드: 2열, 큰 동 이름·공식 BI, 선택 상태 대비, 좁은 화면에서도 독립 스크롤.
- 선택 지역 카드: 이름과 BI 확대, 긴 이름 줄바꿈.
- 상단 관측정보: 선택 구역 대표위치의 기상청 격자 기온·1시간 강수, 실제 에어코리아 측정소의 PM10과 각 관측시각. API 실패 시 같은 구역의 이전 정상값은 원래 시각과 ‘갱신 실패’를 유지합니다. 다른 동의 값을 옮겨 표시하지 않습니다.
- 재난 관련 지도층: 수신된 관련 도형 종류 수만 표시. 경보·위험등급은 계산하지 않습니다.
- 동 자동 둘러보기: 약 4.2초마다 다음 동으로 이동, 18개 동 종료 후 멈춤. 직접 선택·Esc·숨김 탭에서 중지.
- 기존 3D 그림자 재생: 5분 모의시간 간격을 유지. 2D 그늘 면은 확보된 건물의 기하학적 근사입니다.

## 확인 사항

- `npm run check`, `npm test`(384개), `npm run build`, `node scripts/audit-release.mjs` 통과.
- 이 실행환경에 브라우저 바이너리가 없어 변경 후 화면 캡처는 완료하지 못했습니다. 기존 v0.6.1 화면 검증 이미지를 v0.7.0의 검증으로 사용하지 않습니다.
- 실제 브이월드 원본 건물·그림자 GPU 렌더링과 외부 기상·대기 API 인증·최신 관측값은 운영 배포에서 별도 확인해야 합니다.
- OSM 일부 도로망은 보행 가능성과 그늘을 검증한 길찾기 자료가 아닙니다. 자동 폭염 보행 회피 경로를 제공하거나 안전한 길로 판정하지 않습니다. 현재 상황판과 그늘 도형은 경로 검토 참고자료입니다.
