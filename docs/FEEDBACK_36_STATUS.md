# 36개 개선 의견 반영 상태 — v0.16.0

검토일: 2026-10-28. 사용자가 전달한 36개 의견의 번호를 유지했다. 이 표는 로컬 소스와 자동검사의 범위를 대조한 기록이다. 배포 성공은 운영 사이트의 버전 및 배포 검증 기록으로 확인하며, 실제 이용자·현장 검증은 별도로 확인한다. 기존 모의평가 점수와 이번 기능 추가를 합산하거나 특정 심사 점수를 보장하지 않는다.

상태는 다음 의미로 사용한다.

- **구현·자동검사**: 해당 범위의 코드가 있고 자동검사 근거가 있다. 실제 기관 도입·현장 안전·업무효과를 확인했다는 뜻은 아니다.
- **일부 구현**: 도구나 데이터의 일부가 있으나 의견 전체를 충족하지 않는다. 남은 범위를 각 행에 적었다.
- **실측/기관자료/운영설정 필요**: 원문 자료, 실제 참가자, 현장 관측 또는 기관 운영체계 없이는 완료를 판정할 수 없다. 이를 가상 결과나 임의 좌표로 대신하지 않았다.

최종 로컬 통합검사에서 **1,018개 통과·실패 0개**, 빌드 검사 27개·로컬 HTTP 검사 65개가 통과했다. Windows에서 심볼릭 링크 이름의 시험은 실행 대상에서 제외했으며 Linux CI에서는 전체 시험을 실행한다. 제공기관 실제 경로 628m에서 지시 10개·연결 단절 0개도 확인했다. 이는 단말 GPS 실측이나 36개 의견의 완료율이 아니다.

## 후속 실증에서 남길 증거

실제 담당자의 동일과제 원본 기록, 익명 산출물·채점표, 기기와 권한·네트워크 조건, 제공기관 호출 결과와 배포 버전, 공식 시설·귀갓길·노면 원자료의 기준일 및 검수 기록을 별도로 보관한다. 좋은 결과뿐 아니라 실패·미확인·중단과 재수행 조건을 남긴다. 운영 키·개인 위치 이력·민원인 정보는 이 공개 문서나 평가 파일에 넣지 않는다.
