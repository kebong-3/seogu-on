# 육아·돌봄 생활지도 자료

2026-10-24(한국시간) 수집·확인. 어린이집의 영유아 보육, 유치원 교육, 초등 방과후 돌봄은 이용대상과 제도가 다르므로 하나의 공급 수로 합치지 않는다.

## 이번에 실제 반영한 자료

**한국사회보장정보원 어린이집정보공개포털의 ‘어린이집 기본정보’ 공개 SHEET**를 수시조회하여 수록했다. 원문 1,639행을 전부 수신한 뒤 서구/순천시 주소와 각 지역 행정경계를 함께 확인했다. API 키를 사용하지 않은 공개 조회 스냅샷이며, 운영 API 상시연결 또는 실시간 갱신 성공을 뜻하지 않는다.

| 지역 | 원문 해당 지역 | 지도 수록 | 제외 |
|---|---:|---:|---|
| 서구 | 134행 | 122개 | 공시 휴지 8개, 지역 경계 밖 좌표 3개, 동일 주소의 공식 공개자료와 좌표 불일치 1개 |
| 순천시 | 159행 | 151개 | 공시 휴지 4개, 지역 경계 밖 좌표 4개 |

수록 파일은 `public/data/decision/seogu/childcare.geojson`, `public/data/decision/suncheon/childcare.geojson`이다. 각 지역의 `childcare-source.json`에 수신 건수·요청변수·원문 해시·제외사유를 남겼다.

- 제공기관: 한국사회보장정보원
- 공식 공개 목록: <https://info.childcare.go.kr/info_html5/oais/openapi/OpenApiSlL.jsp>
- 공식 자료 설명·재이용 조건: <https://www.data.go.kr/data/15013108/standard.do>
- 이용조건: 공공누리 제1유형(출처표시). 제공기관과 자료 출처를 함께 표시한다.
- 수집시각: `2026-10-23T17:32:48.964Z` = 한국시간 2026-10-24 02:32:48
- 원문 자료 기준일: **수시조회 화면에서 별도 제공되지 않음**. `sourceDate: null`을 유지하고 수집일을 원자료 기준일로 바꾸지 않았다.
- 포함 속성: 어린이집명, 주소, 시설유형(국공립/민간/가정/직장 등), 공시 운영현황, 공시 정원·현원, 기관 전화, 원문 좌표, 출처, 수집시각.
- 미포함 속성: 개인 이름, 아동별 정보, 입소 대기자, 입소 가능 자리, 시설 안전평가.

공시 ‘정상/재개’이며 해당 지역 경계 안의 원문 좌표가 있는 행만 지도에 넣었다. 원문이 서울 대표좌표이거나 다른 지역을 가리키는 행은 주소로 좌표를 추정하지 않고 제외했다. 같은 공동주택 대표좌표에 여러 시설이 있는 경우 임의로 위치를 흩뜨리지 않고 좌표 중복 설명을 남겼다. 공개 좌표와 실제 출입구가 같다고 보장하지 않는다.

**광주서구청어린이집의 원문 좌표 1건은 추가 검토 후 공간 수록·계산에서 제외했다.** 공개 SHEET 99행의 주소는 ‘서구 경열로 33 서구청’인데 좌표는 `[126.86332875147805, 35.147776108049314]`이다. 같은 주소의 [공식 개방공간 자료](https://www.data.go.kr/data/15013117/standard.do) ‘서구청 들불홀’ 대표좌표 `[126.8900126833, 35.15202903]`와 2,472m 차이가 확인됐다. 원문 HTML 해시가 수신기록과 일치하고, 독립 파서로도 같은 값이 확인되어 수집기의 열·행 연결 오류는 아니다. 비교한 공공공간 좌표를 어린이집 좌표로 대체하지 않았으며, `childcare-source.json`의 제외 기록에 시설 ID·원래 좌표·원문 행·근거 출처·비교 거리를 보존했다. 수집기는 해당 시설 ID와 문제 좌표가 모두 같은 경우에만 제외하므로 향후 원문 좌표가 변경되면 일반 검증을 다시 적용한다. 이 조치는 전체 시설 좌표의 현장 검증을 뜻하지 않는다.

**정원에서 현원을 뺀 값은 현재 입소 가능한 자리 수가 아니다.** 공시 상태·정현원과 현재 운영시간·이용자격·연령별 반 편성·입소 가능 여부는 구분한다. 직장어린이집을 누구나 이용 가능한 시설로 표시하지 않는다.

## 어떤 업무에 쓰는가

1. 육아 관련 민원을 받았을 때 실제 공시 시설의 명칭·유형·주소·연락처를 빠르게 확인한다.
2. 현장점검이나 찾아가는 부모교육을 준비할 때 어린이집 주변의 공공공간·버스·공원 등을 함께 확인한다.
3. ‘돌봄시설 주변 활동공간 검토’에서는 어린이집 대표위치와 수록 공공공간의 직선거리를 비교해 **연락·협의 후보**를 찾는다.

이 비교는 실제 보행거리·시설 대관 가능·프로그램 적합·돌봄 수요·대기수요·시설 공급 부족 또는 최적 입지를 판정하지 않는다. 이런 판단에는 시설별 이용대상, 운영조건, 현장 접근성, 연령별 인구, 실제 이용·대기수요가 추가로 필요하다.

## 갱신 재현

```bash
node scripts/data/collect-childcare.mjs --fetch --source-html /tmp/childcare-source.html
```

이미 수신한 원문을 재처리하려면 다음처럼 실행한다.

```bash
node scripts/data/collect-childcare.mjs --source-html /tmp/childcare-source.html --collected-at 2026-10-23T17:32:48.964Z
```

스크립트는 공개 SHEET의 원문 총 건수와 실제 파싱 행 수가 다르거나 열 구성이 바뀌면 중단한다. 현 포털의 시도 선택값 `12`를 사용하며, 수신한 시군구명·주소·행정경계로 지역을 재검사한다. 지역코드 변경 시 선택값을 다시 확인해야 한다. 자료를 갱신한 뒤 manifest의 파일 해시도 갱신하고 `npm test` 및 `npm run validate:region`을 실행한다.

## 2026-10-27 서구 돌봄·육아시설 확장

공식 공개목록에서 어린이집 외 **78개 시설·서비스 공간**을 추가했다. 지도에 위치를 표시한 항목은 **31개**, 위치를 확정하지 못해 주소 목록으로 제공하는 항목은 **47개**다. 같은 건물의 도서관·장난감대여·수유실은 서비스가 달라 별도 항목이며 건물 수 또는 전체 공급량이 아니다. 민간 키즈카페를 포함한 서구의 모든 시설을 완전히 확보한 것으로 표시하지 않는다.

### 위치의 의미와 오류 처리

29개는 **공식 시설목록의 도로명주소와 기존 공개자료의 건물 주소를 대조한 대표위치**다. `locationStatus: address_reference`와 좌표 원출처·원자료 ID·파일 해시를 남겼다. 해당 시설의 독립적인 원문 좌표나 출입구 좌표라는 뜻은 아니다. 여러 동이 있는 단지의 개별 세대 등 위치를 좁히기 어려운 사례는 주소 목록만 제공한다.

수유실 2개는 공식 상세페이지의 길찾기 링크 좌표를 WCONGNAMUL → EPSG:5181 → WGS84로 변환해 사용했다. [카카오 공식 개발자 답변](https://devtalk.kakao.com/t/topic/38086)의 투영좌표 배율을 적용하고 서구 경계를 검사했다. 원문 지도링크 자체에 오류가 있는 사례(운천역의 지역 밖 좌표, 신세계백화점의 터미널 동일좌표 등)는 사용하지 않고 동일주소의 기존 공개 대표점으로 대조했다.

시설 목록의 공개 등록상태와 현재 운영·예약·정원·방문 가능 여부는 별개다. 2026-10-27 호출한 운영 사이트의 브이월드 장소검색은 `VWORLD_API_KEY`/`VWORLD_DOMAIN` 미설정 응답을 반환했다. 따라서 미확정 47곳을 자동으로 찾았다고 표시하지 않는다. 해당 환경변수 설정 후 주소 검색 결과를 대조해 위치를 보완할 수 있다.

새 데이터 파일들의 해시, 지역경계, 행정동 일치와 수록 개수는 `node scripts/validate-decision-data.mjs`로 확인했다.
