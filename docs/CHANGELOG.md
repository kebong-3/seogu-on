# 서구:온 변경 기록

버전별로 흩어져 있던 문서(docs/v02 ~ v061의 안내문·시험 출력·화면 캡처)를 이 한 장으로 줄였습니다.
지운 파일은 Git 이력(v0.7.0 기준 커밋)에 그대로 남아 있습니다. 자료의 출처·제외 사유처럼 지금도 근거로 쓰는 문서는 지우지 않았습니다(맨 아래 표).

각 항목의 "확인하지 못한 것"은 당시 문서에 적힌 그대로 옮겼습니다. 검증하지 않은 것을 검증한 것처럼 고쳐 쓰지 않았습니다.

## 0.8.1 (동 이름 정리·상습결빙구간·공개자료 보강)

- **동 번호·번호표 제거**: 지도 위 숫자, 왼쪽 동 카드 숫자 배지, 번호표 범례를 제거했습니다. 마을 BI와 동 이름은 유지합니다. 경계도·밝은 도시모형·브이월드 3D·OSM 경량지도에서 선택한 동의 전체 이름을 우선 배치하고, 겹치는 이름은 숨겼다가 확대·이동 시 다시 배치합니다. 쓰지 않는 `dong-legend.js`와 번호 전달 이벤트도 제거했습니다.
- **상습결빙구간 API 추가**: 공식 `DSSP-IF-00120`을 재난안전 목록에 등록해 기존 9종에서 10종이 됐습니다. 주소는 `https://www.safetydata.go.kr/V2/api/DSSP-IF-00120`, 서버 Secret은 `SAFETYDATA_00120_KEY`, 공식 설명은 [dataSn=111](https://www.safetydata.go.kr/disaster-data/view?dataSn=111)입니다. 목록 등록은 수신 성공을 의미하지 않습니다.
- **전용 메뉴·광주 서구 우선 조회**: 상습결빙구간 메뉴에서 서구 전체를 우선 대상으로 조회하며, 전국 원자료의 지역명과 실제 행정경계를 검수합니다. 지점 수와 고유 구간번호 수, 키 설정과 수신 상태를 분리합니다. API 대표점을 임의로 이어 실제 도로 선형을 만들지 않습니다.
- **직접 확보한 공개자료**: 수록 항목, 출처, 기준일, 제외 사유와 검증 결과는 [0.8.1 변경·확인 기록](v081/RELEASE.md)에 정리합니다.
- **확인한 것**: 동 이름 배치·홈 관련 Node 회귀시험 24개 통과(`node --test tests/ui-label-layout.test.mjs tests/ui-home.test.mjs`). 360·414·672·1024·1440px 배치, 선택 동 우선 표시, 확대 시 이름 복원, 3D 좌표 계산 실패 시 예외 처리를 확인했습니다. `app.js`, `viewer.js`, `scene.js` 문법 검사도 통과했습니다.
- **추가 시점의 수신·배포 상태**: 실제 호출에서는 HTTP 200 응답 본문에 `resultCode: 32`(등록 IP 오류)가 확인됐습니다. 해당 점검 당시 Vercel 키 저장까지 확인했고 새 배포와 API 실자료 수신 성공은 확인하지 않았습니다. 후속 배포·실수신 결과는 위 0.8.1 기록에서 별도로 확인합니다. Node 배치 시험은 실제 브이월드·OSM 화면 검증을 대신하지 않습니다.

## 0.8.0 (AI 질의·MCP·자료 파이프라인·화면 정리)

- **동 이름표**: 서구 전체 화면에서 18개 동 이름이 겹치던 문제를 고쳤습니다. 겹치는 자리에는 이름 대신 번호표(1~18)를 두고, 지도 위 "번호표" 안내와 왼쪽 동 목록에 같은 번호를 표시합니다. 경계도·밝은 도시모형·브이월드 3D·OSM 경량지도가 같은 배치 계산(`src/city/label-layout.js`)을 씁니다.
- **미세먼지(PM10) 미수신**: 공공데이터포털의 Encoding 키를 넣으면 에어코리아 요청에서만 이중 인코딩되어 거부되던 문제를 고쳤습니다. 실패 원인을 `code`로 구분해 상단 값의 말풍선과 "관측자료 수신 상태" 패널에 한국어로 보여 줍니다(`docs/API_SETUP.md`).
- **메뉴**: 첫 화면의 버튼 9개를 주요 카드 3개(폭염 그늘 · 생활 인프라 · 재난 상황판)와 "더 보기"로 정리했습니다. 기존 기능은 모두 남아 있습니다.
- **지도에게 묻기**: 문장으로 질문하면 수록 자료만으로 답하고 결과 지점을 지도에 표시하는 패널을 켰습니다(`/api/ask`). `GEMINI_API_KEY`가 있으면 AI가, 없으면 규칙 기반으로 답합니다. 이 카드가 켜지면서 주요 카드는 폭염 그늘 · 지도에게 묻기 · 생활 인프라가 되고 재난 상황판은 "더 보기"로 옮겨졌습니다. 확인하지 못한 것: 실제 Gemini 호출(개발 환경에서 Google 서버에 연결할 수 없었음), 브이월드 3D·OSM 경량지도에서의 결과 표시(`docs/AI_PANEL.md`).
- **대표 시나리오 "폭염 그늘"**: 그늘막·쿨링포그·무더위쉼터 지도층과 5분 그림자 패널을 한 번에 엽니다. 받지 못한 자료는 "미수신"으로 적습니다.
- **좁은 화면**: 820px 이하에서 왼쪽 패널을 서랍으로 바꾸고, 상단 관측정보가 잘리지 않게 칸으로 나눴습니다. 누르는 영역은 40px 이상입니다.
- **저장소 정리**: 과거 버전의 화면 캡처와 시험 출력 171개(약 15MB)를 지웠습니다. CI는 `main` 기준 하나로 합쳤습니다.
- 확인하지 못한 것: 실제 브이월드 3D 화면, 실제 기상청·에어코리아 응답. 로컬 경계도·밝은 도시모형과 가짜 응답 시험으로만 확인했습니다.
