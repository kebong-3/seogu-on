# 행정판단 업무에 연결한 공식 자료

검토·수집일: 2026-10-23. 공공데이터포털 공개 JSON 원문과 제공기관 상세화면을 직접 수신한 결과이다. API를 목록에 올려 둔 상태와 실제 받은 자료를 구분한다.

## 이번에 실제 연결한 자료

서구와 순천 수치는 실제 배포본의 2026-07-01 행정동 경계 안 좌표로 검사했다. 학교 원문 전체 12,004행, 그늘막 13,217행, 어린이보호구역 14,640행을 수신했다. 전국 횡단보도 공개 다운로드는 50,000행 상한이 있어 전국 전수라고 표현하지 않는다. 순천 현행 제공기관 `5790000`의 수신 866행은 해당 제공기관 상세화면의 전체 866행과 일치했다. 구 기관코드 `4820000`의 30행은 현행본의 관리번호·좌표와 모두 일치해 제외했다.

그늘막 151행은 151개의 검증된 독립 시설이라는 뜻이 아니다. 같은 교차로의 같은 좌표에서 위치 설명·형태·설치연도·규격이 다른 행을 원문 그대로 유지했다. 보호구역 100행도 대상시설 기록 수이며 지정구역 폴리곤 수가 아니다. 분석에서 주변 수록시설을 셀 때 이 단위와 동일 좌표 중복을 고려해야 한다.

## 출처·좌표·이용조건

학교는 한국교육시설안전원(`B554398`), 순천의 나머지 자료는 순천시(`5790000`)가 제공한다. 각 제공기관 상세화면에서 **무료 / 이용허락범위 제한 없음**을 확인했다. 코드 저장소의 라이선스와 데이터 이용조건은 별개이다.

| 자료 | 제공기관 상세 식별자 |
|---|---|
| 학교 | `uddi:9793c2f7-4dba-49ed-bf64-8c6cfd56102a` |
| 순천 그늘막 | `uddi:fe008ea7-bc44-43e9-b6b7-d3de1a3f0920` |
| 순천 횡단보도 | `uddi:294d8637-d5f2-45e1-8efc-f91e600c240d` |
| 순천 보호구역 | `uddi:6d18caf9-342e-4e7a-bf1d-ae86d85abd8f_202002241356` |

원문 상세정보 확인 요청: `POST https://www.data.go.kr/tcs/dss/selectDpkDetailInfo.do`, 폼 항목 `publicDataDetailPk`에 위 식별자를 입력한다. 표준데이터 화면의 제공기관 목록에서 동일한 상세화면을 열 수 있다.

위도·경도를 GeoJSON의 `[경도, 위도]` 순서로 옮겼다. 값의 한국 좌표 범위와 실제 행정경계 포함을 검사했으며 주소에서 좌표를 추정하거나 좌표를 임의 이동하지 않았다. 학교·횡단보도는 원본 학교ID·관리번호를 보존한다. 그늘막·보호구역에는 영구 원본ID가 없어 원문행 기반 스냅샷 식별자를 사용하고 `originalId: null`로 명시한다.

각 GeoJSON의 `metadata`에는 기준일, 수집시각, 제공기관 원문 총행·수신행, 지역 원문 SHA-256, 행정경계 해시, 누락 기준일 수, 중복 좌표 수와 적용 범위를 기록했다. `sourceAttributes`에는 원문 신호·접근시설·규격 속성을 보존한다. 빈칸은 미상이며 시설 미설치로 바꾸지 않는다. 횡단보도의 신호시간은 수록 당시 값으로 실시간 신호정보가 아니다.

## 수집 재현

새 API 키나 계정을 만들지 않고 공공데이터포털의 공개 다운로드를 사용한다. 현재 앱은 이 수집본을 제공하며, 실시간 API 수신이라고 표시하지 않는다.

```bash
node scripts/data/collect-decision-sources.mjs --fetch --source-dir /tmp/seogu-decision-sources
```

이미 내려받은 원본으로 다시 생성할 때:

```bash
node scripts/data/collect-decision-sources.mjs --source-dir /tmp/seogu-decision-sources
```

임시 출력 폴더를 지정하려면 `--out /tmp/seogu-decision-output`을 추가한다. 프로젝트에는 관내 GeoJSON만 저장하며 전국 전체 원문을 중복 배포하지 않는다.

공개 다운로드 방식:

1. `GET https://www.data.go.kr/download/columList.json?pk={표준데이터ID}&ext=JSON`으로 컬럼·테이블·다운로드 행 수를 받는다.
2. `GET https://www.data.go.kr/download/standard.json`에 `publicDataPk`, `totalCount`, `svcTableNm`, `perPage`, `page`, 반복 `colNmList`를 넘겨 페이지를 수신한다. 공식 화면의 다운로드 스크립트와 같은 규격이다.
3. 기관별 원문 총행 수, 이용조건, SHA-256과 행정경계 포함 여부를 검사한다. 50,000행 제한 때문에 특정 기관 자료를 모두 받지 못하면 생성에 실패하며 부분자료를 전수자료처럼 게시하지 않는다.
4. 새 행정구역 코드, 원문 구조 또는 제공기관 변경이 생기면 기존 수치를 고정 복제하지 않고 검토 후 갱신한다.

`curl`이 설치된 Node.js 환경에서 실행한다. 다운로드 화면 규격은 공개 OpenAPI 계약과 다르므로 포털이 규격을 바꾸면 수집기 갱신이 필요하다. 반복 자동 수집이 필요해지면 해당 표준데이터 OpenAPI 활용신청으로 전환할 수 있으나, 기존 공공데이터 인증키가 있어도 개별 서비스의 이용 승인 여부는 따로 확인한다.

## 자료를 행정판단으로 연결할 때

- **현장점검 준비:** 현재 등록된 학교·정류장·횡단보도와 그늘막·활동공간·쉼터의 거리조건을 비교하고, 순천 횡단보도는 원문의 턱낮춤·점자블록 등 상태도 함께 확인한다. 점검대상 위치와 확인할 항목을 내보내며 자료 미수록은 부재·위법 판정으로 바꾸지 않는다.
- **생활시설 추가 후보 비교:** 기존 시설과 수요를 대리하는 공개 위치자료를 표시한 뒤 후보 A/B를 배치해 같은 거리 기준에서 새로 범위에 들어오는 위치·중복되는 위치를 계산한다. 보행 네트워크나 인구 격자가 없을 때는 직선거리 기반 위치 비교라고 명시한다.
- **사업 후보지 주변 검토:** 지도에 후보점을 찍고 지역별 Manifest에 등록된 학교·보호대상시설·공공공간·그늘막 등의 주변 수록자료를 같은 반경으로 조회해 부서협의·현장확인 항목과 근거자료를 만든다. 이를 법정 영향평가·허가 가능 여부·인과적 피해 예측으로 부르지 않는다. 기존 앱의 보안등·CCTV·공원·주차장 레이어는 새 업무 비교에 아직 포함하지 않았으며, 자료 검증 후 추가할 확장 대상이다.

AI는 질문을 이 업무·지역·거리·시설 조건으로 바꾸고, 결정적 공간계산 결과의 차이와 확인사항을 근거와 함께 설명한다. 사고 감소율·민원 감소율·예산 절감액은 검증자료 없이 생성하지 않는다.
