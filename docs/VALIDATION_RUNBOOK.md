# 제출 버전 검증과 실제 증거 남기기

자동시험, 실제 모델 호출, 다른 지역 자료 재현, 직원 업무효과 실험은 서로 다른 증거다. 실행하지 않은 항목은 미실행으로 남긴다. 결과는 원자료와 분리한 `outputs/`에 저장한다. 원본 공개자료를 테스트 때문에 바꾸거나, 실패한 수행을 삭제해 성공률을 높이지 않는다.

## 1. 같은 제출 버전의 전체 검증

Node.js 22.x와 Python 3가 필요하다. 저장소의 `vendor/cesium-1.121.0.tar.gz`를 포함해 전체 소스를 받는다. 빈 파일이나 다른 버전의 tar로 대체하면 안 된다. 외부 모델 키 없이도 아래 코드·자료 검증을 실행할 수 있다.

```sh
npm run verify
node scripts/validate-region-replay.mjs --out outputs/region-replay.json
```

`verify`는 코드검사 → 단위시험 → 정적 빌드 → 배포묶음 감사 순서다. 중간 실패 후 뒤 단계가 실행되지 않았다면 전체 통과라고 쓰지 않는다. 브라우저 시연은 최종 배포 URL에서 별도로 확인한다.

## 2. 실제 모델 2종의 동일 과업 검증

관리자가 승인한 서버 환경에 모델 ID와 키를 설정한다. `.env.local`은 저장소에 올리지 않는다. 아래 `YOUR_GOOGLE_MODEL`과 `YOUR_SOLAR_MODEL`을 실제 사용할 모델 ID로 바꾼다. 모델 이름은 제공기관의 현재 목록과 운영 설정으로 확인한다.

```sh
node --env-file=.env.local scripts/validate-models.mjs --target google:YOUR_GOOGLE_MODEL --target upstage:YOUR_SOLAR_MODEL --out outputs/model-validation.json
```

- Google 키는 `GEMINI_API_KEY`, Solar 키는 `UPSTAGE_API_KEY`를 사용한다. `AI_API_KEY`를 쓰는 경우 현재 `AI_PROVIDER`와 같은 공급자에만 재사용한다. 다른 제공기관으로 키를 넘기지 않는다.
- 같은 제공기관의 서로 다른 실제 모델도 `--target google:모델A --target google:모델B`처럼 지정할 수 있다. OpenAI 호환 서버는 `AI_PROVIDER=openai-compatible`, `AI_API_BASE`, 필요한 경우 `AI_API_KEY`를 먼저 설정한다.
- 고정 과업은 풍암동 공원 위치, 학교 주변 그늘막 200m 비교, 풍암동·상무2동 학교 수 비교의 세 가지다. 실행 중 운영 서버의 환경설정을 바꾸지 않는다.
- 실제 외부 호출과 사용량이 발생한다. `not-configured`는 호출하지 못한 상태, `rules`는 규칙 대체다. 둘 다 모델 성공이 아니다.
- 다른 모델로 자동 복구되면 실제 모델 ID를 기록하지만 요청한 모델 성공으로 세지 않는다. 복구된 모델을 검증 대상으로 명시해 다시 실행한다.
- 요청 모델·실제 모델·응답모드·동·반경·근거·지도 결과를 함께 검증한다. 모든 과업을 통과한 서로 다른 두 모델이 있어야 `twoModelVerificationPassed:true`다.
- 이 하니스의 판단 시험은 모의 응답으로 검사한다. 시험 통과 자체가 실제 두 모델 정상 구동의 증거는 아니다.

결과 JSON의 응답·출처와 지도 지점을 사람이 한 번 더 확인하고, 최종 제출 커밋 및 실제 화면 캡처와 함께 보관한다. 관측 지연을 직원 업무시간 절감률로 바꾸지 않는다.

## 3. 순천 공개자료팩 재현

`validate-region-replay.mjs`는 저장소에 수록된 실제 순천 자료로 다음 흐름을 수행한다.

1. 지역 프로필·행정경계·공공공간 자료를 검증한다.
2. 외부 자료팩 형식(`manifest.json`, `admin-boundaries.geojson`, `facilities.geojson`)으로 작업 사본을 만들어 다시 검증한다.
3. 회의공간 조회 → 특정 구역 조회 → 다른 지역 질문 차단을 확인한다.
4. 토요일 14~17시 비교를 수행하며, 현장 확인값 없는 공간을 ‘사용 가능’으로 확정하지 않는지 확인한다.
5. 원본 파일 SHA-256이 수행 전후 동일한지 확인한다.

이 결과는 다른 실제 지역의 데이터·계산 재현 증거다. 신규 기관에 운영 도입을 완료했다거나, 현재 예약 가능 여부를 조사했다거나, AI가 실제 호출됐다는 의미는 아니다. 지역 조회는 키 없이 규칙 모드로 재현한다.

## 4. 사진 판독 참고기호 재생성

```sh
python3 scripts/data/build-safe-return-image-routes.py
node scripts/data/assign-dongs.mjs --check
npm run data:audit
```

생성기는 공통 행정동 판정 함수를 호출해 동 속성을 포함한다. `NODE_BINARY`로 Node 실행파일을 명시할 수 있다. 경계 밖·모호한 경계 점은 임의 배정하지 않는다. 사진 판독 좌표·불확실성·현재 작동 미확인·자동 경유점 비대상 속성을 유지한다. 행정동 속성이 생겼다고 공식 설치 좌표가 되는 것은 아니다.

## 5. 직원 업무효과 실험

직원 3~5명이 같은 공개자료와 완료 기준으로 기존 방식·서구온을 번갈아 수행한다. 시간, 시설 오류, 출처 누락, 완료 여부를 원시 기록에 남긴다. 실패도 포함한다. 이 실험은 사람이 실제 수행한 뒤 기록해야 하며 자동시험 결과로 대신 채우지 않는다.

## 제출 증거의 최소 묶음

- 최종 커밋 및 전체 `verify` 로그
- 실제 모델 검증 JSON과 화면 확인 기록 또는 미실행 사유
- 순천 재현 JSON
- 핵심 과업 3개의 실제 내보내기 파일
- 직원 실험 원시 기록 또는 미측정 표시

자료 갱신·API 변경·코드 수정이 있으면 영향을 받는 항목을 다시 실행하고 문서·영상의 버전을 맞춘다.
