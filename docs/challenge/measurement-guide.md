# 서구온 업무 비교 기록 안내

이 자료는 실제 직원 사용 결과를 기록하기 위한 도구입니다. 빈 양식과 도구를 만들었다는 사실은 업무효과를 측정했다는 의미가 아닙니다.

## 10분 안에 시작하는 방법

1. 같은 PC에서 `seoguon-work-study.html`을 엽니다. 별도 설치·서버·로그인이 없습니다.
2. 진행자가 비교할 앱 버전, 공개자료 기준일, 공통 과업 조건을 입력합니다. 직원 이름 대신 참가번호를 배정합니다.
3. 공원 과업 하나부터 시작합니다. 페이지의 권장 순서대로 기존 방식과 서구온을 각각 실행합니다. 다른 사람이 진행 순서를 바꿔 학습효과를 줄입니다.
4. 각 수행의 시간·완료 여부·잘못된 결과 수·출처 누락 수를 기록합니다. 실패·중단도 남깁니다.
5. 원시 CSV와 JSON 백업을 내려받습니다. 첫 과업이 익숙해진 다음 폭염·침수 과업으로 넓힙니다.

10분은 첫 과업의 준비·기록을 시작하기 위한 안내입니다. 전체 3과업을 직원 3~5명이 끝내는 데 걸리는 시간을 보장하지 않습니다.

## 비교가 공정해지는 조건

- 두 방식 모두 같은 공개자료 사본, 같은 기준일, 같은 과업 완료 기준을 씁니다.
- 기존 방식은 현재 실제로 하는 검색·지도 조회·엑셀/메모 작성 흐름으로 수행합니다. 불필요한 절차를 일부러 더하지 않습니다.
- 서구온은 같은 입력으로 수행하고 결과 파일을 다시 열어 확인합니다.
- 두 방식 모두 결과물을 검토하는 시간까지 포함합니다. 앱 로딩·실패·재시도 시간을 빼지 않습니다.
- 참가번호·과업마다 수행 순서를 바꿉니다. 순서와 기존 방식에 대한 익숙함, API 연결 실패 등 영향을 메모합니다.
- 자료 부족 때문에 확인할 수 없으면 미완료로 기록합니다. 자료 없음과 시설 없음은 다릅니다.
- 초보자에게만 불리한 방식을 배정하거나 좋은 수행만 골라 제출하지 않습니다.

## 공통 과업과 완료 기준

| 과업 | 두 방식에 똑같이 요구할 결과 | 완료 판단 |
|---|---|---|
| 공원 문의 | 풍암동 공원의 이름·위치, 출처 2종 또는 확인 가능한 모든 출처, 기준일을 짧은 검토메모로 정리 | 동일한 공개자료 범위에서 누락·중복을 확인하고 메모 파일을 열어봄 |
| 폭염 검토 | 풍암동 정류장·그늘막·쉼터의 공개자료를 사용해 150m/300m/추가 후보 최대 3개 조건으로 기존 활용안과 추가 검토안을 비교 | 계산 조건·미확인 사항을 적고 동일 기준으로 비교표를 완성함. 현장 위험 감소로 단정하지 않음 |
| 침수 점검 | 풍암동 과거 침수기록을 확인하고 대표좌표와 과거 이력을 구분해 현장 확인목록 작성 | 기록 출처·기준일·좌표 성격·현장 확인사항을 포함한 점검메모를 저장함 |

과업 문구는 현업 담당자가 먼저 확인합니다. 기존 방식으로 수행하기 어려운 복합 계산은 기존 방식의 한계로 기록하되, 서로 다른 결과물을 완성한 시간을 단순 비교하지 않습니다. 검토 대상 수는 갱신에 따라 바뀔 수 있으므로 특정 숫자를 정답으로 고정하지 않습니다.

## 숫자를 읽는 방법

- **비교 조건 선택:** 버전·자료·공통 조건별로 요약을 나눠 볼 수 있습니다. 제출에 쓸 결과는 같은 조건을 선택합니다. 원시 CSV와 JSON에는 모든 조건이 보존됩니다.
- **전체 수행 중앙값:** 완료·미완료를 모두 포함한 기록 시간의 중앙값입니다. 두 집단의 결과물이 다르면 이 값만으로 절감률을 주장하지 않습니다.
- **완료율:** 완료 수행 수 ÷ 기록된 수행 수입니다. 빈 양식은 0%가 아니라 ‘미측정’입니다.
- **짝 비교:** 같은 참가번호·과업·앱 버전·자료 기준일·조건에서 양쪽 모두 완료한 경우에만 계산합니다.
- **짝별 시간 변화 중앙값:** 각 짝의 `(기존 시간 − 서구온 시간) ÷ 기존 시간 × 100`을 계산한 뒤 중앙값을 냅니다. 음수는 더 오래 걸렸다는 뜻입니다.
- **오류·출처 누락:** 각 수행에서 검토자가 확인한 건수입니다. 검사하지 않았으면 기록을 확정하지 않습니다.
- **제약:** 소수 참여자의 탐색적 결과이며, 전 직원·모든 업무의 효과를 대표하지 않습니다. 참가 수·과업 수·자료 기준일·수행 순서·실패를 함께 제시합니다.

## 기록 보호와 제출

- 이 페이지는 기록을 외부로 보내지 않습니다. 현재 브라우저의 로컬 저장소를 사용합니다. 파일 방식에서 저장이 제한되면 화면에 알리고 해당 탭 안에서만 유지합니다.
- 서로 다른 PC의 기록은 JSON 백업을 가져와 합칩니다. 같은 참가번호가 다른 사람에게 배정되지 않도록 진행자가 번호를 나눕니다. 중복 기록을 조용히 덮어쓰지 않습니다.
- 이름·연락처·민원인 정보·내부 문서 내용·API 키를 메모에 넣지 않습니다.
- 원시 CSV는 검토와 계산 확인용입니다. JSON은 재가져오기용입니다. 제출 문서에는 익명 요약과 한계를 넣고 원시 기록은 근거로 보관합니다.
- 브라우저 기록 삭제·기기 교체 전에 JSON을 내려받습니다. CSV만으로 페이지에 복원할 수는 없습니다.
