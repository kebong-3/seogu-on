# 서구온 운영·자료 갱신 인수표

운영 담당자 이름을 임의로 정하지 않았습니다. 아래 역할을 실제 부서에 배정하고, 완료한 항목에만 근거를 연결합니다. 이 문서는 운영 승인이나 서비스 수준 보장이 아닙니다.

## 누가 무엇을 맡는가

| 역할 | 해야 할 일 | 인수 시 채울 값 |
|---|---|---|
| 업무 책임 | 서비스 범위·해석 한계·직원 안내·문의 답변 승인 | 담당 부서·대체 담당·공용 문의 경로 |
| 자료 관리 | 출처·기준일·갱신 여부·중복·좌표·수록 범위 점검 | 자료별 담당 역할·검토일·다음 확인일 |
| 기술 운영 | 저장소·배포·장애 기록·변경 검증·복구 | 관리 계정의 역할·인수 절차·최근 정상 버전 |
| 보안·이용조건 검토 | 키·개인정보·외부자료 이용조건·재배포 범위 확인 | 담당 부서·검토 근거·미확정 항목 |

개인 계정 비밀번호를 이 표에 적지 않습니다. 승인된 계정 권한과 키 교체 절차를 별도 경로로 인수합니다.

## 자료를 갱신할 때

1. 원본 공개자료의 주소·기준일·수록 범위·이용조건을 확인하고 원본 사본을 보관합니다.
2. 별도 작업본에서 형식을 변환합니다. 좌표계·행정동 매칭·중복 제거·제외 이유를 기록합니다.
3. 이전 버전과 신규·삭제·변경 건수 및 지도 위치를 비교합니다. 급격한 감소가 정상 변경인지 확인합니다.
4. 자료 없음, 미수신, 만료, 범위 밖을 구분합니다. 0건을 ‘시설 없음’이나 ‘위험 없음’으로 자동 바꾸지 않습니다.
5. 자동 검증과 대표 과업을 실행합니다. 원본·가공본·실행 결과의 기준일이 같은지 확인합니다.
6. 검토자가 승인한 자료만 배포하고 변경 일자·커밋·기준일·출처를 남깁니다. 문제가 있으면 직전 정상본으로 복구합니다.

자동 갱신 주기를 제공기관이 보장한다고 쓰지 않습니다. 자료별 원문 갱신 주기와 운영자의 다음 확인일을 분리해 기록합니다.

## 장애별 대응

| 증상 | 직원에게 안내할 내용 | 운영자가 확인할 내용 |
|---|---|---|
| 3D 지도가 표시되지 않음 | 경계도·경량 지도에서 자료를 확인하도록 안내 | 브라우저 WebGL, SDK 수신, 등록 도메인·키, 외부 서비스 상태 |
| AI가 규칙 기반으로 전환됨 | 화면의 근거와 출처를 확인하고 AI 성공으로 설명하지 않음 | 실제 provider/model, 오류 종류, 요청 크기, 호출 제한; 키 값은 로그 제외 |
| 조건과 다른 결과가 표시됨 | 해당 결과를 업무 판단에 쓰지 말고 입력·결과 조건을 비교 | 지역·시설 종류·반경·비교 방식 전달과 회귀 테스트 |
| 자료가 0건 또는 미수신 | 자료 범위·기준일·수신 상태를 확인 | 원본 제공 중단, 인증, 변환 실패, 좌표·동 매칭 |
| 내보내기 파일이 열리지 않음 | 저장 경로와 브라우저 다운로드 제한 확인 | 파일 형식·인코딩·필수 필드·재열기 시험 |

## 버전별 최소 인수 기록

- 소스 커밋 / 앱 표시 버전 / 배포 식별자 / 배포 일시.
- 전체 자동 검증 로그와 마지막 성공 일시.
- 새 브라우저에서 공원 질문·폭염 비교·침수 점검과 결과 파일 재열기 기록.
- 실제 AI provider/model과 검증한 질문; 모의 응답과 실모델 결과 구분.
- 자료별 출처·기준일·이용조건·미수신 항목.
- 운영자·대체 담당·비밀값을 제외한 설정 설명·직전 정상 버전.

## 외부자료 이용조건을 확인하는 실무표

`SOURCE_LICENSE_REGISTER.csv`와 원본의 개별 조건을 대조합니다. 코드의 MIT 고지는 외부 지도·공공자료·기관 표장·모델 서비스 전체에 적용되지 않습니다. 아래 질문은 검토 항목이며 이용허락 여부를 대신 판정하지 않습니다.

| 확인할 질문 | 남길 근거 | 미확정일 때 |
|---|---|---|
| 코드·문서·화면·데이터 중 무엇을 배포하는가 | 배포 파일 목록과 출처 | 배포 범위를 먼저 구분 |
| 출처·저작권·라이선스 고지를 유지했는가 | 원문 URL·기준일·고지 파일 | 고지 누락부터 보완 |
| 변환·가공·후속 수정·재배포가 허용되는가 | 개별 이용조건·제공기관 회신 | 무제한 재사용 가능으로 표시하지 않음 |
| 대회가 요구하는 후속 사용 범위와 맞는가 | 공식 안내서의 권리 항목과 자료별 조건 대조 | 제공기관 또는 주관기관 확인 필요 항목으로 기록 |
| API 조회 권한과 원본 대량 재배포 권한을 구분했는가 | API 약관·다운로드 조건 | 키 발급만으로 재배포 허용을 추정하지 않음 |
| 자료·표장 이용조건이 바뀌었는가 | 확인일·원문 사본·변경 기록 | 최종 제출 전에 다시 대조 |

특히 기존 고지에 변경 제한이 있는 것으로 기록된 상습결빙 자료·재난안전 자료, 브이월드·TMAP·기관 표장 항목을 먼저 확인합니다. 현재 문서 작성만으로 이 확인이 완료된 것은 아닙니다.
