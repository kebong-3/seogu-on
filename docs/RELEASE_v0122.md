# 0.12.2 — 브이월드 기본 진입과 작은 업무 메뉴

2026-10-25(한국시간).

## 수정 목적

기본 주소에서는 브이월드 3D를 먼저 열고, 생활지도·검토 기능은 그 지도 위에서 사용한다. 사용자가 명시적으로 고른 경계도·경량지도는 보존한다. 이전에 안내한 `?map=boundary` 주소는 경계도를 지정하는 주소이므로 기본 접속 안내는 `https://seogu-on.vercel.app/`를 사용한다.

순천을 경계도로만 제한하던 지도 기능과 서구 전용 행정자료 기능을 분리한다. 공통 지도·브이월드 키 상태만 공유하고, 서구 전용 API 및 자료층은 순천에 자동 활성화하지 않는다. 지역 경계와 카메라 제한도 선택 지역을 따른다.

## 메뉴 크기

첨부 화면의 큰 반복 질문과 화살표를 짧은 안내로 바꿨다. 홈 상단 안내는 최소 132px→64px, 돌봄·안심 카드 각76px→48px로 줄였다. 점검·보완안 버튼은 한 줄로 배치하고 중복 링크를 없앴다. 자동 계산 요약·API 연결 안내는 기본 접힌 추가 자료 메뉴에 보존한다. 전체 글자를 일괄 축소하지 않고 주요 글자14~16px와44px 이상 터치영역을 유지한다.

## 추가 API 기획

`DIGITAL_TWIN_API_ROADMAP.md`에 주민 시설 탐색, 폭염 운영계획, 호우 대응, 현장시설 상태 갱신의 입력·변경 시나리오·주민 안내·행정 산출물·추가 API 조건을 정리한다. 이 문서의 미래 기능은 이번에 연동 완료한 API가 아니다.

기존 미배포 품질수정은 보존한다. 서구청어린이집의 동일 주소 공식자료와 불일치한 좌표는 임의 이동하지 않고 공간계산에서 보류하며, 원문과 제외근거를 보존한다. 질문의 시설 종류·반경 및 보고서의 실제 선택 위치 안내도 유지한다.

## 검증 범위

기본 엔진 선택, 명시적 대체모드 보존, 지역 전환, 공통 지도 설정과 서구자료 격리, 지역 경계 좌표 검증, 회귀검사·배포파일·HTTP 경로를 확인한다. 외부 브이월드 SDK 수신과 실제 지형·건물 렌더링은 브라우저 접속 환경에 따라 별도로 확인한다.
