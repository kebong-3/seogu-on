# 서구온 v0.17.0 — 주민이 찾고, 고르고, 걸어가는 생활지도

검토일: 2026-10-29. 운영 배포 여부와 실제 제공기관 연결은 최종 검증 기록으로 확인한다. 이 문서의 전문가·심사 관점은 역할에 따른 모의 검토이며, 실제 기관 직원이나 특정 회사 경력자가 참여했다는 뜻이 아니다. [40개 피드백·6인 모의평가](UX_REVIEW_v0170.md)에 수정 전 근거, 구현 범위, 남은 확인을 함께 기록한다.

## 달라진 화면과 이용 순서

지역 선택이 먼저 보이고 그 아래에 돌봄·생활안전, 계절 안심 도보 내비게이션, 재난안전지도가 이어진다. 긴 동 목록은 펼쳐서 선택한다. 주민 생활서비스와 행정 검토 도구를 나누고, 모바일에는 홈·지역 / 돌봄·안심 / 길찾기 / 재난지도 메뉴를 둔다. 큰 그림자와 반복되는 배경·테두리를 줄이고 밝은 바탕, 일관된 아이콘·간격·둥근 카드로 정리했다. 낮은 데스크톱 화면에서는 보조 인사말을 줄여 세 서비스를 먼저 볼 수 있게 했다.

1. **시설 찾기**: 어린이집·돌봄센터·도서관·장난감·수유실·놀이를 고르거나 이름·동·주소를 검색한다. 결과는 10곳씩 보고 조건을 지울 수 있다. 실제 동 경계로 확인한 지도시설과 주소만 있는 서구 전체 목록의 범위를 구분한다.
2. **그 시설로 길찾기**: 지도 위치가 확인된 시설의 ‘여기로 길찾기’를 누르면 현재 지역과 원자료 ID가 일치하는 후보만 도착지에 넣는다. 중복 원문 참조도 유일하게 일치해야 하며, 미확정 47건에 임의 핀이나 경로를 만들지 않는다.
3. **출발·도착 → 경로 선택 → 안내 시작**: 자동으로 예시 장소를 채우지 않는다. 기본 길찾기는 제공기관의 직접 경로 한 개부터 조회하고, 계절·경유·우회 조건은 필요할 때 펼친다. ‘예시로 해보기’와 계절 예시 시각은 명시적으로 선택한다.
4. **실제 안내와 미리보기 구분**: GPS 시작은 별도 동작이며 음성·자동 재탐색 설정은 접어서 관리한다. 미리보기는 황갈색 배지와 점선으로 구별한다. 지도 선택 중에도 취소를 볼 수 있고, 진입 시 기존 GPS 안내와 진행 중 위치 요청을 멈춘다.

현재 위치·회전 지시·이탈·도착 판단의 기존 정확도·시각·연속성 검사는 유지한다. 종료·화면 닫기·서비스 전환 후 늦게 온 위치 응답이 화면을 다시 열거나 카메라를 움직이지 않도록 한다. 길찾기 제공기관 경로·시간은 실제 보행 접근성이나 안전 보증이 아니다.

## 접근성과 상태 표현

이용안내, 큰 글씨, 자동회전 줄이기, 회전 중 멈추기를 제공한다. 탭의 화살표·Home·End와 선택 탭만의 Tab 진입을 지원한다. 새 상세를 열면 제목으로, 닫으면 화면에 보이는 원래 제어 또는 해당 서비스로 초점을 돌린다. 같은 화면의 재렌더에서는 동일 ID 입력의 초점·선택 범위, 유일하게 식별되는 버튼을 복원한다. 숨겨짐·비활성·모호한 제어에는 초점을 보내지 않는다.

큰 글씨·375/390 CSS 픽셀 화면·데스크톱을 개발자 브라우저로 확인한다. 이 검사는 실제 iOS/Android 화면읽기·OS 글꼴 설정·위치 권한·현장 보행을 대체하지 않는다. [Apple HIG](https://developer.apple.com/design/human-interface-guidelines)의 시각적 위계와 [Android 접근성 지침](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views)의 여유 있는 터치 영역을 참고했으며 인증·가이드 전체 준수 판정을 주장하지 않는다.

화면 제목 옆에서 공개자료·현재 운영 확인, 도보경로·계절 계산 추정, 관측·과거자료, 개인 기록·기관 공유를 구분한다. ‘자료와 가정 안내’는 공개자료 / 관측값 / 계산·추정 / 사용자 가정을 설명하고 실제 비교·자료 점검으로 연결한다. 모든 객체의 실시간 상태배지를 구축한 것은 아니다. 개인 과제·단계 변경·복원·측정 저장 근처에도 이 브라우저 기록이며 공식 접수·승인·공유가 아님을 표시한다.

## 디지털트윈으로서의 판단

현재 앱은 **공간자료·일부 관측·조건별 대안 비교를 연결한 의사결정 지원 시제품**이다. 3D 화면에 더해 시설 추가·공간 개방 조건을 바꾸고 같은 기준의 차이를 계산하는 기능이 있으므로 단순한 시설 목록보다 나아갔다. 다만 모든 시설·도로의 현재 상태를 지속적으로 관측하고 기관의 조치·승인 뒤 운영 자료에 반영하는 체계는 없다. [NIST의 디지털트윈 설명](https://www.nist.gov/digital-twins) 및 [IR 8356](https://csrc.nist.gov/pubs/ir/8356/final)의 모형·관측·시뮬레이션과 신뢰 구분에 비춰 볼 때, 현재 상태를 완전한 실시간 운영 트윈이라고 평가하기에는 근거가 부족하다. 이는 이 프로젝트에 대한 모의 검토자의 판단이다.

다음 우선순위는 기능 버튼 추가보다 다음 근거를 연결하는 일이다.

- **객체별 상태와 시간**: 안정적인 시설·도로 ID, 원자료 기준일, 수집일, 실제 현장 확인일, 유효기간과 출처를 연결한다. 개인 가정과 공식 상태를 구분한다.
- **실제 조치 한 사례**: 발견 → 검토 → 조치 → 현장 확인 → 승인된 원자료 반영을 실제 시설 하나에서 입증한다. 현재 개인 기록을 기관 시스템 연동으로 설명하지 않는다.
- **같은 조건의 전후 비교 검증**: 시설 개방·폐쇄 가정과 실제 이용 가능·이동 부담의 차이를 확인한다. 현재 A/B 시설 수를 보행망 우회·안전도·수요 개선으로 바꾸지 않는다.
- **모형 보정과 처음 사용자 실증**: 같은 시각의 그늘 표본, 공식 출입구·현재 운영·노면 관측, 실제 이용자의 완료·오선택·확인 전화·수행시간을 수집한다. 미측정값을 성과로 만들지 않는다.

공식 여성안심 귀갓길 GIS 선형, 주소만 있는 47건의 검수 좌표, 현재 노면·통제, 기관 공동 인증·승인 서버와 운영 책임은 별도로 확보해야 한다. 실제 보행·이용자·기관 도입 자료 없이 모의 대회 점수를 확정 성과로 쓰지 않는다.

## 검증과 설정

수정 전 버전은 v0.16.0, 운영 소스 기준은 `1340f70c7339b29002dd3ffb31d5877068455042`다. 소스 원자료와 해시는 변경하지 않았다. 기존 보기 조건을 가져올 수 있고 v0.17.0 내보내기·가져오기도 지원한다. 설정 저장은 이용 목적·큰 글씨·자동회전 선호에 한정되며 질문·좌표·경로 이력은 저장하지 않는다.

전체 자동검사와 빌드·로컬 HTTP 검사, 배포 후 실제 경로 조회·시설 목적지 연결·종료 확인은 최종 검증 기록에서 실행 시점과 범위를 확인한다. Windows에서는 심볼릭 링크 이름의 시험을 대상에서 제외하며 Linux CI에서는 전체 시험을 실행한다. 시험 통과 수는 대회 점수나 실제 안전도·접근성 성공률이 아니다.

AI 제공기관 설정은 유지한다. Solar는 [설정 안내](SOLAR_SETUP.md)에 따라 새 키를 Vercel 환경변수로 등록하고 재배포해야 한다. 외부 장소·주소 검색은 별도 VWorld 서버 설정이 필요하며 수록시설 검색·지도 선택과 구분한다. 실제 키를 공개 파일이나 브라우저 입력란에 넣지 않는다.

## 최종 로컬 검사

전체 자동검사 1,050개 통과·실패 0개, 빌드 파일 검사 27개와 로컬 HTTP 검사 65개가 통과했다. 추가한 클라이언트 소스가 빌드 출력과 바이트 단위로 같은지도 확인했다. 원자료 파일은 변경하지 않았다. 배포·실제 제공기관·브라우저 검증은 별도 최종 기록으로 구분한다.
