# 서구온 v0.5.0 적용 안내

기존 `kebong-3/seogu-on` 저장소와 Vercel 프로젝트를 그대로 사용합니다. 이 파일 묶음은 로컬 구현본이며 운영 주소를 변경한 상태가 아닙니다.

## 1. ZIP 전체 내용 반영

기존 변경사항을 백업한 뒤 압축을 풀어 `index.html`, `classic.html`, `package.json`, `package-lock.json`, `vercel.json`, `src/`, `api/`, `server/`, `public/`, `scripts/`, **`vendor/`**를 기존 저장소 최상위에 반영합니다. ZIP 자체를 저장소에 올리는 것이 아닙니다.

`vendor/cesium-1.121.0.tar.gz`는 밝은 도시모형의 실행자료입니다. 빌드가 SHA-256을 검증한 후 `public/vendor/cesium/`을 복원합니다. 수백 개 실행파일을 직접 업로드할 필요는 없지만 vendor 압축파일은 빠뜨리면 안 됩니다. 키가 든 `.env.local`은 업로드하지 마세요.

별도 검토 브랜치를 사용하더라도 브이월드 인증은 실제 등록된 도메인에서 확인해야 합니다. 임의 Preview 주소가 Production 도메인과 같은 인증 결과를 보장하지 않습니다.

## 2. Vercel

Framework: Other / Node.js: 22.x / Build Command: `npm run build` / Output Directory: `dist` / Root Directory: 저장소 최상위.

이미 작동하는 `VWORLD_BROWSER_KEY`, `VWORLD_DOMAIN` 값을 유지합니다. 주제도는 `VWORLD_API_KEY`도 필요합니다. 키의 승인 서비스가 WMS/WFS를 포함하는지 브이월드에서 확인합니다. 환경변수는 Production에 적용하고 저장 후 최신 커밋으로 다시 배포합니다.

## 3. 버전 먼저 확인

`/api/city-config`의 version과 `/data/release.json`의 version이 둘 다 `0.5.0`이어야 합니다. configured=true는 환경변수 존재 여부이지 유효키·원자료 수신 성공을 뜻하지 않습니다.

## 4. 그림자 확인

실제 브이월드 건물이 보이는 상태 → 동 선택(예: 금호2동/치평동) → 계절·3D 그림자 → 겨울 → 09:00 → 3D 그림자 켜기 → 12:00 / 15:00 → 여름 순으로 비교합니다.

슬라이더를 바꿀 때 렌더러의 적용시각도 바뀌는지 확인합니다. `3D 렌더 프레임 확인`은 렌더링 한 프레임을 확인했다는 뜻이며, 모든 서구 건물에서 그림자가 정확히 보인다는 인증은 아닙니다. 원본 모형·지형 미수신, GPU, 카메라 거리와 그림자 해상도가 영향을 줍니다. 가까이 보기/그래픽 메뉴로 구도를 조정합니다.

`그늘 면 계산`은 기존 OSM 높이자료의 2D 근사 도형 기능입니다. 브이월드 3D 일영과 다른 기능입니다. 경계도·OSM 경량모드에서는 새 네이티브 일영을 실행하지 않습니다.

## 5. 주제도 확인

공식 주제도 → 재난·방재 → 재해위험지구 `이 도형만 보기` → 다른 주제도 `함께 보기`. 실제 수신이 되면 도형 수와 수신시각이 나옵니다. 처음부터 모든 데이터를 동시에 켜지 않습니다.

도형 API가 비어 있거나 지원 오류가 날 때 `지도영상 보기`를 별도로 시험할 수 있습니다. WMS 영상이 표시되는 것과 WFS 속성자료를 수집한 것은 다릅니다. 제공되지 않는 지역/기준일/범례는 원 제공기관에 확인합니다.

동을 선택해 수집하면 그 동 범위의 자료만 받습니다. 이후 서구 전체로 이동해도 그 동의 조회본을 전역 자료라고 표시하지 않습니다. 전체 범위로 다시 조회하거나 동별 결과를 검수하여 관리하세요.

## 6. 수집 결과 보관

`받은 자료 내보내기`는 현재 구역에서 수집 완료한 WFS 도형을 GeoJSON으로 저장합니다. 새로고침 후 서버 공통자료로 유지하는 기능은 아닙니다. 검수한 내보내기 파일은 기존 `자료 가져오기`로 다시 읽거나, 공통자료 반영 절차에 따라 저장소에 추가할 수 있습니다.

개발용 일괄 수집 명령은 API_SETUP.md의 `collect:vworld` 절을 참고합니다. 미완료 수집은 새 정상본으로 덮어쓰지 않습니다.

## 적용 완료로 보지 않는 항목

정밀 일조권·채광량, 침수심 예측, 산사태/화재 확산, 실시간 제설완료·현장 개방 상태, LoD4 건물 전수 확보와 사용자 계정의 인증은 이 ZIP의 자동 완료항목이 아닙니다.
