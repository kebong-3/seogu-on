# 서구온 v0.5.0 · 서구 한정 주제도와 계절별 3D 일영

2026-09-28. v0.4.1 전체 소스에서 이어서 수정한 로컬 배포용 구현본입니다. GitHub main 수정, Vercel 배포 또는 사용자 키 입력을 대신 완료한 상태가 아닙니다.

## 이번에 달라진 점

- `계절·3D 그림자`: 날짜·시간·대표 계절일과 Cesium 네이티브 일영 제어기를 연결했습니다. 한국시간을 실제 렌더러 시각으로 변환하고, 요청 ID에 맞는 렌더 프레임 응답을 표시합니다.
- 2D 그늘 면 계산 직후 네이티브 그림자를 끄던 기존 처리를 제거했습니다. 2D 근사 계산과 3D 시각적 그림자는 서로 다른 기능으로 유지합니다.
- `공식 주제도`: 공식 WMS/WFS 레퍼런스에서 식별자를 확인한 66종을 검색·분류·서구/동별 조회합니다. 도형만 보기, 함께 보기, 제공기관 지도영상(WMS), 순차 수집, 취소, GeoJSON 내보내기를 구현했습니다.
- `재난·생활안전`: 호우·하천 / 급경사·산림 / 폭염·그늘 / 한파·제설 / 화재·산불 / 어린이·보행의 6개 조합과 자료상태 표를 제공합니다. 재난 위험등급 점수는 만들지 않습니다.
- 소유자 등 불필요한 원본 속성은 서버 허용 목록에서 제외합니다. 보호시설 거주지 등 민감 위치를 이번 공개 주제도 묶음에 추가하지 않았습니다.
- 기존 18개 동, 도시게임형 카메라, 인프라 단독 선택, 기상·미세먼지, 제설 작성·저장·복원, 가상 GLB, 지형 표본 도구를 유지했습니다.

## 데이터 수신과 구현을 구분합니다

66개는 실제로 공간자료를 받은 개수가 아니라 **공식 API 식별자를 연결한 주제도 수**입니다. 기본 공원·학교·생활시설·행정경계·OSM 건물은 이전 공개본을 유지했습니다. 이번 작업에서 새 브이월드 공간도형을 전량 수집하지 못했습니다.

복구한 2026-09-27 공개조회 기록의 20개 주제도는 모두 `request-unavailable`였습니다. 브이월드 포털의 412개 메뉴와 이번에 확인한 WMS/WFS 문서의 169종은 서로 같은 목록이 아닙니다. 명세에 없는 API 식별자나 LoD4 모델 다운로드 주소를 추측하지 않았습니다.

실제자료 수신은 배포 후 본인의 승인된 `VWORLD_API_KEY`와 등록 도메인으로 실행합니다. 목록 카드는 미조회/수신/0도형/갱신실패/다른 동 조회본을 구분합니다. 최신 원본 기준일이 없으면 수신 날짜로 대체하지 않습니다.

## 시험 범위

새 소스 기준 문법검사, 단위시험 327개, 기존 UI 59개, 기록작성 UI 22개, 신규 UI 34개, 배포물 12개, 로컬 HTTP·정적파일 33개 검사를 통과했습니다. 화면은 실제 앱·실제 포함자료의 2D 경계도이며 외부 API 응답은 시험용입니다. 현재 제작환경에서 WebGL이 초기화되지 않아 새 소스의 VWorld 실렌더링·화질·GPU 그림자·실사용 인증은 미검증입니다.

과거에 회수된 별도 WebGL 결과는 합성 상자 장면을 대상으로 한 이전 제어기 시험입니다. 최신 코드의 실제 서구 검증으로 합산하거나 화질 전후 사진으로 사용하지 않았습니다.
