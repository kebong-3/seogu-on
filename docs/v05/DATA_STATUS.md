## 4. 수신 후 화면이 보증하는 범위

WFS는 선택 동 또는 서구 경계의 외접사각형으로 요청한 후, 반환 도형을 실제 행정경계로 절단합니다. 고유번호·좌표계·페이지 수량을 검사하고 원본 속성을 허용 목록으로 제한합니다. 모든 페이지가 정상 완료되어야 이전본을 교체합니다. 중간 실패·취소·동 변경·반복 페이지·갑작스러운 0도형은 기존 정상본을 지우지 않습니다.

`수신됨`은 API가 반환한 자료를 받았다는 뜻이지 현장 점검 완료가 아닙니다. 제외 항목 수를 별도로 표시합니다. 도형이 잘려 여러 조각이 되거나 시설 하나가 여러 도형으로 구성될 수 있습니다. 원본 기준일이 없으면 미제공으로 남겨두고 수신시각만 별도로 기록합니다.

WMS는 제공기관의 지도영상입니다. 범위 외 픽셀은 화면 마스크로 가리며, 픽셀 색을 임의의 위험점수·안전등급으로 바꾸지 않습니다. 지도영상만으로 개별시설 목록·면적 통계·위험구역 포함 여부를 추정하지 않습니다.

## 5. 이번 공개 묶음에서 제외하거나 별도 연계한 항목

LoD별 원본 입체모형·실감영상 다운로드, 비공개 보호시설 거주지, 원본 토지소유자 정보, API 식별자를 확인하지 못한 산사태위험지도는 자동 수집 대상으로 만들지 않았습니다. 산림입지도와 급경사 지정구역을 산사태 예측지도라고 부르지 않습니다.

무더위쉼터·기상·미세먼지·공개 교통CCTV 영상은 별도 제공기관의 API입니다. VWorld의 3D 지도가 보이는 것만으로 이 서비스들의 인증까지 완료되지는 않습니다. 통학 관련 자료명은 공식 명세의 '초등학교학교군'을 보존하며 입학 배정 확정자료로 해석하지 않습니다.
