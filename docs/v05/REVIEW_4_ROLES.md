## 최종 결정

새 메뉴를 많이 보여주는 것보다 실제로 받은 범위를 설명하는 쪽을 선택했습니다. 기본공개본은 보존하고, WFS로 받은 점·선·면과 WMS지도영상을 분리합니다. 재난상황 버튼은 자료 조합이지 재난 예보가 아닙니다.

그림자의 시각적 표현은 VWorld가 브라우저에 제공한 모형에 적용합니다. LoD4전체 원본 다운로드, 민간 건물 내부의 조도, 총/연속 일조시간, 법적 일조권 판정은 구현한 것처럼 표시하지 않습니다.

최종 코드와 시험은 로컬 ZIP으로 전달합니다. 이전 GitHub 쓰기 시도가 차단된 경로를 우회하여 업로드하지 않았고 이번에 main/운영배포/권한/키를 변경하지 않았습니다.
