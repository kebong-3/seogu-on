# v0.5 출처와 반영 범위

확인일: 2026-09-28. 원문 설명·첨부 예제의 주장과 이번 프로그램의 판단을 구분합니다.

## 공식 웹 명세

1. 브이월드 WMS/WFS API2.0 레퍼런스: https://www.vworld.kr/dev/v4dv_wmsguide2_s001.do
   - 서비스 목록169종, 소문자 WMS/WFS/스타일명, 인증키·도메인, EPSG:3857, WFS2.0 count/startindex/GeoJSON 출력 명세를 확인했습니다.
   - 이번66종의 카탈로그 근거입니다. 현행 서구 공간도형 수신을 보증하는 자료는 아닙니다.
2. Cesium ShadowMap: https://cesium.com/learn/cesiumjs/ref-doc/ShadowMap.html
   - Viewer의 그림자 거리·소프트 그림자·명암·사용 설정. 원본 모형/지형이 없는 부분은 이 설정으로 복원되지 않습니다.
3. Cesium Simon1994PlanetaryPositions: https://cesium.com/learn/cesiumjs/ref-doc/Simon1994PlanetaryPositions.html
   - 지정 일시 태양 위치 계산. 이 함수 하나가 건물 차폐·총일조시간을 계산하는 것은 아닙니다.
4. Cesium Viewer / Clock / SunLight: https://cesium.com/learn/cesiumjs/ref-doc/Viewer.html / https://cesium.com/learn/cesiumjs/ref-doc/Clock.html / https://cesium.com/learn/cesiumjs/ref-doc/SunLight.html
   - 공개 렌더러 시계·광원·그림자 설정을 사용합니다. 이번 VWorld에 모든 속성이 동일하게 노출된다는 보장은 하지 않고 지원 여부를 검사합니다.
5. Vercel 환경변수: https://vercel.com/docs/environment-variables
   - 새 배포의 Production/Preview 환경과 제공기관 도메인 등록을 별도로 확인합니다.

## 사용자가 제공한 자료

- VWorld 일조권 화면과 알고리즘 설명 이미지: 사용자가 원하는 계절·시간별 변화, Simon1994 태양 위치 및 광선-건물/지형 교차라는 설명을 확인했습니다. 포털의 총/연속 일조 분석 API 호출 명세까지 이미지에서 확인한 것은 아닙니다.
- `화면 내 CCTV 조회(2).html`: 화면과 상대경로의 hls.js/index.js 호출이 있습니다. 그 두 로컬 실행파일을 제공받은 것으로 취급하지 않습니다.
- `날씨 & 미세먼지 — 3D 통합(2).html`: 기상청·에어코리아와 3D마커 구성 참고. 원문에는 위경도를 반올림해 기상격자로 쓰는 부분, 측정소명을 지명에서 추측하는 부분, 결측을 보통으로 표현하는 부분이 있습니다. 우리 앱은 각각의 기존 수정 경로를 유지했습니다.
- `전국 무더위쉼터 생활안전 지도(1).html`: 쉼터·응급의료·기상 서비스의 원본 연결 구조를 참고했습니다. 현재 운영/수용 가능 여부는 기본 등록정보만으로 확정하지 않습니다.
- `침수·홍수 지점 위험도 분석기(2).html`: 국가/지방하천범람·침수흔적·도시침수(30년빈도) 4개 지도 구조를 참고했습니다. 원문은 감지된 픽셀에 가중치를 더해 위험점수를 만듭니다. 검증된 위험모형 근거는 첨부에서 확인되지 않아 우리 앱에서는 그 점수/등급을 사용하지 않았습니다.
- `실시간 교통정보·교통안전 지도(2).html`: ITS와2024사고다발지역 구조 참고. 원문 기준연도를 그대로 드러내며 새 현황으로 바꾸지 않습니다.
- `건축부지 입지분석 프로토타입(2).html`: 브이월드 지형단면·경사·가상건물 경로를 참고했습니다. 원문 입지점수를 검증된 행정판정으로 도입하지 않았습니다.

첨부에 포함된 인증키는 사용/복사하지 않았습니다. 공식 API로 제공되는 범위와 이용조건을 확인하며, 사이트 전용 내부엔드포인트·제3자 인증키를 이용한 원본 메시 추출은 하지 않았습니다.

66주제도 화면/서버 정규화와 전페이지 검증, 행정동 절단, 재난상황 6조합, 네이티브 시계/빛/그림자 복원, 최신요청 우선 처리, 검수대기 수집CLI, 시험과 보고서는 이번 프로젝트 코드입니다. 공식 제공기관이 이 구현을 검증/인증했다는 의미는 아닙니다.
