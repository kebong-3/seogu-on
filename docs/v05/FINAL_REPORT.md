# 서구온 v0.5 통합 마감 보고

2026-09-28 · 전달 파일: seogu-on-v0.5-final.zip

## 이번 작업 결과

v0.4.1 전체 소스에서 계절·시간별 네이티브 3D 그림자, 서구 한정 주제도66종 조회, 재난·생활안전 상황별6개 자료 조합을 통합했습니다. 파일은 로컬에서 작성·검사했으며 GitHub main·Vercel Production·환경변수는 변경하지 않았습니다.

특히 기존 2D 그늘 계산 뒤 3D 그림자를 끄던 처리를 제거했습니다. 새 '계절·3D 그림자'는 날짜·시간 입력과 실제 렌더러 시계를 연결하고 요청 ID별 렌더 프레임 응답을 표시합니다. 원래 조명·시각·그림자 설정으로 되돌리는 기능도 추가했습니다. 실제 수신된 모형과 해당 SDK의 공개 그림자 기능에 의존하므로 배포 후 실제 건물 그림자는 별도 검증해야 합니다.

## 자료 연계

- 공식 WMS/WFS 레퍼런스에서 확인한66식별자: 재난·방재7 / 하천·환경17 / 도시·시설17 / 교육·생활11 / 교통·보행10 / 경계·토지4.
- 선택한 종류만 보기, 여러 자료 함께 보기, WMS 원본 지도영상, 서구/18동별 절단, 순차수집·중지·GeoJSON내보내기 구현.
- 기존 공원·학교·생활시설·행정경계·OSM모형 유지. 이번에 새로운66공간데이터를 모두 수신한 것이 아님.
- 본인 승인키로 대량 조회할 명령을 추가하되 검수 전 파일은 data-staging/에 두고 자동 공개하지 않음.
- 호우·급경사·폭염·한파·화재·어린이보행 상황판은 필요한 자료의 조합과 수신상태를 표시. 위험점수·재난안전 확정판정은 제공하지 않음.

## 최종 검증

문법검사 통과, 단위327/327, 기존화면59/59, 기록작성화면22/22, 신규화면34/34, 배포물12/12, 로컬HTTP33/33. ZIP빈폴더 재검사와 로컬SDK375파일 복원·빌드 통과. 실행 소스와 기본자료의 해시 일치 확인. 첨부6개 HTML에서 추출·정규화한 인증값6개에 대해 전달자료 일치파일0, 글꼴파일0 확인.

화면검사는 실제 앱의2D경계도이며 API는 시험용 응답입니다. 현재 환경의 WebGL초기화가 실패하여 최신 소스의 실제3D화질·브이월드 그림자·GPU성능은 미검증입니다. 과거 합성상자 WebGL실험은 이번 실제서구 결과로 합산하지 않았습니다.

## 적용

기존 저장소 최상위에 압축 내용 전체(특히 vendor/)를 반영하고, 작동하는 브이월드 키를 유지합니다. Production 환경변수를 확인한 뒤 새로 배포합니다. /api/city-config 와 /data/release.json 의버전0.5.0확인 → '계절·3D그림자' → '공식주제도' 순으로 점검합니다.

상세 문서는 DEPLOY.md, API_SETUP.md, DATA_STATUS.md, TEST_REPORT.md, SOURCES.md 순으로 확인합니다.
