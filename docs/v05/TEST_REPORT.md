UI시험은 실제 애플리케이션을 로드하지만 지도는 **2D BoundaryView**입니다. WFS·기상·제설 등 외부 응답은 명시적 시험자료를 사용했습니다. 시험용 위험구역이나 가상 측정값은 public 기본자료에 넣지 않았습니다. 합계 수를 실제 지도·실제 API 인증 성공 건수로 표현하지 않습니다.

`tests/v05.test.mjs`에는 네이티브 시간동기화·그림자 상태 원상복원·마지막 렌더 응답·한국시간·미지원 SDK·공개 속성 검사, WFS 좌표계/페이지/반복/외부구역/속성제한, 과거 정상본 보존 검사가 포함됩니다. 모의 SDK 객체 시험은 실제 GPU 픽셀 검증의 대체가 아닙니다.

## 실제 GPU 및 운영 인증

이 환경에서 3개 Chromium 렌더 설정을 확인했지만 WebGL 초기화가 모두 실패했습니다. `WEBGL_PROBE.json`에 결과를 그대로 보존했습니다. 새 소스의 실제 VWorld 건물·지형 그림자, 밝은 도시모형의 GPU 렌더링, LoD 전환·FPS·새 화질은 검증 완료가 아닙니다.

이전 작업의 회수된 11개 WebGL 결과는 이전 태양 제어기와 **합성 상자 장면**으로 만든 결과입니다. 실제 서구 그림자나 이번 최종 소스 검증으로 합산하지 않았습니다. 과거 VWorld 네트워크 실패도 성공으로 바꾸지 않았습니다.

사용자 키에 대한 서비스 승인·인증·실제 WFS/WMS 공간자료, 기상청·에어코리아·무더위쉼터·ITS·홍수 API 실수신, Vercel 배포/함수 번들을 이번 로컬 시험으로 검증하지 않았습니다. API 식별자66종 확인은 실제 제공범위·최신성·전수성 검증과 다릅니다.

## 원인 확인 및 수정

1. 기존 2D 그늘 계산 후 `shadows:false`를 보내던 경로 제거.
2. 날짜·시간 입력을 네이티브 3D 조명/시계와 연결. 시간 슬라이더 변경 시 재적용.
3. SDK 초기화 뒤 마지막 선택을 적용하고, 고유 요청 ID가 일치하는 렌더 프레임만 화면에 반영.
4. 그림자 렌더 거리를 카메라 범위와 연결하되 성능을 위해 상한 적용.
5. 켜기 전에 시계·빛·그림자 설정을 보관하고 끄기/종료 시 복원.
6. WFS 전 페이지 완료·좌표계·범위 절단·원본 ID·부분실패 보존. 미조회와 0반환을 분리.
7. 주제도별 원본 속성·수신시각·제외 항목·동별 수집범위 표시.
