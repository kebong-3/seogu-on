# 0.13.0 · 생활도보길

2026-10-27. 교통정보를 조회하던 탭을 생활도보길로 바꾸고, TMAP 보행자 경로를 실제 공개시설의 방문·점검에 연결했다.

- 하단 교통 탭 제거. 돌발상황·공개 교통CCTV·소통·사고다발구역 API는 일반 표시 메뉴에서 숨겼다. 스쿨존·횡단보도·결빙 등 보행 관련 자료는 유지했다.
- 그늘·쉼터 경유, 경찰시설 경유, 돌봄 방문, 최대 3시설 현장점검의 네 가지 목적을 제공한다. 직접 경로와 최대 두 단일 경유안의 TMAP 거리·시간을 비교한다. 점검 경유지는 선택 순서를 따른다.
- 실제 공개시설 예시 또는 지도에서 출발·도착을 선택한다. 경로 조회는 비교 버튼을 눌렀을 때만 수행한다. 계단 제외 옵션과 점검 체류시간 가정은 보행시간과 구분한다.
- 그늘막 지점 경유를 시간별 그늘 최적화로, 경찰시설 경유를 범죄위험·안전 인증으로 표현하지 않는다. 화장실에 설치된 비상벨 62개는 경유지에서 제외한다.
- TMAP 키는 서버에서만 읽는다. 같은 출처의 JSON 요청, 등록 지역의 실제 경계, 후보 유형·ID, 중복 위치, 10km, 시간·크기·호출 한도를 검증한다. 제공기관 실패를 직선 경로로 바꾸지 않는다.
- 결과는 최대 30분간 메모리에 표시한다. 도보선은 기존 자료·보고서·CSV·브라우저 영구저장과 분리했다. 지우기·만료 때 지도 내부 도형도 빈 배열로 교체한다.
- 서버리스 함수를 추가하지 않고 기존 단일 처리기에 `/api/walk-routes`를 연결했다. 서구·순천은 서로의 공개시설을 섞지 않는다.

설정과 자료 범위는 [생활도보길 안내](WALK_ROUTES.md), [API 설정](API_SETUP.md)을 참고한다. 원문 대표좌표는 현장 검수한 보행 출입구가 아니며 시설의 현재 개방·작동·방문 허용은 별도 확인한다.

검증: 전체 자동검사 819개 통과, 빌드 항목 27개·로컬 HTTP/배포구성 항목 66개 통과. 최종 생명주기·시설 재조회 수정은 관련 회귀검사 77개를 추가 실행해 모두 통과했다. 테스트의 TMAP 응답은 모의 자료이며 운영 인증·실경로 수신과 구분한다. 로컬 브라우저 미리보기 경로는 연결 거부로 검증하지 못했으며 배포 후 실제 화면을 별도 확인한다.
