# 0.14.0 · 시간별 그늘과 겨울철 보행안전

기존 시설 경유 비교에 건물 높이·태양방향 모형을 연결한다. 여름에는 선택 출발시각 또는 이동시각의 그늘을, 겨울에는 같은 날짜의 09~16시 일조 부족과 공개 결빙관리지점 주변 통과거리를 각각 표시한다. 실제 TMAP 후보만 비교하며 사용자의 추가 거리·시간 조건을 모두 적용한다.

## 변경

- 여름 그늘길·겨울철 보행안전 목적, 한국시간 일시, 500m/5분 기본 우회 조건, 층수×3m 추정 포함 선택.
- 실제 경로 선형을 따라 20m 표본을 평가하고 그늘·햇볕·미확인 및 겨울 일조 상태를 지도 색으로 표시. 경로 굴곡을 보존한다.
- 높이미상·모형 밖·야간·낮은 태양고도는 미평가. 표시 전용 6m는 그늘 높이로 사용하지 않는다.
- 직접경로와 자료 범위가 충분하고, 미확인 구간까지 고려해 개선되는 실제 후보만 우선안으로 선택하는 비교기.
- 서구 OSM 5,779개 건물, 원자료 높이 태그 52개·층수 추정 2,217개·높이미상 3,510개. 현재는 완전한 평가범위 미확보로 우선안 선택을 보류한다.
- 공식 상습결빙 관리점 23개 주변 50m 거리 합집합. 점 사이를 임의로 이어 실제 도로·보도 결빙구간으로 만들지 않는다.
- 광주경찰청 2026년 8월 공식 여성안심귀갓길 지도 6개소의 사실 요약·원문 링크. 공식 좌표 미확보 상태를 명시한다.
- VWorld 기본 지도와 TMAP 호출·보관 한도 유지. 계절 계산 실패 시 확보한 일반 도보경로는 유지한다.

## 확인 범위

단위·통합 검사는 태양방향, 건물 높이 근거, 모형 범위, 겨울 시간창과 미확인 시간 상한, 관리점 근접거리 합집합, 유효일시, 우회 조건, 실제 경로 ID 연결, 지역별 자료 격리, 지도 구간 절단, 경로 만료와 삭제를 검증한다. 외부 제공기관의 현재 키 승인이나 현장 안전·효과의 검증은 아니다.

필요 자료·공식 출처·모형 가정은 [운영 안내](SEASONAL_WALKING.md)를 참고한다. 노면온도·수분·제설·현장 확인 없이는 현재 결빙 여부나 미끄러짐 확률을 산정하지 않는다.
