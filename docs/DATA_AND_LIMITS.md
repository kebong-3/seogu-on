# 자료와 한계

이 사이트는 공개자료로 만든 행정 검토용 시제품입니다. 공식 관제·재난대응 시스템이나 정밀 예측 모형이 아닙니다.

## 표시 원칙

- 받지 못한 값은 **미수신**, 응답에 값이 없으면 **미관측**으로 둡니다. 0이나 추정값으로 채우지 않습니다.
- 검증하지 않은 것을 검증됐다고 표시하지 않습니다. 화면과 내보내기의 "시연/미검수" 표시는 사실 검수가 끝나기 전에 지우지 않습니다.
- 출처·기준일·수신시각·공간단위·검수상태를 구분해 둡니다. 누락·오류를 "해당 시설 없음"으로 바꾸지 않습니다.
- 개인정보·비공개 행정자료·취약가구·민감한 거주시설 정보는 넣지 않습니다.

## 숫자를 읽을 때

- 기본 공개자료 325개(공원 87 · 주차장 67 · 공공 개방공간 58 · 도서관 83 · 지진대피 학교 30)는 **자료 항목 수**입니다. 건물 325동이나 전수 현황이 아닙니다.
- 공원 위치 87개와 OSM 공원 면 94개는 서로 다른 자료입니다. 더해서 공원 수로 쓰지 않습니다. 학교 위치와 학교 면도 같습니다.
- 서구 그늘막 199 · 쿨링포그 7 · 과거 침수피해 468은 원본 행 수 기준입니다. 같은 위치가 반복되므로 "침수 사건 468건"이 아닙니다. 침수 자료는 과거 기록이며 현재 위험등급이 아닙니다(`docs/v06/DATA_STATUS.md`).
- 공식 주제도 66종, 재난안전 API 10종, 공식 소스 60개는 **등록된 목록의 수**입니다. 실제로 받은 자료의 수가 아닙니다. 0.8.1에서 상습결빙구간 API를 목록에 추가했습니다.
- 상단 "재난 자료 n종"은 수신된 관련 지도층의 종류 수입니다. 위험도나 실시간 경보가 아닙니다.

## 관측값

- 기온·강수는 기상청 5km 격자의 대표위치 값입니다. 동 전체나 개별 건물의 실측값이 아닙니다.
- PM10은 서구 경계 안 에어코리아 측정소 한 곳의 값입니다. 다른 위치의 농도로 보간하지 않습니다.
- 서구 전체를 볼 때의 값은 "대표위치 격자 + 측정소 한 곳"이며 18개 동의 실측을 뜻하지 않습니다.

## 지도와 그림자

- 3D 그림자는 건물 모형에 조명 시각을 적용한 시각 표현입니다. 구름·수목·그늘막 자체의 그늘, 법정 일조권, 열환경 분석이 아닙니다.
- 2D 그늘 면은 높이값이 있는 일부 건물의 기하학적 근사입니다(`docs/v04/GRAPHICS_AND_SHADE.md`).
- 밝은 도시모형은 OSM 건물 도형을 입체화한 것으로 지형이 없고 높이 미상 건물이 있습니다.
- OSM 도로망은 보행 가능성과 그늘을 검증한 경로 자료가 아닙니다. 폭염 회피 경로를 자동으로 안내하지 않습니다.
- 동 이름표는 선택한 동을 우선 표시하고, 공간이 부족하면 일부를 숨깁니다. 확대·이동하면 다시 배치합니다. 이름이 숨겨져도 행정동 경계나 자료가 삭제된 것은 아니며 왼쪽의 BI·동 이름 카드로 선택할 수 있습니다. 숫자 배지와 번호표 범례는 사용하지 않습니다.

## 상습결빙구간

- 공식 API는 `DSSP-IF-00120`이며, 원자료 설명과 이용조건은 [재난안전데이터공유플랫폼(dataSn=111)](https://www.safetydata.go.kr/disaster-data/view?dataSn=111)을 기준으로 합니다. API 목록 추가나 `SAFETYDATA_00120_KEY` 저장은 실제 인증·자료 수신 성공을 뜻하지 않습니다.
- 서구 전체를 우선 대상으로 조회하고 전국 응답에서 지역명과 서구 행정경계를 검수합니다. 정상 조회 후 서구 자료가 없는 경우와 인증 실패·미수신·좌표 확인이 필요한 경우를 구분합니다.
- 원자료의 **지점 수**와 **서로 다른 구간번호 수**는 다릅니다. API가 대표점을 제공하면 그 점을 표시하며 여러 점을 이어 실제 도로 구간을 추정하지 않습니다. 별도로 확보한 공개 구간 도형은 해당 출처·기준일에 따라 읽어야 합니다.
- 등록된 상습결빙구간은 현재 결빙·통제·제설 완료 상태를 알려 주는 실시간 관측값이 아닙니다. 좌표가 확인되지 않은 자료는 지도 위치를 임의로 만들지 않습니다.
- 0.8.1 점검에서는 HTTP 200 응답 본문에 `resultCode: 32`(등록 IP 오류)가 확인됐습니다. 이를 정상 수신이나 서구 0건으로 표시하지 않습니다. 이후 배포·수신 상태와 직접 확보한 공개자료는 [0.8.1 변경·확인 기록](v081/RELEASE.md)에 구분해 기록합니다.

## 그 밖의 한계

- 응급의료기관 정보는 기본 등록자료입니다. 실시간 수용 가능 여부가 아니며 긴급상황은 119가 우선입니다.
- 필지 조회의 건폐율·용적률은 기존 건물의 속성일 수 있습니다. 인허가 가능 여부 판정이 아닙니다.
- 사용자가 가져온 파일과 검토 기록은 그 브라우저에만 있습니다. 서버에 저장하거나 다른 사람과 공유되지 않습니다.
- 서버의 캐시와 요청 제한은 함수 인스턴스 메모리에 있는 임시 기능입니다.
