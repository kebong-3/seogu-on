# 자료 구분과 해석 한계

## 제공 자료의 성격

| 대상 | 현재 상태 |
|---|---|
| 기본 웹지도 | 실제 OSM 지리정보를 외부 요청하도록 구현. 실제 수신 및 서구 제공범위 미검증 |
| 브이월드 | 실제 SDK 연결 코드를 제공. 키·도메인 승인·타일 로딩 미검증 |
| 디자인 미리보기 도시 | 자체 생성한 가상 건물·도로·공원·강. 실제 서구 도형 아님 |
| 초기 시설 48개 | 이름·좌표·12개월 실적을 생성한 합성 시연자료 |
| 초기 사업 6개 | 이름·선·기간을 생성한 합성 시연자료 |
| 실제 시설 기본 파일 | 빈 FeatureCollection. 확인하지 않은 실물을 꾸며 넣지 않음 |
| GeoJSON 가져오기 | 사용자 제공 자료로 표시. 스키마 검사 통과와 실제 내용 검수는 별개 |
| 공공데이터 API | 한 종류 시설 API의 1페이지 매핑. 행정구역 전체·실시간 수집 아님 |

사용자가 올린 스크린샷에서 실제 시설·건물·통계를 추출해 데이터베이스를 구축한 것이 아닙니다. 생성된 가상 도시 이미지·수치가 촬영된 원본 서비스의 자료와 일치한다는 의미도 없습니다.

## 시연과 실제 자료의 분리

기본은 시연 모드입니다. 스위치를 끄거나 실제 자료를 가져오면 합성 시설·실적과 혼합하지 않습니다. 합성 데이터 고유 문구는 화면·시계열·내보내기에 함께 기록합니다. API 수집이나 파일 불러오기 성공만으로 ‘검수 완료’로 승격하지 않습니다.

디자인 미리보기에서 실제 자료를 가져오더라도 배경은 계속 가상 도시입니다. 실제 위치 해석은 기본 웹지도 또는 유효하게 연결된 브이월드에서만 확인해야 합니다. 카메라 중심점은 광주 서구를 향하도록 설정했으나, ‘상무권역·농성권역·풍암권역’ 바로가기는 카메라 프리셋일 뿐 행정동 경계 선택이 아닙니다.

## 계산의 범위

- **반경:** 경위도 사이의 구면 직선거리입니다. 도로·보행망·실제 출입구·경사·접근제한·법정 서비스 범위를 계산하지 않습니다.
- **가상 시설:** 지정 위치 주변의 등록자료 수를 조회합니다. 신규시설의 수요·효과·적정성·우선순위를 예측하지 않습니다.
- **사업 근접:** 사업 도형 좌표의 평균으로 만든 대표점 간500m 이내이고 일정이 겹치는 쌍입니다. 실제 공사구역 중첩·영향 범위·충돌을 확정하지 않습니다. 실사업 자료 가져오기는 미구현입니다.
- **월별 합계:** 조회조건의 값이 있는 시설만 더합니다. 결측을0으로 바꾸지 않습니다. 0은 실제 입력된 숫자0으로 유지합니다.
- **전월비교:** 두 달 모두 값이 있는 동일 시설 집합에 한합니다. 같은 시설이어도 운영기간·정의가 달라졌는지는 별도 검토해야 합니다. 분모가0이면 증감률은 표시하지 않습니다.
- **지표 혼합:** 이름 또는 단위가 다른 지표는 합산과 기둥을 중단합니다. 같은 이름·단위라도 의미가 다를 수 있어 원자료 정의를 확인해야 합니다.
- **통계기둥:** 눈에 잘 보이도록 값에 비례하는 시각적 높이와 최소 높이·상한을 적용합니다. 0도 선택 가능한 작은 형태로 보일 수 있습니다. 값은 패널·차트에서 확인하세요. 실제 건물 높이나 물리량이 아닙니다.
- **시간축:** 입력된 월별 키 중 최근 최대24개월을 표시합니다. 초기 시연에는2026년12개월이 있으나 미래를 예측한 값이 아닙니다.

## 범위와 표시 제한

시설 파일: 2MB 이하, 최대5,000개. Point/EPSG:4326만 지원합니다. 좌표 순서는 `[경도, 위도]`입니다. 주소만 있는 파일, EPSG:5179·5186 투영좌표, SHP·Excel을 직접 변환하지 않습니다.

지도는 시설 최대1,000개(브이월드500개), 통계기둥500개까지 표시합니다. 시설 표는300개까지 보이고 CSV에는 조회조건을 만족한 전체 자료가 포함됩니다. 표시 제한이 적용되면 지도 설명에 안내합니다. 브라우저 성능은 기기·자료·지도 공급 상태에 따라 달라지며 성능보장은 하지 않습니다.

API는 원본1페이지 최대1,000건이며 응답2MB 제한을 둡니다. 원본 전체건수와 비교해 일부인지 표시하고 전체건수를 알 수 없으면 부분수집으로 취급합니다. 좌표 필터는 광주 주변의 사각형이므로 서구만을 정확히 선별하지 않습니다. 현재 UI에서 지도를 이동한다고 집계지역이 자동 변경되는 것은 아닙니다.

## 현장 검수용 확인표

실자료를 연결할 때 ID 중복, 주소·좌표 일치, 실제시설 존재, 운영·폐지 상태, 조사 기준일, 이용허락·출처 표시, 월별 정의, 누락·제외 수, 행정구역 코드와 경계를 대조하세요. 일부 자료의 수집이 끝났다고 행정구역 전체 시설이 확보되었다고 표현하면 안 됩니다.

공공시설별 값은 수요를 전부 설명하지 않습니다. 시스템은 시설 부족, 효율성, 정책효과, 예산 우선순위를 자동 판정하지 않습니다. 최종 검토는 담당자가 추가자료와 현장 여건을 함께 보고 수행합니다.

## 아직 없는 기능

실시간 센서/민원/새올 연결, 주민 개인위치·CCTV 영상, 자동 수집 스케줄, 실제 생활인구·건물별 인구 추정, 관리자 계정, 원격 공동 편집, 침수·일조·열환경·교통 예측, LLM 질문응답·학습은 포함하지 않았습니다. 이번 파일은 확장 가능한 공개 시제품 기반입니다.
