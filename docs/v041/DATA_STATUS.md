# 실제 자료·아직 연결할 자료

## 이번 버전의 추가 확인

기본 인프라/OSM 건물 도형은0.4에 포함된 공개본을 유지했습니다. 전체 서구 시설을 새로 전수수집했다고 주장하지 않습니다. 자세한 분류별 수량은 `../v04/DATA_CATALOG.md`, 원본/제외사유는 `../v04/DATA_AUDIT.json`에 있습니다.

**행정복지센터:** 점11·면7의 원래 형태를 그대로 유지하면서18개 행정동의 명칭과 대조했습니다. 서로 다른18개 동 명칭에 하나씩 대응했습니다. 위치·이전 여부를 현장검수한 결과는 아닙니다. 대조표 `public/data/city/civic-index.json`의 `fieldVerified`는 false입니다. 다른 자료층의 점/면도 일반적으로 합산할 수 있다는 뜻은 아닙니다.

**주소 검수 대기:** 기존32개 공개주소에 서구장애인복지관 임시이전 안내1건을 추가해33건입니다. 공식 주소는 ‘서구 상무대로1032’이며 좌표를 만들어 넣지 않았습니다. 안내를 확인한 날짜와 시설 이전 시행일은 다르므로 `sourceDate`는 null입니다. 공식 안내: https://www.bjsk.kr/page/intro/location . 서버 주소변환은 본인 VWorld REST 승인키가 있어야 하며 후보를 확인한 뒤 사용자 등록자료로 반영합니다. 주소 대기33건은 이미 지도에 있는33개 시설이라는 뜻이 아닙니다.

## 포함된 대표 자료층

공원87위치/94면, 학교52위치/52면, 도서관83위치/4면, 체육시설14위치/110면, 유치원18위치/7면, 어린이집10위치/7면, 공연·문화6위치/5면, 주차67위치/287면 등입니다. 서로 다른 기관 수로 합산하지 않습니다. 학교위치는2026-03-20 표준자료, 다수 면은 OSM 부분자료이며 공인 시설대지 경계와 같다고 보장하지 않습니다.

무더위쉼터·기상·PM·응급기관·교통 등은 종류별 승인 API가 필요합니다. 한파쉼터·적사함·그늘막·제설 작업구간·공식 복지/영유아 전수대장은 아직 완비되지 않았습니다. ‘연결 필요’는 시설이 없다는 뜻이 아닙니다. 과거2019년 어린이집246행과 쉼터 운영자료를 최신 시설 목록으로 재사용하지 않았습니다.

## 그늘자료

건물 도형5,779개 중 원본 height태그52개, 층수추정2,217개, 높이미상3,510개입니다. 기본 그늘 계산은 height태그52개, 층수×3m는 사용자 선택 때만 포함, 높이미상은 제외입니다. 밝은 도시모형의 미상높이 표시용6m는 그늘 계산의 높이가 아닙니다.

계산은 부분 건물도형·수직벽·평탄지면 가정입니다. 나무·차양·실제 지형·구름을 포함하지 않으며 자료 없는 곳을 일사구간으로 단정하지 않습니다. 건물 외관이 선명하다고 예측 정확도가 자동으로 높아지는 것도 아닙니다.

## 제설기록

이번에 새로 보이는 제설선은 담당자가 검수한 공개 자료를 직접 그리거나 가져와야 합니다. 실재하지 않는 노선·작업차량·완료 현황을 기본자료로 생성하지 않았습니다. 시간과 출처가 있는 기록만 그 근거대로 표시합니다. localStorage는 현재 브라우저/서비스 주소별 저장이며 다른 직원에게 자동으로 공유되지 않습니다.
