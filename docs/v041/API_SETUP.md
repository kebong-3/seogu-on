# 서구온0.4.1 — API·자료 연결

## 먼저 유지할 브이월드 값

```text
VWORLD_BROWSER_KEY = 본인 WebGL3D 사용 승인키
VWORLD_DOMAIN = https://seogu-on.vercel.app
VWORLD_API_KEY = 본인 주소·검색·데이터 사용 승인키
```

`VWORLD_API_KEY`는 앱 서버가 읽는 변수 이름이며 반드시 별종의 키를 새로 받아야 한다는 뜻은 아닙니다. 한 키의 두 용도 사용 가능 여부는 승인 서비스/도메인 조건에 따릅니다. SDK키는 브라우저에 전달되므로 제공기관 도메인 제한을 적용합니다. 예제 HTML의 키를 복사해 쓰지 않습니다.

## 날씨·미세먼지

| 변수 | 필요한 서비스 | 표시 방식 |
|---|---|---|
| KMA_SERVICE_KEY | 기상청 단기예보 조회서비스 | 대표위치를 기상격자로 변환, 실황·예보시각을 별도 표시 |
| AIRKOREA_SERVICE_KEY | 에어코리아 측정소정보 + 대기오염정보 | 반환된 측정소 좌표와 PM값/관측시각/점검플래그 |
| DATA_GO_KR_SERVICE_KEY | 승인된 서비스의 공통 대체키 | 각 서비스 활용승인 필요; 한 키로 모든 서비스가 자동승인되지 않음 |
| AIRKOREA_REGION_QUERY | 측정소 조회의 지역 문자열 | 기본 광주. 실제 제공기관 반환범위를 대조 |

기상청: https://www.data.go.kr/data/15084084/openapi.do
에어코리아: https://www.data.go.kr/data/15073861/openapi.do
측정소정보는 `MsrstnInfoInqireSvc/getMsrstnList` 서비스 권한도 확인합니다.

키를 Vercel Production 환경변수에 저장한 뒤 새 배포에서 ‘기후·그늘 → 날씨 실황 지도 / 미세먼지 관측 지도’를 실행합니다. 설정값 인식과 실제 인증·자료 수신은 별도 검사입니다. 기존 값이 있는 상태에서 갱신 실패하면 원래 관측시각과 이전값을 보존합니다. 처음부터 값이 없으면 미연결/오류로 표시합니다.

## 다른 인프라·안전 서비스

무더위쉼터 `SAFETYDATA_SERVICE_KEY`, 응급기관 `EMERGENCY_SERVICE_KEY`, 교통 `ITS_API_KEY`, 생활안전지도 `SAFEMAP_SERVICE_KEY`, 홍수지도 `FLOODMAP_SERVICE_KEY`, 사고자료 `TAAS_SERVICE_KEY` 등 기존 변수를 유지합니다. 세부명세는 `../v03/API_SETUP.md`를 참고합니다. 기본2024 사고자료를 현재 실시간 위험도로 표시하지 않습니다.

추가 공개JSON API는 `INFRA_SOURCES_JSON`에서 실제 endpoint/열이름/고유번호/좌표 또는 도형/출처/기준일을 지정합니다. 완성되지 않은 가짜 endpoint를 기본 연결에 넣지 않았습니다. 예시는 `../v04/API_SETUP.md`에 있으며, 대문자 자리표시자를 실제 승인명세로 바꿔야 합니다. 인증키 자체는 JSON에 넣지 않고 `keyEnv`로 변수명을 참조합니다.

## 키 없이 사용할 관리자료 경로

‘제설·겨울 관리 → 지도에서 직접 작성’은 조회API가 아니라 담당자가 확인한 공개 작업기록 입력입니다. 제설/검토구간, 적사함, 한파쉼터, 그늘시설을 그려 출처·시각·상태를 등록합니다. 도형이 없는데 좌표를 자동으로 꾸며내지 않습니다. 빈 시각은 상태미확인으로 남깁니다.

‘기록 보관함’에서 명시적으로 브라우저에 저장/복원하거나 JSON백업·GeoJSON파일로 내보낼 수 있습니다. 다른 직원과 공유하려면 검수한 자료를 공통 공개자료파일에 반영하고 재배포하거나 승인API로 연결해야 합니다. 누구나 서버 공통자료를 덮어쓰는 기능은 없습니다.

## 공개주소 검수

인프라 찾기 → 공개시설 주소검수 → 등록된 주소 조회 → 좌표후보 확인 → 현재 지도 반영입니다. REST키가 필요하며 이름만 입력해 임의 외부주소를 무제한 조회하는 공개 프록시가 아닙니다. 원자료·좌표를 확인한 결과는 사용자 확인자료이지 측량검수가 아닙니다. 주소정보만 최신이고 좌표가 없는 항목은 지도에 자동 등록하지 않습니다.
