# 서구온 0.4.1 마감 수정·4개 역할 검토

검토일: 2026-09-27. 기준 파일은 전달했던 `seogu-on-v0.4.zip`입니다. 아래 네 역할은 같은 구현물을 다른 관점으로 나눠 순차 교차 검토한 기록입니다. 별도 자율 에이전트 네 개를 실행하거나 독립 회의를 진행했다는 의미는 아닙니다.

## 1. 그래픽·지도 상태

발견: 사용자 선택마다 바뀌지 않은 자료까지 iframe으로 다시 보내 도형을 지우고 재생성했습니다. 이는 불필요한 렌더 작업을 만듭니다. 또 지도 초기화 도중의 마지막 선택을 일관되게 보존할 필요가 있었습니다.

수정: `LayerSync`로 실제 데이터/범위/선택이 바뀔 때만 도형을 보내고 표시 여부만 바뀌면 상태만 전송합니다. `PendingMessages`는 초기화 중 마지막 카메라·레이어 상태를 합치되 사용자 작업 명령을 별도로 보존합니다. 독립 밝은 모형은 필요 시 렌더하도록 변경했습니다. 이는 호출·재생성 경로 개선이며 FPS 개선 수치를 측정한 것은 아닙니다.

주신 VWorld 예제에서 `facility_build`, `facility_build_all` 공개 레이어 전환을 확인하여 상세/기본 모델 요청을 추가했습니다. 지원되는 getter와 show/hide만 사용하고 새 레이어 show가 성공한 뒤 이전 레이어를 숨깁니다. 미지원·예외이면 기존 건물을 유지합니다. 요청 성공은 실제 상세 타일 수신·정밀도·화질 만족도의 보증이 아닙니다.

품질 설정은 고해상도 단말에서 가벼운 모드가 오히려 과도한 배율을 적용하던 부분을 수정했습니다. 실제 캔버스 크기·배율·렌더 프레임·오류를 보고하는 점검창을 추가했습니다. 브이월드에 없는 원본 외벽/지형 해상도를 AI로 만들어 넣지 않았습니다.

## 2. 인프라·자료 검수

학교·공원·문화·돌봄 등34분류의 단독선택/명시적 복수선택, 실제 면/위치 구분, 18행정동 필터와 목록·CSV 연결을 재검사했습니다. 점·면 건수가 우연히 같아도 일대일 기관 대응이라고 단정하지 않습니다.

포함된 행정복지센터 점11·면7을 이름으로 다시 대조한 결과 서로 다른18개 동 명칭에 하나씩 대응함을 확인했습니다. `civic-index.json`과 ‘18개동 센터 대조’ 목록에 결과를 표시했습니다. 현장 위치/이전 여부는 미검수로 남깁니다.

서구장애인복지관 공식 이전 안내의 공개 주소를1건 추가해 주소 검수 대기 목록은33건입니다. 공식 안내가 없는 좌표나 이전 시행일을 만들지 않았습니다. 기존 서버의 등록주소 전용 조회로 후보를 받고 사용자가 원자료·위치를 확인한 뒤 현재 화면에 반영하도록 했습니다. 사용자 키를 통한 주소변환 실수신은 미검증입니다.

## 3. 기후·그늘·제설

발견: 그늘 재생에서 계산된 시각보다 UI 시간 표시가 앞서 이동할 수 있었습니다. 제설 상태를 다시 평가할 때 원래 보고값이 사라지고 파생 상태만 남는 경로도 있었습니다.

수정: 그늘 시간 변경은 짧게 지연해 최신 요청을 계산하며, 계산 중 이전 시각의 그늘을 숨깁니다. 재생 단계와 표시시각을 맞췄습니다. 기존 기하학적 근사/자료 누락 한계는 그대로 표시합니다.

기상·PM 요청 실패 시 이전 관측값과 원래 관측시각을 보존하고 실패 상태를 별도로 표시합니다. 선택 지역 밖 기존 기록을 실패로 잘못 바꾸지 않습니다. 0과 결측을 구분하며 미래 예보와 현재 관측 시각을 섞지 않습니다.

공개 제설구간·검토구간·적사함·한파쉼터·그늘시설을 지도에서 직접 작성하는 화면을 추가했습니다. 기록명·출처·확인시각·유효기한·원래 보고상태를 보존합니다. 시각이 없거나 잘못되면 상태미확인, 유효기간이 지났으면 갱신 확인 필요입니다. 노면결빙/통행안전 예측모형이 아닙니다.

## 4. 보안·저장·배포 검증

공개 관리기록은 정해진 속성만 보존합니다. 저장은 사용자가 눌렀을 때 현재 브라우저의 localStorage에 수행하며 자동 서버 전송은 없습니다. JSON 백업/검증 후 복원/GeoJSON 내보내기/확인 후 삭제를 연결했습니다. 민감 자료를 넣지 말라는 안내와 크기/위치/시간 제한을 적용했습니다.

수백 개 Cesium 파일을 하나씩 올리지 않도록 고정 SDK를 단일 로컬 tar.gz로 묶고 SHA-256·경로·크기·항목 검증 후 빌드에서 복원합니다. Vercel용 서버자료 포함 설정과 공개 배포물에서 서버/.env/시험자료가 제외되는지 검사했습니다. 완전한 보안인증은 아닙니다.

‘버튼 있음’을 ‘실제 자료 확보/인증 성공’으로 바꾸지 않습니다. 코드 작성, 포함자료 대조, 오프라인 화면, 로컬 빌드, 실GPU/외부 API/운영 배포를 각각 기록합니다. 이번 전달은 첫 네 범주의 검증된 수정본이며 마지막 범주는 별도 실제 환경 확인이 남습니다.
