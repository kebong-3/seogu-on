## 실제 확인한 동작

선택자료가 같을 때 중복도형 재전송 방지, 초기화중 최종상태 보존, 미지원 상세모형에서 기존표시 보존, 실제렌더러종류 구분, 18개센터명칭대조, 주소대기33건과 이전안내, 지도마우스로 두점구간 작성/마지막점취소, 비어있는도형등록거부, 출처/시각 검사, 선건수표시, 명시적저장·검증후복원·GeoJSON내보내기·확인후삭제, 재선택시다른종류숨김, 제설원래상태와만료상태분리, 그늘시간/높이누락, 날씨0·결측·실패시원래시각보존 등을 검사했습니다.

코드 시험: `tests/city-final.test.mjs`, `tests/city-final-ui.py`, `tests/city-regression-ui.py`. 출력: `verify-output.txt`, `regression-ui/results.json`, `final-ui/results.json`, `RELEASE_AUDIT.json`, `DEPLOYMENT_CHECK.json`.

## 중요한 시험환경 구분

UI는 실제 애플리케이션을 로드하고 실제포함자료를2D BoundaryView에 그립니다. API응답은fixture로 대체했으며, 신규저장시험에서는localStorage도 명시적인시험객체로 대체했습니다. 따라서 실제서비스주소의브라우저저장권한·재접속지속성까지 확인한 것이 아닙니다.

실제 Chromium 컨텍스트 생성검사 결과 `webgl:false`, `webgl2:false`였습니다(`WEBGL_PROBE.json`). 이 환경에서는 새 브이월드/독립모형의 실제GPU화질·FPS·건물/지형·그림자·GLB를 검증하지 못했습니다. 기능검사와 모의SDK객체를 통한 검사로 이 공백을 대체했다고 주장하지 않습니다.

본인 인증키로 기상청·에어코리아·쉼터·ITS·VWorld주소변환을 수신하거나 Vercel에 이번코드를배포하지 않았습니다. 실제배포의함수번들/도메인인증은 `LIVE_CHECK.md`에서확인합니다.

## 증거 이미지

`*-NOT-3D.png`는 실제2D경계도상에서의UI동작입니다. 기록명 TEST ONLY 또는관측시험값은 시험용이며 public기본현황에추가하지 않았습니다. 3D화질개선 전후사진으로 사용하지 않습니다. 중간 실패 캡처는 최종 전달물에서 제외하며 최종results.json은 모든 검사를 통과한 재실행 결과입니다.

## 배포 묶음과 보안

전체ZIP은확장SDK/dist를중복포함하지않고검증된로컬SDK압축파일과원본소스를포함합니다. Node빌드가SHA-256을확인한후실행자료를복원합니다. ZIP을빈폴더에풀어빌드하는별도검사결과는 `CLEAN_PACKAGE_CHECK.json`, 첨부예제키문자열·글꼴파일대조는 `SECURITY_SCAN.json`을확인하세요. 포괄적인보안인증이나제공기관사용승인서가아닙니다.

앱 소스 마감·로컬검증은완료했지만, 최신시설전수·정밀그늘/재난예측·서버공동DB·실운영인증까지완성된것은아닙니다. 이번작업에서원격저장소와운영사이트는변경하지않았습니다.
