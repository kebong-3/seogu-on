# 육아지도 · 아이와 나들이

접속: [서구온 육아 나들이지도](https://seogu-on.vercel.app/?work=family)

## 수록 범위

사용자가 제공한 「광주에서 함께 놀 지도」 지역별 목록 42개 항목, 「우리 동네 유아숲체험원」 목록 45개 항목(92~93쪽), 장소별 소개 사진을 반영했습니다. 원본 사진·삽화는 공개 저장소에 재게시하지 않았습니다.

광주시민의숲·광주사직공원·5·18 유아숲체험원은 두 목록에 공통으로 실려 있어 통합했습니다. 문화지도 14번의 환벽당·취가정·풍암정은 주소가 서로 달라 세 목적지로 분리했습니다. **87개 원문 항목 − 중복 3개 + 분리 2개 = 86개 목적지**입니다.

| 구 | 목적지 | 지도 표시 | 위치 재확인 |
|---|---:|---:|---:|
| 서구 | 17 | 16 | 1 |
| 북구 | 32 | 31 | 1 |
| 동구 | 5 | 5 | 0 |
| 남구 | 12 | 12 | 0 |
| 광산구 | 20 | 20 | 0 |
| 합계 | 86 | 84 | 2 |

공원과 내부 유아숲, 중앙공원과 풍암호수, 서로 다른 구간의 푸른길은 각각 찾을 수 있게 유지했습니다. 제목에 ‘유아숲체험원’이 있는 원문 목록에 일반 공원·산·서원도 포함되어 있으므로 모두 등록 유아숲체험원이라고 표시하지 않습니다.

## 이용 흐름

홈 또는 돌봄·육아 생활지도에서 **아이와 나들이**를 엽니다. 서구가 기본이며 다른 구 또는 전체를 선택할 수 있습니다. 이름·동네·활동 검색과 종류·실내외 필터가 목록과 지도에 함께 적용됩니다. 카드와 지도 표시를 누르면 동일한 장소를 선택하며, 선택 장소의 이름과 안내를 보여줍니다.

각 카드에는 소개, 주소, 책자 활동 또는 편집자가 제안한 활동, 방문 안내, 공식 페이지, 위치 출처를 담았습니다. 공원 위치와 방문 프로그램 운영 여부는 별개입니다. 확인되지 않은 시간·요금·주차·유모차 접근성은 값으로 채우지 않았습니다.

지도 보기 범위는 광주 5개 구를 탐색할 때만 확장합니다. 행정 분석에 쓰는 서구 경계·선택 동은 이 필터로 바뀌지 않으며, 다른 서비스로 전환하면 임시 지도층과 확장 범위를 해제합니다. 순천에서는 이 메뉴를 노출하지 않습니다.

## 위치와 길찾기 판단

위치는 공개 자료의 수치를 읽어 이름·주소와 대조했습니다. 시설점, 공원 경계 대표점, 공원 내 안내 거점은 실제 출입구·주차장 측량값과 다릅니다. 각 레코드에 `coordinateSource`, `positionNote`, 원문 `sourceRefs`와 `sourceAddress`를 보존했습니다. `checkedAt`은 대조한 날짜이며 현재 영업·개방 상태를 확인한 날짜가 아닙니다.

| 항목 | 적용한 판단 |
|---|---|
| 광주천변공원 | 첨부 칠성로35번길19는 어린이집 주소와 겹침. 주 안내 주소와 좌표는 비우고 장소명 검색만 연결. 원문 주소는 출처 상세에 보존. |
| 평두메습지 | 첨부 화암동530 일원과 공개 좌표의 불일치를 해소하지 못해 좌표 미표시. 공식 특별보호구역 안내에 따라 출입·해설 가능 여부를 먼저 확인. |
| 전일빌딩245 | 원문 ‘옛 전남도청(전일빌딩245)’은 시설명이 혼합됨. 금남로245에 맞는 전일빌딩245로 정정하고 원문은 출처에 남김. 옛 전남도청을 같은 시설의 별칭으로 사용하지 않음. |
| 교육청 청사 | 기관 위치는 표시하되 상시 가족 체험을 보장하지 않음. 사전 문의·방문 안내로 연결. |
| 중앙공원·풍암호수 | 공원 대표 위치 표시. 공사와 개방 구간 확인 안내, 장소명 검색으로 실제 진입 동선 확인. |
| 매곡산·운암산·각화제 | 산·저수지 대표점으로 표시. 정상·물 경계 중심점을 직접 길찾기 목적지로 전달하지 않고 진입로 검색을 사용. |
| 푸른길 동명동 구간 | 광주폴리 공식 ‘푸른길 문화샘터(농장다리)’를 공원 접근 안내 거점으로 표시. 원본 필지의 정밀 위치로 주장하지 않음. |
| 푸른길 중앙로 구간 | 환경운동연합의 공식 행사 안내와 공원 명명 도형으로 계림동 구간을 대조. 원문 사무실 건물 자체를 공원 입구로 표시하지 않음. |
| 원당산·풍영정천변길 | 공식 확인된 공원 내 유아숲·별밤미술관을 안내 기준점으로 사용하고 카드의 위치 설명에 명시. |

일반 장소는 대조된 대표 위치로 카카오맵 길찾기를 엽니다. `search-only`는 장소 검색만, `confirm-first`는 공식 방문·출입 안내를 제공합니다. 외부 지도는 사용자가 직접 누를 때만 열며 현재 위치는 자동 요청하지 않습니다.

## 출처와 정정

대표 좌표와 주소는 광주관광, 산림청 숲교육포털, 공공데이터포털 도시공원·관광지·도서관 공개자료, 한국관광공사, 각 시설 공식 누리집, 한국학중앙연구원 광주문화예술인문스토리플랫폼, OpenStreetMap 및 카카오맵 공개 시설 안내를 대조했습니다. 개별 URL과 추출 방법은 [육아지도 데이터](../public/data/family/gwangju-outings.geojson)에 있습니다.

일부 2026년 서구 공원 표준자료에서도 시설 지번과 도로명·좌표가 엇갈려 해당 좌표를 채택하지 않았습니다. 유적근린공원과 금당산 유아숲은 숲교육포털, 마재는 이름이 확인된 공원 도형, 상무·풍암 일대는 공식 관광 지도를 우선했습니다. 금당산은 공식 포털의 풍암동 산95-45를 방문 안내 주소로 사용하고 책자 풍암동929를 원문으로 남겼습니다.

## 유지보수와 검증

정적 자료 경로는 `public/data/family/gwangju-outings.geojson`입니다. 이름을 수정할 때에도 안정 ID와 원문 번호를 유지합니다. 근거 없는 위경도 또는 구·동 중심점을 추가하지 않습니다. 새 위치를 확인하면 근거 URL·방법·대조일·대표점 설명을 함께 갱신하고 metadata의 실제 지도 표시 건수를 맞춥니다.

```sh
node scripts/validate-family-outings.mjs
node --test tests/family-outings.test.mjs tests/family-outings-data.test.mjs
npm run verify
```

빌드는 원문 번호 전수 포함, 86개 목적지의 고유 ID, 구별 건수, 좌표 근거, 방문 안내, 관계 ID를 검증합니다. 배포 확인용 `/data/release.json`의 `familyOutings`에 실제 건수와 GeoJSON SHA-256을 기록합니다. 자동검증은 현장 답사나 현재 운영 확인을 대신하지 않습니다.
