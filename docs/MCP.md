# 서구:온 MCP 서버 안내

서구:온에 실린 공간자료(행정동 경계, 버스정류장, 그늘막, 과거 침수기록 등)를 ChatGPT·Claude 같은 AI가 직접 조회할 수 있게 해 주는 읽기 전용 MCP 서버입니다.

## 커넥터 주소

```
https://seogu-on.vercel.app/api/mcp
```

- 방식: Streamable HTTP(상태 없음, JSON 응답). 인증 없음.
- 읽기 전용입니다. 저장소에 포함된 공개 GeoJSON 만 읽고 외부 API 를 호출하지 않습니다.
- 지원 프로토콜 버전: 2025-06-18, 2025-03-26, 2024-11-05

## 연결 방법

메뉴 이름과 위치는 서비스·요금제·시점에 따라 달라지므로 아래는 일반적인 순서만 적었습니다.

**Claude**: 설정의 커넥터(Connectors) 항목에서 "사용자 지정 커넥터 추가"를 선택하고 위 주소를 입력합니다. 인증 정보는 비워 둡니다. 대화창에서 커넥터를 켠 뒤 질문하면 됩니다.

**ChatGPT**: 설정의 커넥터(또는 앱) 항목에서 사용자 지정 MCP 커넥터를 추가하고 위 주소를 입력합니다. 인증은 "없음"을 선택합니다. 사용자 지정 커넥터 추가는 개발자 모드 등 별도 설정을 켜야 보일 수 있습니다.

**직접 확인(curl)**:

```bash
curl -s https://seogu-on.vercel.app/api/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

로컬에서는 `npm run dev` 후 `http://127.0.0.1:4173/api/mcp` 로 같은 요청을 보낼 수 있습니다.

## 도구와 질문 예시

| 도구 | 하는 일 | 질문 예시 |
| --- | --- | --- |
| `list_datasets` | 수록 자료 목록, 수록 지점 수, 출처·기준일, 연결 상태 | "서구:온에 어떤 자료가 있어?" |
| `locate` | 동 이름·시설 이름 → 좌표와 행정동 | "풍암동 행정복지센터가 어디야?" |
| `dong_profile` | 한 동의 분류별 수록 지점 수, 미연결 자료, 침수기록 연도별 수 | "금호1동 현황을 요약해 줘" |
| `find_facilities` | 분류별 지점 찾기(동 / 기준점 반경) | "서구청 반경 300m 안 주차장은?" |
| `nearest` | 기준점에서 가장 가까운 N곳 | "풍암초등학교에서 가장 가까운 그늘막 3곳" |
| `coverage_gap` | 반경 안에 서비스 시설이 없는 대상 찾기 | "풍암동에서 반경 150m 안에 그늘막이 없는 버스정류장은?" |
| `compare_dongs` | 18개 동 비교표(건수, ㎢당 밀도) | "동별 그늘막 수와 버스정류장 수를 비교해 줘" |
| `flood_history` | 과거 침수피해 기록(동 / 반경, 연도별) | "서창동의 과거 침수 기록을 연도별로 알려 줘" |
| `sun_position` | 태양 고도·방위, 수직 물체의 평지 그림자 길이 | "8월 1일 오후 2시 풍암동에서 해는 어느 쪽이고 3m 그늘막 그림자는 몇 m야?" |

분류(`category`)는 `list_datasets` 가 돌려주는 id(`bus`, `local-shade`, `school` 등)나 한국어 이름(`버스정류장`, `그늘막`, `도서관` 등)으로 줄 수 있습니다. 기준점은 장소 이름(`place`)이나 경도·위도(`lon`, `lat`)로 줍니다.

모든 도구의 결과는 같은 모양입니다: 숫자가 들어간 한 문장 요약(`summary`), 표 형태의 자료(`data`), 사용한 출처와 기준일(`sources`), 자료의 한계(`caveats`).

## 자료의 한계 (답변에 함께 전달해야 하는 내용)

- **모든 자료가 부분 자료입니다.** 다수는 OpenStreetMap 에 등록된 일부 시설이고, 공공데이터포털 자료도 특정 기준일의 공개본입니다. 건수는 "자료에 수록된 지점 수"이지 서구 전체 시설 수가 아닙니다.
- **미연결 자료는 "0곳"이 아닙니다.** 한파쉼터·제설함처럼 검수된 자료가 아직 없거나 수집 건이 0인 분류는 건수 대신 "미연결"로 답합니다. 시설이 없다는 뜻이 아닙니다.
- **사각지대 분석은 후보 목록입니다.** 수록된 자료끼리 비교한 결과이므로, 자료에 빠진 시설이 실제로는 있을 수 있습니다. 현장 확인 전에는 확정된 사실로 쓰지 마세요.
- **과거 침수 기록은 이력입니다.** 이미 일어난 피해의 집계이며 현재 침수 상황이나 미래 위험 예측이 아닙니다. 연도별 건수 차이에는 공개 범위의 차이가 섞여 있습니다.
- **거리는 직선거리입니다.** 대표위치 사이의 거리이며 보행 경로, 출입구, 횡단 가능 여부를 반영하지 않습니다.
- **같은 시설이 여러 번 실릴 수 있습니다.** 위치 점과 부지 면이 겹치는 경우는 하나로 합치지만, 양방향 정류장이나 이름이 다른 중복 등록은 따로 셉니다.
- **행정동 배정과 면적은 근사입니다.** 공개 가공 경계(법적 확정 경계 아님)에 대표점이 들어가는지로 동을 정하고, 면적도 그 도형으로 계산합니다.
- **운영 상태를 모릅니다.** 현재 운영·개방·가동 여부는 확인되지 않았습니다.
- **태양 위치는 기하 계산입니다.** 그림자 길이는 평지 위 수직 물체를 가정한 값이며, 실제 건물·나무 그늘 여부는 판정하지 않습니다.

## 운영상 제한

- 요청 본문 64KB 이하, 배치는 20개 메시지 이하.
- IP별 분당 120회의 임시 제한이 있습니다(함수 인스턴스 메모리 기준이며 전역 제한이 아님).
- 요청 본문은 서버 로그에 남기지 않습니다.
- 인증이 없는 공개 서버이므로 비공개 행정자료나 개인정보를 이 경로로 연결하면 안 됩니다.
