## 시험 방법과 한계

화면시험은 실제 index.html, CSS, JavaScript 모듈, 공식 BI 원본 및 포함된 경계·시설자료를 사용했습니다. 브라우저의 외부 네트워크 요청과 localStorage는 명시적인 시험 객체로 대체했습니다. 실제 2D BoundaryView이며 WebGL 지도·브이월드 인증 검사가 아닙니다.

크기 1440×900, 1280×720, 1024×640, 390×844, 844×390에서 메뉴 범위·가로 넘침·아래 동 선택 가능 여부를 확인했습니다. CI/BI 원본 이미지의 로드도 검사했습니다.

5분 재생 시험은 실제 재생 컨트롤러를 사용하되 렌더 완료 응답만 시험 객체로 만들었습니다. 09:00→09:05→09:10, 일시정지, 일말 종료, 다른 패널로 이동 시 정지, 요청 번호 불일치 무시, 이전 프레임 응답 대기, 외부 API 추가 요청 0건을 검사했습니다. 실제 광주 서구 3D 건물의 그림자 픽셀 정확도는 확인하지 않았습니다.

로컬 키 도우미는 가짜 키 9개로 발급 내역 붙여넣기→비밀번호 입력칸→통합 JSON→전체 지우기를 검사했습니다. 실제 키를 시험 결과나 ZIP에 넣지 않았습니다. 외부 요청과 저장소 사용을 하지 않으며 CSP connect-src는 none입니다. 파일을 사용자가 자신의 PC에서 열어 입력합니다.

재난안전 API 9종은 공개 명세와 정상·오류 시험 응답으로 검사했습니다. 실제 발급키로 한파 API 1회 접속을 시도했지만 네트워크 연결 단계에서 실패하여 제공기관의 응답을 받지 못했습니다. 따라서 실제 9종 수신 성공은 0건이며, 키 유효성·허용 IP·쿼터를 검증하지 않았습니다. 오류 32 등은 처리 가능한 예외이지 이번 계정에서 실제 관측된 오류가 아닙니다.

## 원자료 검증

18개 동 BI는 원본 파일 SHA-256을 대조했고 모두 일치했습니다. 그늘막은 201행 중 서구 경계 안 199행, 쿨링포그는 7행, 과거 침수피해는 468행입니다. 출처와 원속성을 보존하고 점을 부지 경계로 확대하지 않았습니다. 시설의 현재 가동·개방 상태를 증명하는 자료는 아닙니다.

## 재현 명령과 증거

`npm run verify`가 문법·단위·빌드·배포물·HTTP 검사를 실행합니다. `npm run test:v06-ui`, `npm run test:v06-flow`, `python3 tests/city-regression-ui.py`, `python3 tests/city-final-ui.py`, `npm run test:v05-ui`는 Playwright/Chromium 환경이 필요합니다.

`final-verify.txt`, `RELEASE_AUDIT.json`, `DEPLOYMENT_CHECK.json`, `ui/results.json`, `regression-ui/results.json`, `records-ui/results.json`, `ui-evidence/results.json`, `FLOW_TEST_RESULTS.json`, `LOCAL_DATA_AUDIT.json`, `SECURITY_SCAN.json`, `CLEAN_PACKAGE_CHECK.json`을 참조하세요. 이미지의 NOT-3D 표시는 실제 3D 화면으로 오인하지 않도록 붙인 것입니다.

## 전달 및 미완료 범위

앱 소스는 전달 ZIP에 있습니다. GitHub 조사 브랜치의 공개자료 수집 작업과 앱 main 반영은 별개입니다. 이번에 Vercel 환경변수 저장·배포를 하지 않았습니다. 실제 브이월드 기본영상 밝기·SDK logo:false 반영·계절 그림자, 9종 서비스 인증/수신, AWS·병상의 식별번호-검수좌표 연결은 운영 검증 대상으로 남아 있습니다. 고정밀 일조권·실내 채광량·실시간 침수 및 결빙 예측을 완성한 결과물이 아닙니다.
