그늘막 제외행: 원본 15행 (126,35), 134행 (126.885934,35.141163). 잘못된 좌표인지 다른 행정구역인지 최종 원인·정답을 확정하지 않았으며 자동 이동시키지 않았습니다. 전체 원본과 제외·중복·동별 집계는 `raw/*.csv`, `LOCAL_DATA_AUDIT.json`에 있습니다.

그늘막의 경도·위도는 설명 텍스트만 보고 뒤집지 않았습니다. 실제 수치의 범위와 서구 경계를 대조했습니다. 기본 지도에는 검증 가능한 위치만 반영합니다. 점 자료는 시설의 실제 부지 경계가 아닙니다.

## 공식 BI 원본

18개 동 원문은 https://www.seogu.gwangju.kr/menu.es?mid=c7XX01000000 의 XX=01~18 페이지입니다. `public/brand/dongs.json`에는 각 동 ID·이름·BI 문구·원문·이미지 주소·SHA-256이 있습니다. 모든 이미지는 `public/brand/dongs/`에 포함하여 화면 실행 때 외부 이미지를 긁지 않습니다.

양동, 양3동, 농성1동, 농성2동, 광천동, 유덕동, 치평동, 상무1동, 상무2동, 화정1동, 화정2동, 화정3동, 화정4동, 서창동, 금호1동, 금호2동, 풍암동, 동천동을 각각 연결했습니다. BI는 마을 정체성 안내이며 해당 동의 재난 위험도나 사업성과가 아닙니다.

## 첨부 조사문서 60개 목록

사용자의 ‘공식 데이터 소스 60개’ 조사문서를 `public/data/city/source-roadmap.json`으로 연결했습니다. 원문 주소·용도·주의사항·같은 자료의 다른 제공경로를 구분하는 로드맵입니다. 이번에 60종 원자료를 모두 수집한 것은 아닙니다. L01/L02/L03은 이번 실제 수신자료와 연결했고 나머지는 기존자료 또는 추가 연결 대상으로 남습니다.

## API 코드 연결과 수신 현황

재난안전 API 9종은 공식 명세 기반 연결 코드·패널을 추가했습니다. 새 9종의 실제 API 데이터 수신 완료 수는 0종입니다. 1회 제한된 네트워크 시도는 환경 연결 실패였으며 키/IP 승인 여부를 판정하지 않았습니다. 화면시험에 사용한 가상 응답은 `public/`에 넣지 않았습니다.

AWS·병상·지역 재해위험지구의 위치 연결, 침수 도형의 실제 좌표계, 서비스별 원자료 시각과 지역 수록범위는 추가 확인 대상입니다. 이 공백을 임의 시설이나 서구청 중심점으로 채우지 않습니다.

## 기존 자료와 새 기능의 경계

이전 v0.5의 18개 행정동, OSM 건물·도로·공원·부분 인프라, 66개 공식 주제도 명세와 모든 기존 도구를 유지합니다. 66개 명세 역시 실제 수신 66종이 아닙니다. 학교 위치와 학교 면을 합쳐 학교 수로 계산하지 않습니다. 동일 시설에 여러 자료경로가 겹칠 때도 단순합을 시설 전수로 쓰지 않습니다.

밝은 테마는 UI 표현입니다. 기본 영상 밝기는 3D가 준비됐을 때 지원되는 영상 레이어에만 적용합니다. 관측값·위험등급·주제도 색을 밝기 필터로 바꾸지 않습니다. 건물 외벽 텍스처를 새 고해상도 원본으로 교체한 기능은 아닙니다.

5분 재생은 모의시각을 바꾸는 제어입니다. 기존 native shadow 제어기는 시각적 그림자를 그리며 구름·실내채광량·조도·정밀 일조권·고정밀 지형·미수록 수목을 자동 검증하지 않습니다. 지도 위 위치/그림자만으로 현장 안전을 보장하지 않습니다.
