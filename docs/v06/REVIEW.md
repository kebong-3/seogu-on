# 서구온 v0.6 교차 검토·마감 기록

네 검토 관점으로 같은 구현본을 교차 검토했습니다. 별도 자율 에이전트 4개가 실제 병렬 실행된 것처럼 표시하지 않습니다.

## 화면·사용성

밝은 블루 기본값, 스카이·야간 선택, 영상 밝기 설정, 기존 그래픽 설정 접근을 연결했습니다. 좌측 고정 높이에서 지역목록과 자료목록을 모두 세로로 쌓아 메뉴가 잘리던 구조를 탭·독립 스크롤로 바꾸었습니다. 숨긴 하단 중복 버튼의 기능이 없어지지 않도록 자료 목록·분석 도구·검토 기록은 좌측 고정 도구에 남겼습니다. 모바일 및 낮은 높이 화면도 범위를 검사합니다.

## 원자료·행정 맥락

공식 18개 BI와 첨부 CI를 사용합니다. 201행 그늘막 중 199행, 쿨링포그 7행, 과거 침수피해 468행을 받아 원본 식별·속성·기준일·수집일을 보존했습니다. 공식 점 자료를 면적·부지로 부풀리지 않았습니다. 60개 링크목록은 별도 로드맵입니다.

## 안전정보·시뮬레이션

한파·폭염쉼터, 위험지구, 침수이력, 의료·기상·도로정보를 제공기관의 성격대로 분리합니다. 확인된 API 명세에 없는 좌표·최신시각·지역필터를 생성하지 않습니다. 5분 재생은 이전 프레임 처리 응답을 받은 뒤 다음 시각을 적용하며, 실제시각과 모의시각을 혼동하지 않게 표시합니다. 재생 중 외부 API 호출은 없습니다.

## 보안·배포 검증

9개 키를 서버 전용 통합 변수 하나로 분리하고, 로컬 도우미에는 값이 없습니다. 공용 JSON에는 당직의사·작성자·연락처 등 불필요한 개인 속성을 배제합니다. 외부 주소는 고정·허용 목록만 사용하며 허용 IP를 우회하지 않습니다. 패치는 브라우저 업로드 파일 수 제한을 고려해 100개 이하로 만들고 원본 해시와 비교합니다.

GitHub에는 공개자료 조사 워크플로만 추가했고 운영 브랜치와 Vercel은 변경하지 않았습니다. 해당 조사 브랜치는 전체 앱의 완성본이 아닙니다.

## 마감 판단

로컬 구현·문법/단위/화면/배포물 검사를 끝낸 패키지를 전달합니다. Vercel 변수 저장 및 새 배포, 사용자 키 인증과 실제 데이터 수신, 실제 브이월드 GPU 그림자·영상 품질은 남은 운영 검증입니다. 브이월드 공식 코드샘플에 문서화된 `logo: false` 옵션으로 하단 로고의 미표출을 요청합니다. 자체 하단에는 첨부 서구 CI 2개를 사용하고, 지도 위 별도 텍스트에 ‘배경지도: 국토교통부·브이월드’ 출처를 유지합니다. SDK 크레디트·저작권 안내를 가리거나 삭제하는 CSS는 넣지 않았습니다. 실제 브이월드 SDK 화면에서의 옵션 반영은 배포 후 확인해야 합니다. 이 UI 옵션은 개별 데이터의 이용조건을 없애는 허가가 아닙니다.
