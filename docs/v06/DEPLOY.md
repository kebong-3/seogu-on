# 서구온 v0.6 적용 안내

## 전달 상태

기존 `kebong-3/seogu-on`의 v0.5.0을 기준으로 만든 수정본입니다. 기존 저장소와 Vercel 프로젝트를 유지합니다. 이번 작업에서 GitHub에는 `feature/blue-safety-v0.6` 공개자료 조사 브랜치와 조사 워크플로 3개만 추가했습니다. 새 앱 전체 코드의 push/main 병합, Vercel 환경변수 저장·재배포는 하지 않았습니다. 이 조사 브랜치를 완성된 앱으로 생각하고 병합하지 마세요.

Vercel 연결·쓰기 도구가 제공되지 않아 직접 키를 저장하지 못했습니다. 발급된 키를 다시 9개 변수에 하나씩 입력하지 않도록 로컬 정리 도우미와 통합 환경변수 하나를 준비했습니다. 실제 키는 ZIP에 없습니다.

## 1. v0.5 사용 중이면 ‘업데이트 ZIP’을 사용

업데이트 ZIP은 변경·추가된 파일만 담은 묶음입니다. 전체 프로젝트 ZIP과 둘 다 올릴 필요는 없습니다. `UPDATE_MANIFEST.json`에서 파일 수와 경로를 확인하세요. 기존 폴더를 삭제하지 말고 같은 경로에 덮어쓰거나 추가합니다. 패치에는 프로그램이 사용하는 기존 vendor 압축파일과 불변 데이터가 생략되어 있으므로, 빈 저장소에 패치만 올리면 안 됩니다.

1. 기존 GitHub 파일을 백업합니다. 자체 수정 파일이 있다면 변경 목록을 대조합니다.
2. 업데이트 ZIP을 풀고, 압축 바깥 폴더가 아닌 그 안의 파일·폴더를 저장소 **최상위**에 올립니다.
3. 예: `src/city/appearance.css`, `public/brand/dongs/seogu-01.png`. `src/src/`, `public/public/`로 중첩되면 안 됩니다.
4. 새 도우미의 `tools/` 폴더는 개발용입니다. 빌드 과정에서 공개 사이트로 복사하지 않습니다.
5. 기존 `vendor/cesium-1.121.0.tar.gz`, `vendor/cesium-manifest.json`을 보존합니다. 새 기능 때문에 SDK 수백 개 파일을 직접 올릴 필요는 없습니다.
6. `docs` 전체를 다시 업로드할 필요는 없습니다. 업데이트 ZIP 안에 들어 있는 새 문서만 반영합니다.

새 저장소나 원본 유실 상태에는 전체 프로젝트 ZIP을 사용합니다. `.env.local` 등 실제 키 파일은 어느 경우에도 GitHub에 올리지 않습니다.

## 2. Vercel 설정

Framework: Other / Root Directory: 저장소 최상위 / Node.js: 22.x / Build Command: `npm run build` / Output Directory: `dist`.

기존에 작동하는 `VWORLD_BROWSER_KEY`, `VWORLD_DOMAIN`, `VWORLD_API_KEY`를 삭제하지 마세요. 새로운 통합 변수는 API_SETUP.md에 설명한 `SAFETYDATA_KEYS_JSON`입니다. Production 적용 여부를 확인하고 새로 배포합니다. Preview 도메인은 브이월드에 등록된 Production 도메인과 다르므로 별도 인증 확인이 필요합니다.

Vercel 공식 안내: https://vercel.com/docs/environment-variables/managing-environment-variables
환경변수 변경은 이전 배포에 소급 적용되지 않습니다. 저장한 뒤 새 배포를 생성해야 합니다.

## 3. 적용 확인

`/api/city-config`와 `/data/release.json`의 version이 모두 `0.6.0`인지 확인합니다. ‘configured: true’는 키 값이 존재한다는 뜻이며 인증·수신 성공이 아닙니다.

첫 화면은 밝은 블루입니다. ‘화면 설정’에서 스카이 블루·야간 네이비, 기본 영상 밝기, 동 BI 표시를 바꿉니다. 표시 설정은 현재 브라우저에 보관하며 재난·관측 수치를 변경하지 않습니다.

왼쪽 ‘18개 동 / 표시 정보’ 탭을 전환하고 맨 아래 메뉴까지 안쪽 스크롤로 이동합니다. 작은 화면에서는 ‘메뉴 보기’를 눌러 패널을 엽니다. 18개 BI 갤러리에서 동을 누르면 같은 동으로 이동합니다.

‘생활·정책 검토 → 폭염 대응’에서 실제 그늘막 199행·쿨링포그 7행을 확인합니다. ‘침수 이력’의 468행은 과거 피해기록이며 현재 침수범위가 아닙니다.

‘5분 그림자 → 날짜/시간 → 재생’을 사용합니다. 5분은 시뮬레이션상의 시간 간격이며 실제 5분을 기다릴 필요는 없습니다. 보통 속도에서는 렌더러가 준비된 경우 약 1.8초마다 다음 5분으로 넘어갑니다. 경계도에서는 3D 그림자가 실행되지 않습니다.

마지막으로 ‘재난안전 API’에서 한파쉼터 한 종류부터 수신합니다. 오류 32, 30, 31, 22는 각각 허용 IP·키·만료·호출량 조건을 확인하는 단서입니다. 좌표가 없는 자료는 위치 연결이 끝나기 전까지 지도 점으로 표시하지 않습니다.

## 4. 하단 CI와 지도 출처

브이월드 공식 코드샘플에 문서화된 `logo: false` 옵션으로 하단 로고의 미표출을 요청합니다. 자체 하단에는 첨부 서구 CI 2개를 사용하고, 지도 위 별도 텍스트에 ‘배경지도: 국토교통부·브이월드’ 출처를 유지합니다. SDK 크레디트·저작권 안내를 가리거나 삭제하는 CSS는 넣지 않았습니다. 실제 브이월드 SDK 화면에서의 옵션 반영은 배포 후 확인해야 합니다. 이 UI 옵션은 개별 데이터의 이용조건을 없애는 허가가 아닙니다.

공식 옵션 근거: https://github.com/V-world/V-world_API_sample/blob/master/%5BWebGL%5D%20glb%20%EC%9B%80%EC%A7%81%EC%9D%B4%EA%B8%B0.html

브이월드의 실제 건물·기본 영상 밝기·GPU 그림자, 실제 SafetyData 키 승인과 허용 IP, AWS·병상 등의 식별번호와 좌표 연결, 원자료 최신성은 운영 도메인에서 확인해야 합니다. 회의·재난 대응의 유일한 판단 근거로 사용하지 마세요.
