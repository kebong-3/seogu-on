# 행정 업무에 쓰는 공간 비교 — 0.11.0

## 바뀐 출발점

공무원이 시설별 운영시간·확인 근거를 모두 입력하기 전에, 현재 수록된 자료로 판단할 재료를 먼저 제공한다. 공공공간 운영시간 검토는 기타 도구에 남겨 두고 시설 배치·현장점검·사업 후보지 비교를 첫 화면으로 올렸다.

### 1. 시설을 어디에 추가할까

1. 첫 화면 **시설을 어디에 추가할까요?**를 연다. 최초 결과에는 입력이 필요 없다.
2. 항상 보이는 **무엇을 검토하나요?**에서 정류장/횡단보도 그늘막, 학교 주변 그늘막, 학교 주변 활동공간 등을 선택한다.
3. **비교 조건 바꾸기**에서 구역, 직선거리, 추가 개수를 조정한다.
4. 추천 후보를 하나 제외하거나 **위치 옮기기**로 지도에서 다른 위치를 고른다. 전후 수치와 지도 반경이 함께 바뀐다.
5. 기존 시설을 제외하면 운영 중단·이전의 가정도 비교할 수 있다. 원자료나 실제 시설 상태를 수정하는 기능은 아니다.

자동 후보는 수록 대상의 실제 대표좌표에서 고른다. 현재 시설과 이미 선택한 후보를 고려하여 **추가로 포함하는 고유 좌표 수가 큰 곳**을 순차 선택한다. 다음으로 원문 기록 수, 거리, 원본 ID를 비교한다. 연속 공간의 최적 입지, 사유지 사용 가능성, 설치 타당성을 판정하지 않는다.

후보 카드의 **이 후보를 빼면 다시 공백이 되는 위치 수**는 현재 선택한 다른 후보를 그대로 둔 상태에서 계산한다. 가까운 후보 둘이 겹치는지, 하나를 빼도 연결 상태가 유지되는지 살펴볼 수 있다.

### 2. 어디부터 점검할까

**점검 목록**은 위치·좌표·최근접 수록 시설·선정 근거·주변자료를 모아 준다. 순천 횡단보도는 턱낮춤·점자블록 등 원문의 명시적 미설치 표기와 미상 값을 구분한다. 핵심 접근시설의 미설치 표기 수, 기타 표기 수, 거리 순으로 목록을 정리한다. 표기가 없는 다른 자료는 거리 조건으로 정리한다.

미설치 표기만으로 위험·위법·설치 의무를 판단하지 않는다. 신호 설치 적정성이나 현재 상태는 현장에서 확인한다. 예를 들어 집중조명 값이 빈칸인 기록을 조명 미설치로 분류하지 않는다.

### 3. 사업 후보지 A와 B는 무엇이 다른가

**후보지 비교**는 처음에 수록 공공공간의 서로 다른 좌표 두 곳을 예시로 제시한다. 실제 사업 후보를 뜻하는 자동 선정은 아니다. **위치 바꾸기**로 사용자의 검토 위치를 정하면 기본 500m의 같은 반경에서 주변 학교·시설·공개 기록을 비교한다.

공간 수, 고유 좌표 수, 최근접 거리를 함께 보여 준다. 주민활동 공간·학습 거점·시설 재배치·부서협의의 사전 검토자료로 사용할 수 있다. 실제 인구 수요, 소유권, 용도지역, 통행 동선은 별도로 확인해야 한다.

## AI 사용법

상단 날씨 옆 질문칸이나 업무 화면 질문칸에서 다음처럼 입력한다.

- “그늘막 3곳을 추가하면 공백이 얼마나 줄어들까?”
- “추가 후보를 두 곳으로 줄여줘.”
- “풍암동 학교 주변 그늘막을 반경 200m로 비교해줘.”
- “사업 후보지 주변 여건을 비교해줘.”

AI가 등록된 업무·자료·구역 안에서 계산 조건을 선택한다. 질문에 명시한 숫자와 지역은 우선 적용한다. 한 번에 한 구역을 지원하며 다른 지역이나 복수 동 질문은 잘못된 구역으로 대체하지 않고 안내한다. 모델 호출이 불가능하면 문장에 명시된 조건을 규칙으로 읽고 해당 상태를 표시한다.

결과 바로 아래 **AI로 근거와 다음 업무 정리**를 누르면 AI가 검토 방향, 주요 계산 근거, 후속 확인 순서를 고른다. 서버는 실제 근거 ID와 업무 조건을 검증하고 정확한 값으로 문장을 작성한다. AI가 거리·효과·이용자 수를 임의로 생성하지 않는다. 메모 작성은 현재 후보나 반경을 변경하지 않는다.

## 결과를 업무자료로 가져가기

- **검토서 내려받기:** HTML 문서. 전후 결과, 비교 가정, 후보 위치, 주요 근거, AI 메모, 자료 출처를 포함한다. 브라우저에서 인쇄·PDF 저장이 가능하다.
- **좌표 목록 CSV:** 전체 대상과 좌표, 선정 근거, 출처·기준일, 주변 조회 결과를 포함한다. 후보지 비교는 위치·자료 종류별 행으로 저장한다.

보고서는 주요 대상 50개와 근거 20개를 표시해 읽을 수 있는 분량으로 정리한다. 전체 대상은 CSV에 포함된다. 공식 공문·예산 산출서·인허가 판단서는 담당자의 검토를 거쳐 작성한다.

## 실제 수록자료의 계산 예시

2026-10-23 포함 데이터, 전체 구역, 직선 150m, 자동 추가 후보 3곳 기준이다.

| 지역 | 대상 | 현재 조건 이내 고유 좌표 | 추가 후 | 새로 포함 |
|---|---|---:|---:|---:|
| 서구 | OSM 수록 정류장 433개/433좌표 | 203 | 215 | 12 |
| 순천 | 횡단보도 866관리번호/651좌표 | 241 | 280 | 39 |

순천의 원문 관리번호 기준 변화는 316→374, 증가 58건이다. 같은 대표좌표를 공유하는 원문을 별도 장소처럼 부풀리지 않도록 화면은 고유 좌표 수를 먼저 보여 준다. 실제 그늘이 닿는 위치·보행시간·주민 수혜 인원·온도 저감량을 뜻하지 않는다.

## 디지털트윈의 구현 범위

현재 기능은 **공개 위치자료로 현실 시설의 기준 상태를 만들고, 가상의 시설 추가·중단·이전을 동일한 공간 계산에 적용하는 업무형 시제품**이다. 원자료 버전과 해시, 지역, 반경, 후보 위치로 계산을 재현할 수 있다.

실시간 도시 전체 상태를 재현하거나 물리 기반 재난·교통·수요 예측을 검증한 단계는 아니다. 실제 시설 운영, 보행 네트워크, 이용량, 비용을 더 연결하면 의사결정에 사용하는 조건을 확장할 수 있다. 사용 시간 절감이나 정책 효과는 실제 담당자 업무 비교로 측정해야 한다.

## 타 지자체 적용

1. 해당 지역의 검증된 행정경계와 프로필을 등록한다.
2. 대상 자료와 서비스 자료를 원본 ID·좌표·지역·기준일·출처와 함께 구성한다.
3. `public/data/decision/<regionId>/manifest.json`에 자료, 기본 업무와 반경, 주변 조회 자료를 등록한다.
4. 제공기관 코드와 행정기관 코드, 수록 범위를 확인하고 `validateDecisionPacks`를 확장해 실행한다.
5. 같은 UI·계산 엔진으로 실제 지역별 결과를 확인한다.

서구는 수록 정류장, 순천은 공식 횡단보도를 기본 그늘막 검토 대상으로 쓴다. 지역 이름만 바꾸거나 미연결 자료를 0으로 계산하지 않는다.
