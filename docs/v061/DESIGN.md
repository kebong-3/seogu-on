# 서구:온 v0.6.1 — 브랜드·UI 설계

## 한글 브랜드

이름: **서구:온**

설명: **서구의 오늘을 한눈에 · AI 행정 디지털트윈**

심벌은 도시·지도·두 개의 연결점을 조합한 자체 벡터 도형입니다. 전용 한글 워드마크는 `public/brand/seogu-on-wordmark.svg`, 심벌은 `public/brand/seogu-on-symbol.svg`에 있습니다. 상단은 심벌과 실제 HTML 한글 텍스트로 구성해 작은 화면에서도 읽을 수 있도록 했습니다. 별도 글꼴파일을 배포하지 않습니다.

색상은 사용자가 요청한 파랑·초록의 느낌을 참고한 자체 조합입니다. 특정 정당의 공식 CI 색상값을 정확하게 재현했다는 주장이 아니며 정당 로고·명칭·슬로건을 서비스에 사용하지 않습니다. 화면 색상은 #0752a7(블루), #06367d(딥블루), #1faac7(청록빛 파랑), #00a88b(초록 강조)를 중심으로 구성했습니다.

## 지역 카드

지도 위 지역 카드에는 **동 이름 + 기존 공식 BI 원본**만 표시합니다. ‘DISTRICT VIEW’, ‘가까이.’, ‘위치 0개’, ‘면 도형 0개’, ‘선 구간 0개’, ‘탐색 중’은 카드에서 제거했습니다. 카드 높이는 기본 PC에서 58px, 모바일에서 51px입니다. 화면폭에 따라 최대폭을 제한하며 BI는 늘이거나 자르지 않고 비율을 보존합니다.

기존 동 BI 원본 18개는 바꾸지 않았습니다. 이름·자료표·내보내기에 필요한 시설 건수 자체를 삭제한 것은 아니며 내부 진단 요소만 숨긴 상태로 보존합니다.

## 패널과 설정

상단을 블루→청록 그라데이션으로, 일반 패널은 옅은 푸른빛으로 조정했습니다. 얇은 하이라이트, 절제된 바닥 그림자와 선택 버튼의 깊이감으로 입체적 인상을 만듭니다. 이는 CSS 화면 표현이며 3D 건물 모델을 새로 만든 것이 아닙니다.

‘시그니처 블루 / 스카이 블루 / 야간 네이비’와 ‘입체형 / 담백한 평면형’을 조합할 수 있습니다. 이전 v0.6의 밝기·BI 표시·야간 설정은 그대로 읽으며 새 finish 값만 기본 depth로 보완합니다. 위험 레이어의 범례·원자료 색상이나 관측값은 바꾸지 않습니다.

## 출처 띠 정리

지도 위에 고정되어 있던 긴 가로 출처 띠는 제거했습니다. 출처를 없애지 않고 하단의 작은 ‘지도 출처’ 팝오버로 옮겼습니다. © OpenStreetMap 링크는 하단에 계속 표시하며 SDK 자체 크레디트도 숨기거나 삭제하지 않습니다. 출처 버튼은 키보드로 접근할 수 있고 Esc·바깥 클릭으로 닫힙니다.

OpenStreetMap 출처 및 관련 안내: https://osmfoundation.org/wiki/Licence/Attribution_Guidelines

이 안내는 인터랙티브 지도에 알아볼 수 있는 출처와 이용조건 접근 경로를 요구합니다. 본 수정은 시각적 정리이며 제공기관별 이용허락을 대신하지 않습니다. 기존 BI·서구 CI와 데이터의 저작권·출처는 유지합니다.

## 화면 범위

기존 18개 동·시설 선택·API·5분 그림자·기록 기능은 유지합니다. 새 AI 분석 모델을 추가한 버전이 아니며 ‘AI 행정 디지털트윈’은 사용자가 요청한 서비스 설명입니다. 현재 구현·검증되지 않은 데이터나 예측 기능이 추가된 것으로 해석하면 안 됩니다.
