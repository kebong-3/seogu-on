# 서구:온 v0.6.1 디자인 업데이트 적용 안내

## 대상

기존 `kebong-3/seogu-on` 저장소의 v0.6.0에 적용하는 수정본입니다. 같은 Vercel 프로젝트를 사용하며 새 API 키나 환경변수는 필요하지 않습니다. 이 문서는 새 기능의 운영 배포가 완료됐다는 기록이 아닙니다.

## 업데이트 ZIP으로 적용

`seogu-on-v0.6.1-ui-update.zip`의 파일·폴더를 저장소 **최상위**에 같은 경로로 올립니다. 기존 폴더를 먼저 지우지 마세요. 경로 예시는 `src/city/identity.css`, `public/brand/seogu-on-symbol.svg`, `docs/v061/DESIGN.md`입니다.

업데이트 ZIP에는 변경 파일과 새로운 검증자료만 있습니다. 원래 `vendor/cesium-1.121.0.tar.gz`, 행정경계, 시설자료, API 구현을 그대로 사용하므로 빈 저장소에 업데이트 ZIP만 올리면 실행할 수 없습니다.

최상위 `package.json`·`index.html`도 함께 바뀝니다. 새 CSS나 새 로고만 올리고 이 파일을 누락하지 마세요. ZIP 안의 `UPDATE_MANIFEST.json`에 경로·해시·파일 수가 있습니다.

## Vercel

기존 설정 유지: Framework Other / Root 저장소 최상위 / Node.js 22.x / Build `npm run build` / Output `dist`.

기존 브이월드·기상청·에어코리아·SafetyData 환경변수는 삭제·변경하지 않습니다. 새 커밋이 기존 연결 설정으로 배포되는지 Vercel 화면에서 확인합니다.

## 확인 순서

- `/api/city-config` 및 `/data/release.json`의 `version`이 모두 `0.6.1`인지 확인합니다.
- 상단이 ‘서구:온 — 서구의 오늘을 한눈에 · AI 행정 디지털트윈’인지 확인합니다.
- ‘화면 설정 → 시그니처 블루 → 입체형’을 선택합니다. 기존 저장설정이 야간이라면 자동으로 초기화하지 않으므로 직접 전환합니다.
- 동 선택: 동 이름과 BI만 있는 작은 카드인지 확인합니다. BI가 안 보이면 ‘동 BI 표시’ 설정을 켭니다.
- ‘지도 출처’를 눌러 출처가 열리는지, Esc로 닫히는지 확인합니다. 큰 가로 출처 띠는 없습니다.
- 학교·공원 단독 선택, 동 이동, 5분 그림자 제어가 기존처럼 연결되는지 실제 지도에서도 확인합니다.

## 전달 범위

이번 작업에서 GitHub에 커밋하거나 Vercel을 재배포하지 않았습니다. UI 검증 이미지는 실제 앱의 2D 경계도 화면이며 실제 브이월드 GPU 렌더링 검증사진이 아닙니다.
