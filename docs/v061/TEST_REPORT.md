## UI 검사에 사용한 화면

1920×1080, 1440×900, 1280×720, 1024×640, 844×390, 390×844, 360×740, 320×640에서 패널·푸터·한글 로고·동 카드와 스크롤을 확인했습니다. 18개 동 각각 이름과 BI가 맞게 연결되는지 검사했습니다.

PC 카드 높이 58px, 모바일 51px을 확인했고, 카드 내 영어 제목·건수·탐색 문구는 표시되지 않습니다. 마지막 동 메뉴 접근, 가로 넘침, 출처 열기·닫기, 테마·입체감·BI 표시 설정, 5분 제어 접근도 확인했습니다.

## 시험환경의 한계

UI는 실제 앱 모듈·CSS·포함 경계·BI·공개자료를 **2D BoundaryView**로 그립니다. 외부 네트워크와 localStorage는 명시적인 시험용 응답으로 대체했습니다. 5분 재생은 렌더러 응답을 시험 객체로 제공한 제어흐름 검사입니다. 실제 브이월드 3D 건물의 그림자·실시간 API 인증·운영주소 브라우저 저장권한을 확인한 시험이 아닙니다.

로컬 Node HTTP 검사와 별도로 브라우저의 로컬 URL 직접 이동은 실행환경 정책에 의해 차단되어, 기존 오프라인 UI 검사 방식을 사용했습니다. 이를 실제 운영 웹브라우저 방문 성공으로 표현하지 않습니다.

화면이미지 파일명의 ‘2D’ 및 ‘NOT-3D’는 이 구분을 의미합니다. 3D 화질 개선 전후 사진이 아닙니다. 지도·API·키 설정을 변경하지 않았으며 GitHub 쓰기·Vercel 배포도 하지 않았습니다.

## 패키지 재현 확인

`CLEAN_PACKAGE_CHECK.json`은 v0.6.0 전체 프로젝트를 새 폴더에 해제하고 업데이트 파일을 같은 경로로 덮은 뒤 검사·빌드한 결과입니다. `UPDATE_MANIFEST.json`과 `RELEASE_MANIFEST.json`에는 전달파일 해시를 기록합니다. 실제 비밀 환경변수 파일이나 글꼴 바이너리는 포함하지 않습니다.
