# 대표 도보 실증 과제 — v0.16.0

## 과제와 완료 기준

대표 문제는 아이와 함께 필요한 돌봄시설을 경유하는 여름철 보행이다. 시작시설·도착시설·경유시설과 동일 출발시각을 두 방식에 공통으로 지정한다. 재현 예시는 ‘광주시청 장난감도서관 → 운천역 수유실 경유 → 어린이생태학습도서관, 계단 제외’다. 수록 이름이 같더라도 현재 운영시간·이용자격·실제 출입구는 별도 확인한다.

참가자는 출발·도착·경유를 정확히 선택하고 실제 제공기관 경로와 회전 지시를 열며, 거리·시간·계단 제외의 의미·그늘 평가 범위와 확인할 운영조건을 설명하면 화면 과제를 완료한다. 지도 선을 보는 것만으로 완료하지 않는다. 현장 보행 과제는 실제 단말의 동의된 위치 권한으로 별도 수행하며 기기·권한·통신 조건, 다음 안내·이탈·도착·중지 결과를 관찰한다. 경로의 안전성·무장애 여부를 자동판정하지 않는다.

## 비교 방법

기존 방식은 참가자가 평소 사용하는 지도·기관 원문 확인 조합으로 정하고 허용 자료·완료조건을 앱 방식과 같게 둔다. 익명 참가자별로 AB/BA 순서를 나누고 같은 조건에서 각각 시간·완료/중단·잘못된 선택·확인 전화 횟수·출처누락을 기록한다. 잘못된 선택은 지정 시설 또는 경유 조건과 다른 선택을 독립 관찰자가 확인한 건수다. 전화는 해당 과제에서 실제로 건 횟수이며 예상 횟수를 쓰지 않는다. 미측정은 빈칸으로 남긴다.

앱의 ‘업무효과 측정’에 같은 과제·참가자·조건으로 기록한다. 두 방식 모두 완료한 3명 이상인 경우만 확인된 시간 개선을 계산하고, 완료율은 측정 여부와 분모를 함께 제시한다. 개인 이름·전화번호·위치 이력을 공개 결과에 저장하지 않는다. 실제 기록을 확보하기 전에는 절감률·만족도·성공률을 생성하지 않는다.

## 실패와 재수행

검색 실패, 모호한 시설, 자료 미수록, 경로 단절, 권한 거절, 부정확한 위치, 통신 실패, 휴관 또는 출입구 차이는 실패 원인과 함께 남긴다. 수정 전후 버전·조건을 기록하고 동일 과제로 재수행한다. 미리보기와 통제된 GPS 시험은 실제 보행과 구분한다. 공식 귀갓길 선형·노면 관측·47건 미확정 좌표는 확보 전까지 미확인이다.
