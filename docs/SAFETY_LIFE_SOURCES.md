# 생활안전 정보의 실제 연결과 자료 범위

확인일: 2026-10-24 (한국시간). API 검색은 사용자가 제공한 [공공데이터 API 검색 사이트](https://public.rimikimi.com/)를 참조하고, 제공방식·열 정의·이용조건은 공식 원천에서 다시 확인했다.

|---|---:|---|---|
| 서구 보안등 | 7,887개 | 2026-08-06 | 등록 위치. 조도·점등·보행 안전 보장 아님 |
| 경찰서·지구대·파출소 | 8개 | 원문 미제공 | 공개 기관 대표위치. 현행 운영·접근성 별도 확인 |
| 안전비상벨 | 62개 | 2023-06-21 | 방범용으로 공개된 시설의 수록 위치. 현재 작동·경찰 연계 재확인 필요 |

| 안심지킴이집 | 지역 수록 미확인 | 해당 없음 | 전국 표준 다운로드 2,852행에서 서구 자료를 확보하지 못함. 시설이 없다는 뜻 아님 |

신규 파일은 `public/data/city/safety-emergency-bell.geojson`, `safety-cctv.geojson`이다. 비공개 피해자 보호시설의 위치·이용자·관리자 개인정보는 수집하지 않는다. 공개 지정 편의점인 안심지킴이집과 비공개 보호시설을 구분한다.

## 비상벨·CCTV의 실제 공식 제공방식

[전국안전비상벨위치 표준 안내](https://www.data.go.kr/data/15028206/standard.do)와 [전국CCTV 표준 안내](https://www.data.go.kr/data/15013094/standard.do)는 현재 기관 자체의 공개 CSV 다운로드를 안내한다. 예전 API 주소를 추측해 정상 연동된 것으로 등록하지 않았다.

- [비상벨 공식 다운로드 화면](https://file.localdata.go.kr/file/emergency_call_box_info/info)
- [CCTV 공식 다운로드 화면](https://file.localdata.go.kr/file/cctv_info/info)
- 서구의 공식 화면상 지역코드: `5810000` (전남광주서구)
- 공식 화면의 지역 다운로드가 실제 요청하는 경로: `/file/download/<자료종류>/info?orgCode=5810000`
- **추가 API 키 없이 다운로드 가능**. 파일은 HTTP `text/csv`이나 실제 한글 바이트는 CP949이므로 인코딩 검사 후 읽는다.

2026-10-23 UTC 수집에서 비상벨 62행·CCTV 51행을 받았고, 명시된 `WGS84위도`, `WGS84경도`를 사용했다. 웹 요약에 비상벨 좌표계를 EPSG:5174로 적었지만 이 CSV에는 WGS84 좌표 열이 명시되어 있으므로 TM 변환을 적용하지 않았다. 한국 위경도 수치범위, 18개 행정동 경계, 원문 관리번호 중복을 검사했으며 경계 밖·무효 좌표는 없었다.

각 행의 `데이터기준일자`는 2023-06-21이고, `데이터갱신시점`은 2026-07-01이다. 후자를 시설 상태의 기준일로 바꾸지 않는다. 비상벨의 마지막 점검일·점검결과·경찰 연계 표기는 **당시 원문 값**으로 보존하며 현재 작동 사실로 표시하지 않는다. 공식 파일 수집이 최신 경로라는 사실과 시설 현황 자체가 최신인지 여부는 별개다.

포털 구형 표준 JSON 다운로드도 조사했으나 비상벨 서구 59행이 2020년 기준이어서 신규 수록본에 사용하지 않았다. CCTV 구형 표준 JSON은 50,000행 상한이고 지역 필터가 적용되지 않아 완전한 서구 자료로 사용하지 않았다.

## 추가 API가 필요한 부분

| 추가 정보 | 공식 신청·안내 | 서버 변수 / 조건 | 현재 상태 |
|---|---|---|---|
| 공개 안심지킴이집 | [전국안심지킴이집](https://www.data.go.kr/data/15034535/standard.do) | `DATA_GO_KR_SERVICE_KEY`, **서비스별 활용승인** 필요 | 서버 카탈로그 프리셋 추가, 실제 승인키 수신은 미검증 |
| 여성밤길치안안전 WMS | [공식 포털 안내](https://www.data.go.kr/data/15101813/openapi.do), [생활안전지도 개발자센터](https://www.safemap.go.kr/dvct/mapAPI.do) | 기존 `SAFEMAP_SERVICE_KEY`의 해당 서비스 권한·제공조건 확인. 일반 공공데이터키와 동일하다고 가정하지 않음 | 기존 지도층·설정 범위 확인 필요, 이번에 인증성공 주장 안 함 |
| 최신 방범 CCTV·비상벨 점검대장 | 담당부서의 공개 가능한 설치·철거·점검 자료 | API 키보다 최신 공개 위치·기준일·목적·현행 여부가 우선 | 파일 수집본 이후 변경사항 미확인 |

안심지킴이집의 공식 API 주소는 `https://api.data.go.kr/openapi/tn_pubr_public_female_safety_prtchouse_api`이며 공식 페이지 HTML의 명세에서 확인했다. 공개 점포명·주소·위경도·관할경찰서·지정연도·운영여부·데이터기준일자를 제공한다. 이 API의 운영여부는 이용 가능한 시간표나 긴급출동 보장이 아니다. 같은 공공데이터 인증키라도 서비스를 따로 신청해야 한다.

여성밤길치안안전은 과거 범죄발생을 밀도 분석해 도로상 등급으로 표현한 **지도 그림**이다. 개별 시설 수·현시점 범죄 위험·안전 경로 산출에 쓰지 않는다. 추가 지도층을 켜더라도 범례·기간·원문 출처와 함께 제공해야 한다.

## 재수집

```sh
node scripts/data/collect-safety-life.mjs --fetch --source-dir /tmp/safety-life
```

스크립트는 공개 CSV·공식 상세페이지·이용조건 페이지의 해시와 실제 수집시각을 보관하고, 명시된 WGS84 열과 지역코드·경계를 검사한다. 실패하거나 빈 파일이면 기존 정상 수록본을 덮지 않는다. 최종 GeoJSON에는 원문 해시, 수록건수, 제외건수, 출처·기준일, 점검과 운영의 한계를 보존한다. API 키·전화번호·개인 성명은 저장하지 않는다.
