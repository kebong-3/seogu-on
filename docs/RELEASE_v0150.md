# 서구온 v0.15.0

2026-10-27 생활서비스 화면과 시설 탐색을 정리했습니다.

- 첫 진입의 공원 선택을 유지하고, 동 이동이 끝나면 천천히 회전합니다. ◎ 버튼이나 지도 조작으로 멈추며 동작 줄이기 설정을 존중합니다.
- 주요 서비스를 ① 돌봄·육아 · 생활안전지도 ② 계절 안심 도보 내비게이션 ③ 재난안전지도로 구성했습니다. 다른 서비스로 이동하면 이전 분석 표시를 정리합니다.
- 어린이집 122곳을 유지하면서 공식 목록에서 다른 돌봄시설·서비스 공간 78개를 추가했습니다. 31개는 지도 대표위치, 47개는 공식 주소 목록으로 제공합니다. 민간 키즈카페까지 포함한 전수목록은 아닙니다.
- 출발·도착 시설명/주소 검색, 검색결과 선택, 지도 선택과 맞바꾸기를 제공합니다. 외부 주소 검색에는 서버의 VWORLD_API_KEY와 VWORLD_DOMAIN, 실제 보행경로에는 TMAP_API_KEY가 필요합니다.
- 광주서부경찰서의 여성안심귀갓길 6개 공식 안내와 지도 첨부파일 링크를 연결했습니다. 좌표 없는 이미지 지도를 임의의 경로선으로 변환하지 않습니다. 노선 좌표자료 확보 방법을 화면에서 안내합니다.
- Upstage Solar Pro4를 서버에서 사용할 수 있습니다. 설정은 [SOLAR_SETUP.md](SOLAR_SETUP.md)를 참고하세요. 대화에 노출한 키를 재사용하지 않습니다.

## 확인 범위

- 로컬 자동검사 884개 통과. Windows 권한이 필요한 이름에 symlink가 포함된 검사는 제외했으며 Linux CI에서는 전체 검사를 실행합니다.
- JavaScript 구문 검사, 정적 빌드, 배포파일 검사 27개 통과.
- 로컬 HTTP 일괄검사는 실행 환경의 로컬 포트 접근 제한으로 완료하지 못했습니다. 브라우저에서 별도로 첫 화면, 동 회전, 시설 검색, 서비스 전환, 경로 입력·교환을 점검했습니다.
- 데이터 파일 해시, 지역 경계, 유형별 개수와 주소 목록을 확인했습니다. 대표위치의 의미와 출처는 [CARE_DATA_SOURCES.md](CARE_DATA_SOURCES.md)에 기록했습니다.
- Solar는 모의 응답으로 검증했습니다. 새 키 설정 후 운영 응답 확인이 필요합니다.
