# v0.4 인계 메모

전달본 기준일2026-09-27, 기반v0.3. 이전 조사브랜치 산출물에서 공개자료를 회수했습니다. 중단 직전의 수정 중 소스는 런타임에 없었으므로 실제 전달된 v0.3에서 다시 통합했습니다.

새 모듈: infrastructure, graphics, clean-model, solar, observations, operations, enhancements. 서버: server/city/infrastructure.js. 기존 server/city/providers.js와 city-config에 공개 API설정 플래그를 연결했습니다. 새로운 API함수 수를 늘리지 않고 기존 city-data 라우트에 연결했습니다.

상태경계: 사용자 가져오기는 브라우저메모리, 저장소 공개파일은 재배포로 공유, 동별자료/겹침은 source별 타입을 보존합니다. 공동DB·로그인·자동현장보고·전수검수는 미구현입니다.

보안: 키는환경변수, VWorldSDK키는브라우저노출필연/도메인제한, 원본사용자샘플키복사금지, 임의URLproxy금지, 낡은운영기록상태표시, 테스트fixture비공개빌드.

남은 출시검수: VWorld/밝은모형GPU, 고해상도성능, 실제기상/PM/쉼터키인증, 현행복지/영유아/한파좌표, 적사함/제설기록원문, 실제학교/센터기관단위연결, 경계공식검수, 부서별갱신책임.

## 이후 개발자가 우선할 일

‘자료가 적다’를 추정 데이터로 채우지 말고 담당부서 공개본/API를 연결합니다. 자동수집을 도입하면 출처별 실패·마지막정상본·갱신기간을 저장하는 서버영속계층부터 추가합니다. 그늘길 기능은 공개보행망/횡단보도/출입구/보도접근성을 확보하고 경로계산을 검증한 다음 개발합니다.
