## 자료와 기능의 구분

지역별 필터는 실제 Polygon/MultiPolygon을 사용합니다. 선/면은 선택 경계와 교차시켜 표시하며 구멍이 있는 면도 유지합니다. 동 선택 시 지도·목록·CSV의 범위가 일치합니다. **브이월드 원본 건물을 실제로 잘라 삭제하는 기능은 아닙니다.** 선택 밖 지면을 어둡게 하는 표시와 행정자료 절단을 구분하세요.

서버 어댑터: 무더위쉼터, 응급의료기관 기본정보, ITS 돌발·공개 교통 CCTV, TAAS 과거 사고다발구역, 에어코리아 실제 측정소·관측자료, KMA 실황·단기예보, 브이월드 주소·필지·토지·건물 속성. 네 종류 침수 WMS와 교통소통·연속지적도 WMS도 서버에서 제한된 주소만 요청합니다.

지형 검토: 7×7 지형 표본 경사 계산, 두 지점 종단면과 중점 횡단면. GLB는 브라우저 메모리 안에서 배치·회전·배율·높이 조절하며, 자신이 추가한 객체만 제거합니다. 개별 건물 숨김은 SDK가 공개 선택 기능을 제공하는 객체에 한합니다.

**화재예측, CFD 도시바람길, 정밀 침수예측, 법정 일조/입지 적합도 모델은 구현된 것이 아닙니다.** 외부 분석결과 GeoJSON을 출처·모형·시나리오·검증상태와 함께 불러올 수 있습니다.

## 실행

Node.js 22:
```bash
npm run check
npm test
npm run build
npm run dev
```
Vercel: Framework Other / Build `npm run build` / Output `dist` / Node 22.x. API 함수는 루트 `api/`에 남깁니다. `dist` 폴더만 올리면 서버 API가 빠집니다.

화면시험은 `pip install playwright` 후 `playwright install chromium`, `npm run test:city-ui`입니다. Linux Chromium이 설치된 경우 `CHROMIUM_PATH`로 지정할 수 있습니다.

## 검증의 한계

JavaScript·수학·API 실패처리·경계/목록 UI는 검사했습니다. 이 제작환경의 WebGL 초기화 실패로 **새 브이월드 3D GPU 렌더링, 사용자 키 인증, 라이브 API 수신, Vercel 새 배포**는 아직 검증하지 못했습니다. `docs/v03/LIVE_VALIDATION.md`에 배포 후 확인 순서를 제공합니다.

공개 인터넷용 기술 시제품입니다. 개인정보·취약가구 위치·비공개 CCTV·내부 민원 원문을 넣지 않습니다. 서버용 키는 Vercel 환경변수에 저장하세요. 지도 SDK용 키는 브라우저에 전달되는 구조이므로 제공기관 도메인 제한을 적용해야 합니다.
