# 4개 작업영역의 통합 검토 기록

이번 기록은 그래픽·자료·기후·통합의 네 역할로 나누어 수행한 코드 검토표입니다. 별도의 네 AI가 독립 실행·회의했다는 로그는 아닙니다.

| 작업영역 | 산출물 | 교차 검토에서 반영한 결정 |
|---|---|---|
| 그래픽·사용성 | graphics.js, clean-model.js, 품질 패널·인프라 카드·반응형 배치 | 원본 사진 해상도와 캔버스 해상도를 구분. 픽셀 예산을 둬 과도한 GPU 사용 제한. 우측 패널이 열리면 지도가 패널에 가려지지 않도록 폭 조정 |
| 공간자료·인프라 | infrastructure.js, 29개 자료층, 공공 학교와 OSM 도형, DATA_AUDIT | 점·면 합산 금지, 서구/동 절단, 전수 미확인·수집 실패 기록. 행정복지센터 18항목을 18개 동 센터 검수완료라고 부르지 않음 |
| 기후·운영정보 | solar.js, observations.js, operations.js | 높이 미상은 그늘 계산 제외. KST·야간·저고도·긴 그림자 제한. 관측·예보·그늘 시간 분리. 오래된 제설 완료를 현재 완료로 표시하지 않음 |
| 보안·통합검증 | 서버 공개 JSON 어댑터, 238단위시험, 59화면시험, 배포파일 점검 | 키는 환경변수, URL 호스트/리디렉션 제한, 데이터 무단 업로드 방지, 반환 순서/중복 격자 방어. 실GPU 미검증과 시험용 통신을 분리 |

## 최종 통합 결정

브이월드는 실제 지형 확인용으로 유지합니다. 밝은 모형은 별도 공개 도형으로 만들며 원본 브이월드 모형을 추출하지 않습니다. 인프라의 단독 선택을 기본으로 하고 여러 종류 겹치기는 사용자가 명시적으로 선택합니다. 자료가 없으면 위치·건물·현황을 가상으로 채우지 않습니다. 제설과 그늘은 ‘시각화/자료관리’와 ‘검증된 재난·열환경 예측’을 구분합니다.

## 수정한 통합 문제

카테고리 검색의 문구 결합으로 생기던 잘못된 검색 일치, 우측 패널이 지도를 가리는 문제, 그늘 계산의 높이 미상 처리, 제설 상태 만료, 조회 응답의 중복 격자, 도시모형에서 GLB 메뉴가 막히던 엔진 조건을 수정했습니다. 마지막 상태의 단위시험·UI시험을 다시 실행했습니다.
