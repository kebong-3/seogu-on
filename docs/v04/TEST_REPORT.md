## 검증하지 못한 것

이 제작환경에서 WebGL이 초기화되지 않았습니다. 실제 VWorld 3D 화질, 독립 밝은 도시모형의 GPU 렌더링, 브이월드 원본 그림자, 지형 표본 및 GLB 실제 렌더링·프레임률은 검증 완료가 아닙니다. SDK public 속성 검사와 단위시험은 실제 GPU화면 검증의 대체가 아닙니다.

사용자 API키를 통한 기상청·에어코리아·무더위쉼터·ITS 등 운영 인증, 신규 INFRA_SOURCES_JSON의 실제 제공기관 응답은 검증하지 않았습니다. 정규화 시험에는 명시적인 fixture를 넣었습니다. 이전 자료를 복구하는 과정의 `viewer-not-ready` 결과도 성공으로 바꾸지 않았습니다.

Vercel 최신 소스 배포와 함수 번들, 실제 운영 도메인 인증, 외부 서비스별 이용조건은 새 배포에서 확인해야 합니다. `scripts/verify-release.mjs`의 성공은 로컬 서버 결과이지 Vercel에 배포했다는 뜻이 아닙니다.

## 화면 증거

`docs/v04/ui-evidence/`의 PNG 파일명은 NOT-3D입니다. 지도 위 실제 행정경계와 자료 선택의 화면 동작을 보여주지만 브이월드 건물 렌더링이나 화질 개선 전후를 보여주지 않습니다. 기상·PM의 화면시험 값과 제설 시험구간은 시험용으로만 사용되며 public 기본데이터에 추가하지 않았습니다.

## 원자료와 표현 한계

학교 공식 위치52와 OSM학교 도형52는 서로 더해104개교로 계산하지 않습니다. 행정복지센터11위치/7면은18개 센터 전수확인이 아닙니다. OSM건물5,779개 중 기본 그늘 대상은 height태그52개뿐입니다. 층수추정2,217개는 opt-in, 높이미상3,510개는 그늘 제외입니다. 새로운 API가 연결되지 않은 자료는 미연결로 남겨두었습니다.

## 전달 상태

앱 전체 소스는 ZIP으로 전달합니다. 이 이어서 작업에서 앱 코드를 GitHub에 push/main 병합하거나 Vercel 배포/환경변수 변경을 하지 않았습니다. 기존 조사 브랜치는 앱 전체 버전의 대체물이 아닙니다.

배포 후에는 `tests/live-v04.py`를 WebGL 가능한 PC에서 선택적으로 실행하고 실제 화면을 사람이 확인하세요. 이 스크립트는 제작환경의 완료시험에 포함하지 않습니다.

## 배포물 검사

첨부 활용모델 HTML에서 추출한 인증키 형태의 실제 문자열 8개와 배포 소스/텍스트를 대조했습니다. 일치 파일은0개, 별도 글꼴 파일은0개입니다. 값 자체는 로그에 기록하지 않았습니다. 이는 자동 대조 검사이며 포괄적 보안인증을 의미하지 않습니다. `SECURITY_SCAN.json` 참조.
