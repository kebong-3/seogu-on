# 그래픽·그늘 구현과 해석 범위

## 화질 문제를 분리해서 보기

사용자 화면에서는 브이월드 건물과 항공사진이 실제로 표시됩니다. 화면 해상도, 축소/확대 단계의 세부모형, 원본 항공사진/텍스처 해상도, 장치 GPU, 경계/마스크 농도가 함께 영향을 줄 수 있습니다. 스크린샷만으로 원인을 하나로 확정하지 않았습니다.

Cesium 공식 Viewer 문서의 `resolutionScale`은 내부 렌더링 해상도를 바꾸며 1보다 높으면 더 많은 픽셀을 그린 뒤 축소합니다. GPU 비용이 증가할 수 있습니다. 원본 사진에 없는 세부 형상이나 글자를 만들어내는 기능은 아닙니다. `useBrowserRecommendedResolution`과 DPR을 함께 제어해야 지나치게 큰 버퍼를 방지할 수 있습니다.

공식: https://cesium.com/learn/cesiumjs/ref-doc/Viewer.html

## 브이월드 표시 품질

절약/균형/선명의 3개 프리셋, 픽셀 예산, FXAA, 지원되는 그림자맵 설정, 지구 표면 세부오차, 사용자 경계/마스크/동 라벨 농도를 제어합니다. SDK에서 실제로 존재하는 공개 속성에만 적용합니다. 내부 `_tileset`을 추측하여 원본 건물의 LOD를 강제로 바꾸거나 VWorld의 건물 원자료를 추출하지 않습니다.

현재 지원되지 않는 속성은 미지원으로 보고합니다. 캔버스 CSS크기·렌더 버퍼크기·적용값을 확인합니다. 객체 설정 성공이 실제 시각적 화질 개선 검증과 같은 것은 아닙니다.

## 밝은 도시모형 모드

독립 Cesium 1.121 + 공개 OSM 건물/도로/물 도형을 사용합니다. VWorld 사진을 재가공한 것이 아닙니다. 모형 5,779개 도형, 네트워크/수계 2,483개 도형이 포함되며 북부 일부 등 누락이 있습니다. 지면은 타원체 기준면이고 지형 높낮이가 없습니다.

원본 height 태그 52개는 해당 태그 높이, 원본 층수 2,217개는 층수×3m, 높이 없는 3,510개는 표시용 6m를 사용합니다. 실제 측량 높이라고 부르지 않습니다. 색상과 상세정보로 높이 근거를 구분합니다. 형상은 정밀 지붕/외벽 메쉬가 아니라 단순 수직 입체화입니다.

## 그늘 2개 경로

1. **시간별 그늘 근사 도형**: 소규모 태양방향 계산 → 높이/tan(태양고도) 이동량 → 수직 기둥 도형의 평면 투영 → 선택 행정구역과 절단. 원본 도형·계산결과를 사용하는 실제 계산 코드입니다. 그림으로 꾸며 놓은 그늘이 아닙니다.
2. **3D 태양 조명/렌더러 그림자**: 선택 한국시간을 Cesium 시계에 적용하여 렌더러의 조명/그림자 기능을 요청합니다. 브이월드 SDK의 지원 범위와 실제 건물의 shadow 설정에 영향을 받습니다. 실제 브이월드 건물 전체가 그림자를 드리우는지는 배포 후 확인해야 합니다.

두 경로는 같은 ‘정밀 그늘지도’가 아닙니다. 기본 근사 계산은 height 태그가 있는 52개 도형만 사용합니다. 층수×3m 추정은 명시적으로 체크했을 때만 사용하며 표시용 6m는 항상 제외합니다. 데이터 범위 밖의 건물 그림자, 미수록 수목·차양·지형·구름·반사광은 포함하지 않습니다. 동 밖의 확보 건물은 동 안으로 드리우는 그림자를 계산할 수 있도록 원본 전체를 검토한 후 절단합니다.

태양이 지평선 아래면 밤으로 표시합니다. 3도 이하의 낮은 태양은 긴 투영 오차 때문에 계산을 제한하며 길이를 1,500m로 제한합니다. 그림자 중첩을 단순 합산하여 구역 전체 그늘 면적/비율로 표시하지 않습니다.

날짜·시간은 +09:00 한국시간으로 파싱하며 잘못된 날짜는 거절합니다. 태양 위치는 저차 근사식으로 계산하며 공인 일조권·일사량·열쾌적성 평가로 사용하지 않습니다.

## 제설과 결빙의 차이

현재 구현한 제설지도는 출처·시각이 있는 작업기록을 표시하는 지도입니다. 현재 눈 깊이·노면 온도·결빙률을 측정하거나 예측하지 않습니다. 그늘과 낮은 기온을 겹쳐 보더라도 자동으로 위험구간을 단정하지 않습니다.

## 실렌더링 검증

이 제작환경은 WebGL 초기화가 되지 않았습니다. 새 도시모형의 실제 GPU 렌더링, VWorld 화질 변화, 시각적 그림자·GLB·프레임률은 사용자 PC에서 확인해야 합니다. UI시험 스크린샷은 BoundaryView이며 3D 그래픽 검증 증거가 아닙니다.
