## 아직 좌표/현황을 연결하지 않은 자료

현행 한파쉼터, 적사함·제설함 개별 좌표, 제설 작업구간/검토구간, 그늘막·그늘쉼터, 최신 어린이집·복지기관 공식 전수자료는 완비되지 않았습니다. 종류 선택·가져오기·추가 공개 API 어댑터는 있지만 가짜 점이나 현황을 넣지 않았습니다. 무더위쉼터·응급의료기관은 기존 서버 API를 통해 사용자 승인키로 조회합니다.

2019년 기준 어린이집 자료246행은 좌표도 없어 현행 어린이집 기본지도에 사용하지 않았습니다. 현재 OSM 어린이집 표시는 이 오래된 자료에서 좌표를 만들어낸 것이 아닙니다. 과거2019년 무더위쉼터 운영자료도 현재 운영목록으로 대체하지 않았습니다.

## 자료의 시간과 처리

학교 대표위치는 회수한 표준자료의 2026-03-20 기준값입니다. OSM은 2026-09-27에 회수한 자료를 사용했으나 원본 스냅샷 시각은 자료 조각마다 2026-05월, 7월, 9월 등 다릅니다. 회수 날짜를 일괄적으로 원자료 기준일로 바꾸지 않습니다. 시설의 현재 운영상태와 원본 수정시각은 다른 값입니다.

원본 OSM ID로 중복 제거, 명칭·같은 영역에 겹치는 점 일부 중복 제거, 서구 경계 절단, 타입/좌표 검증을 했습니다. 점과 면의 완전한 기관 단위 연결을 완료한 것은 아닙니다. 상세 원본해시·스냅샷·제외사유는 DATA_AUDIT.json, 화면용 범위표는 public/data/city/coverage.json에 있습니다.
