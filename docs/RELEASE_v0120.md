# 0.12.0 — 생활시설 조회에서 현장점검·보완안 비교까지

2026-10-24(한국시간). 공개자료 기반 행정 검토용 웹 시제품이다.

## 바뀐 이용 목적

공공공간 운영시간을 먼저 입력하는 도구에서, 실제 생활시설을 찾아 담당자가 다음 업무를 정할 수 있는 지도 중심 흐름으로 전환했다.

- 돌봄·육아: 동네·시설종류·시설명/주소로 실제 수록 어린이집을 찾는다. 공시 유형·운영상태·정원·현원·기관 연락처와 근거를 확인한다.
- 여성안심·생활안전: 공개 비상벨·보안등·경찰관서·목적이 표시된 CCTV를 함께 보고, 현장점검할 위치를 준비한다.
- 시설 카드의 ‘이 시설 주변 검토’는 실제 시설명·좌표를 후보 A로 전달한다. 후보 B는 지도에서 정한다.
- 어린이집 주변 활동공간 연계, 돌봄시설 주변 비상벨 점검, 야간 정류장 주변 보안등 점검을 같은 계산 구조로 실행한다.
- 시설 추가·중단·이동 가정의 전후 거리조건을 비교하고, AI 검토메모·출처·가정·미확인 사항을 HTML 검토서와 CSV로 내보낸다.
- 단순 시설조회 질문과 추가·점검·사업후보 질문을 구분한다. ‘어린이집 추가’를 ‘공공공간 추가’로 바꾸어 처리하지 않는다.
- 긴 설명은 접고 다음 행동을 먼저 제시한다. 시설수·거리만으로 안전·돌봄공급·입소 가능 여부를 결론내리지 않는다.

공개 어린이집 목록에서 공시 휴지와 경계 밖 좌표를 제외했다. 광주서구청어린이집 1건은 같은 주소의 별도 공식 공개위치와 2,472m 차이가 확인되어 원문 좌표 재확인 전 공간 수록·계산에서 추가 제외했다. 좌표를 임의 교정하지 않고 원문 값·근거를 수신기록에 보존했으며, 동일 시설 ID와 문제 좌표가 함께 일치할 때만 제외한다. 정원-현원은 현재 입소 가능한 자리가 아니다. 비공개 보호시설·아동 개인정보는 수록하지 않는다. OSM의 혼합도형 화장실 참고자료는 이번 검증된 생활지도 데이터팩에서 제외했다. 순천의 여성안전 자료는 미연결 상태이며 시설 0개로 표시하지 않는다.

직선 반경은 사용자가 정한 비교 가정이다. 실제 보행 경로, 현장 조도·범죄 위험, 법정 설치기준, 설치 가능한 토지, 실시간 시설 운영 및 주민 수요를 산정하지 않는다. 기존 실제지역 공간·학교·그늘막·보호구역 자료와 기존 운영시간 검토·저장 기록은 보존한다.

## AI와 데이터 검증

서버가 지역·출처·파일 해시와 계산값을 소유하고 AI는 허용된 지표와 후속업무만 설명한다. 자료가 없는 경우를 0개로 계산하지 않는다. 원문 행ID·자료해시와 정확한 집계는 유지하면서 대용량 보안등의 반복 원문 전송을 줄였다. 실제 야간점검 응답에는 4.2MB 미만 검사를 적용했다.

별도 API 키 없이 수록본 조회·비교를 사용할 수 있다. 상시갱신용 어린이집 API는 정보공개포털 별도 신청 대상이며, 공개 안심지킴이집 API는 공공데이터 키와 해당 서비스 활용승인이 필요하다. 비상벨·CCTV의 현재 공개 CSV와 과거 API 안내를 구분한다. 관련 안내는 화면의 ‘추가 연결할 생활정보 API 확인’에서 제공한다.

## 검증 범위

출처·지역·좌표·명시 상태·누락·허위 지표 방지 및 두 지역의 실제자료 재계산을 자동검증한다. 최종 실행기록은 이 변경에 대한 작업 보고와 CI에 남긴다. 실제 공무원의 시간절감·정확도 개선 실측이나 안전성 인증을 뜻하지 않는다.

로컬 브라우저 미리보기는 이번 실행환경의 포트 충돌로 사용하지 못했다. 배포 파일·HTTP·계산 검사와 별개로 배포된 화면에서 생활지도·시설 선택·후보 비교를 확인한다. 3D 외부지도 수신과 AI 제공기관 응답은 접속 환경·서비스 상태에 따른다.
