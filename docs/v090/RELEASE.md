## 구현

- 실제 공공공간 선택 → 확인일·근거가 있는 운영상태 기록 → 현재/최대 3개 변경안 비교 → 현장 변경 후 재계산.
- 공간별 안정적 원자료 ID, 확인기한·변경 이력, 미확인/미산정 유지, 같은 시간대 개방 조건 계산.
- 계산 당시 출처·상태·가정을 보존한 비교 스냅샷, 이전 결과 차이, HTML 보고서, JSON 보관·충돌 검사 후 합치기.
- 서버 원자료로 재계산한 수치에 근거한 AI 해석. 화면·서버 계산 불일치 시 설명 보류, AI 실패 시 명확히 표시한 계산 근거 요약.
- 지역 설정·행정경계·공공공간 자료 교체를 통한 공통 기능 이식. 서구 전용 기존 서비스는 새 지역에서 차단.
- 실제 담당자의 두 방식 수행시간·오류·출처누락을 짝지어 기록하는 업무효과 측정. 초기 성과값 없음, 수정·제외 이력 보존.

서구 실자료는 18개 행정동과 58개 공공공간이다. 타 지역 검증은 합성 2개 동·2개 공간 자료팩을 사용했다. 실제 두 번째 지자체의 적용 또는 담당자 실증 실적은 아니다. Google와 호환 모델의 통신 계약 시험은 모의 응답으로 실행했다.

### 확인 중 발견해 보완한 사항

- 같은 계산 결과를 보관할 때 이미 받은 AI 설명이 사라지던 문제를 수정했다. 사실·조건이 같은 재계산일 때만 현재 설명을 유지하며, 과거 스냅샷에는 계산 결과만 보관한다.
- AI에 ‘개방 조건 충족’을 ‘이용 가능’으로 단정하지 않도록 지침을 추가했다. 현재안의 추가비 0이 총운영비 0을 의미하지 않는다는 구분도 강화했다.
- 단일 대안 비교표는 패널 폭에 맞춰 제목·숫자를 함께 읽도록 보완했다. 여러 대안은 가로 스크롤을 유지한다.
- 제외한 측정이 있을 때의 빈 요약 문구와 패널 이동 시 남던 이전 설명 제목을 바로잡았다.
- 최초 기능 커밋의 GitHub 주 검사·시험·빌드 작업은 통과했다. 후속 검증에서 변경된 빈 요약 문구를 기대하던 시험 1개를 수정하고 최종 로컬 전체 검사를 다시 통과했다. 참고용 오프라인 UI 검사의 기존 메뉴 전제와 공통 모듈/지역 응답 fixture도 새 구조에 맞춰 보정했다. 실제 CI 결과와 로컬 검사 결과는 구분해 기록한다.
- “풍암동에서 주민 모임에 쓸 공공공간 자료와 확인할 점을 알려줘” 질문이 공원·교통만 조회하던 문제를 수정했다. 공공시설 개방정보를 우선하여 실제 회의실·동아리실 등 4개 수록 항목을 조회하고, 현재 이용 가능한 공간 수가 아니라는 안내를 유지한다. 관련 회귀시험 5개를 추가했으며 질문 결과에서 공공공간 운영안 비교로 이동할 수 있다.

### 후속 운영 검증

후속 배포 `CkkhyGv4xQQuoHwjW84CdPSp4D4E`(커밋 `ac914e89afd53d8d737741cd9cd3865842256656`)도 Ready 상태를 확인했다. 동일 시험 기록으로 현황과 대안 모두 조건 충족 1개·2시간일 때 AI가 증가 효과를 주장하지 않고, 현재안의 0은 추가분 비교 기준이며 대안의 120만원은 입력 가정이라고 설명했다. 결과 보관 뒤 AI 설명이 유지됐으며 HTML에 해당 설명·응답 모델·시험 근거가 포함됐다. 단일 대안 비교표가 패널 폭 안에 들어오는 것도 확인했다.

해당 커밋의 GitHub 오프라인 배치 검사는 155/155 항목을 통과했다. 기존 회귀 하네스의 다중 줄 import 미변환 문제는 로더에서 보완했다. 네 하네스 각각 51개 모듈·111개 연결을 정적 파싱하여 미해결 상대 경로 0개를 확인했으며, 후속 CI의 실제 화면 검사 통과 여부와 이 정적 검사는 구분한다.

최종 기능 배포 `2h7vDbMQXnCvv6Tn6whd5xo6iNze`(커밋 `147bd6a60ce419ed76d6f210110e2ce58d9c0bab`)가 Ready 상태로 운영 도메인에 연결됐다. 실제 질문 “풍암동에서 주민 모임에 쓸 공공공간 자료와 확인할 점을 알려줘”에 4개 실제 수록 공간의 이름·출처 2개·예약 및 사용 승인 미확인 안내를 포함한 `gemini-3.8-flash` 응답을 확인했다. 질문 결과의 “공공공간 운영안 비교”를 누르면 풍암동의 4개 공간 목록으로 이어진다. 업무효과 측정의 제외 기록 안내와 지역 구성 패널의 제목 초기화도 운영 화면에서 확인했다.

동일 커밋의 CI에서 주 검사·시험·빌드는 성공하고 화면 배치 155/155 항목은 다시 통과했다. 참고용 기존 회귀는 강화된 목록 안내에 맞지 않는 이전 단어 검사 한 곳에서 멈춰, 현재의 집계 단위·해석 한계를 함께 검증하도록 시험을 수정했다. 제품 기능을 시험에 맞춰 되돌리거나 행동 검증을 제거하지 않았다.

### 남은 확인 범위

이 검증 브라우저에서는 VWorld SDK 수신과 도시모형의 WebGL 초기화가 실패했다. 제공된 경계도로 전환해 업무 기능을 확인했으며 실제 3D 지형·건물·지도 핀 조작이 모두 검증됐다고 주장하지 않는다. GPU가 지원되는 실제 사용자 환경에서 별도 확인해야 한다. 실제 두 번째 지자체, 실제 모델 두 종류, 실제 담당자 업무효과는 이번 검증 범위 밖이다.
