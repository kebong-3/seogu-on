# 0.9.0 · 공공공간 행정 디지털트윈

2026-10-22 개선 기록.

## 구현

- 실제 공공공간 선택 → 확인일·근거가 있는 운영상태 기록 → 현재/최대 3개 변경안 비교 → 현장 변경 후 재계산.
- 공간별 안정적 원자료 ID, 확인기한·변경 이력, 미확인/미산정 유지, 같은 시간대 개방 조건 계산.
- 계산 당시 출처·상태·가정을 보존한 비교 스냅샷, 이전 결과 차이, HTML 보고서, JSON 보관·충돌 검사 후 합치기.
- 서버 원자료로 재계산한 수치에 근거한 AI 해석. 화면·서버 계산 불일치 시 설명 보류, AI 실패 시 명확히 표시한 계산 근거 요약.
- 지역 설정·행정경계·공공공간 자료 교체를 통한 공통 기능 이식. 서구 전용 기존 서비스는 새 지역에서 차단.
- 실제 담당자의 두 방식 수행시간·오류·출처누락을 짝지어 기록하는 업무효과 측정. 초기 성과값 없음, 수정·제외 이력 보존.

## 검증

전체 로컬 회귀시험 43개 파일의 686개 사례 통과. 빌드 파일 검사 19/19와 실제 로컬 HTTP 검사 56/56 통과. 최종 지역 코드체계와 지도 선택·초기 준비 가드 수정 뒤 해당 시험·문법 재검사를 수행했다. 상세 시험 목록은 [VALIDATION.json](VALIDATION.json).

서구 실자료는 18개 행정동과 58개 공공공간이다. 타 지역 검증은 합성 2개 동·2개 공간 자료팩을 사용했다. 실제 두 번째 지자체의 적용 또는 담당자 실증 실적은 아니다. Google와 호환 모델의 통신 계약 시험은 모의 응답으로 실행했다.

### 확인 중 발견해 보완한 사항

- 같은 계산 결과를 보관할 때 이미 받은 AI 설명이 사라지던 문제를 수정했다. 사실·조건이 같은 재계산일 때만 현재 설명을 유지하며, 과거 스냅샷에는 계산 결과만 보관한다.
- AI에 ‘개방 조건 충족’을 ‘이용 가능’으로 단정하지 않도록 지침을 추가했다. 현재안의 추가비 0이 총운영비 0을 의미하지 않는다는 구분도 강화했다.
- 단일 대안 비교표는 패널 폭에 맞춰 제목·숫자를 함께 읽도록 보완했다. 여러 대안은 가로 스크롤을 유지한다.
- 제외한 측정이 있을 때의 빈 요약 문구와 패널 이동 시 남던 이전 설명 제목을 바로잡았다.
- GitHub의 주 검사·시험·빌드 작업은 통과했다. 참고용 오프라인 UI 검사의 기존 메뉴 전제와 공통 모듈/지역 응답 fixture를 새 구조에 맞춰 보정했다. 해당 후속 커밋의 실제 CI 결과를 함께 확인한다.

### 남은 확인 범위

이 검증 브라우저에서는 VWorld SDK 수신과 도시모형의 WebGL 초기화가 실패했다. 제공된 경계도로 전환해 업무 기능을 확인했으며 실제 3D 지형·건물·지도 핀 조작이 모두 검증됐다고 주장하지 않는다. GPU가 지원되는 실제 사용자 환경에서 별도 확인해야 한다. 실제 두 번째 지자체, 실제 모델 두 종류, 실제 담당자 업무효과는 이번 검증 범위 밖이다.
