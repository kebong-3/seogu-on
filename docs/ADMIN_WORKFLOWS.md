# 지역 행정 검토 업무

홈의 ‘선택한 지역 살펴보기’에 폭염 계획 외에 한파 대응, 결빙 관리지점 점검, 침수 이력 현장점검, 통학환경 점검을 제공합니다. 이 메뉴들은 현재 확보한 공개자료로 대상 확인 → 담당부서·기한·현장 기록 → 검토보고서 저장까지 실행됩니다.

| 업무 | 사용하는 자료 | 산출물과 해석 |
|---|---|---|
| 한파 대응계획 | 정류장 433지점, 국민안전24 한파쉼터 256곳 공개본 | 기존 쉼터 연결안과 대기환경 보완안 비교. 비용은 견적 전 미산정. 실제 난방·개방·접근성은 현장 확인 |
| 결빙 관리지점 점검 | 결빙 관리 시작·종료점 23개 | 구간 원문의 식별자로 12묶음. 같은 관리번호가 있어도 서로 다른 원문을 합치지 않음. 현재 결빙·제설 완료 아님 |
| 침수 이력 현장점검 | 과거 침수 기록 468행 | 정확히 동일한 대표좌표만 묶고 원래 행 식별자와 발생연도를 보존. 동일 건물·피해 세대 수 또는 미래 침수 예측 아님 |
| 통학환경 현장점검 | 어린이보호구역 대상시설 대표위치 62개 | 실제 출입구·보도·횡단·표지·공개 안전시설 정보를 대조할 합동 점검표. 안전한 통학경로·법적 구역 경계 판정 아님 |

## 사용 순서

1. 업무를 열고 검토 구역을 선택합니다. 한파는 쉼터 연결 검토거리와 보완 후보 상한을 바꿀 수 있습니다. 이 거리는 사용자의 검토 가정이며 법정 기준이 아닙니다.
2. ‘검토대상 불러오기’를 누릅니다. 자료를 받지 못하면 실패 원인을 표시하고 이전 결과의 보고서 저장을 막습니다. 대상은 선택 구역 안이며, 한파의 인접 쉼터는 동 경계를 넘어 서구 공개본 전체에서 조회합니다.
3. 대상을 펼쳐 검토안, 확인 상태, 담당부서, 후속 확인기한, 현장 확인내용·보류 사유를 기록합니다. 확인내용이 있어야 확인 상태를 설정할 수 있습니다. 입력 상태는 현장 확인을 시스템이 검증했다는 뜻이 아닙니다.
4. 대상 지도를 확인하고 같은 업무 버튼으로 돌아올 수 있습니다. 목록은 30개씩 표시하지만 보고서는 선택 구역 전체 대상을 포함합니다.
5. 검토의견을 작성하고 미리보기, HTML 다운로드, 인쇄/PDF 저장 또는 JSON 기록 저장을 실행합니다.

기록은 현재 브라우저 localStorage에만 저장합니다. 원자료는 변경하지 않습니다. 데이터 해시가 바뀌면 과거 확인상태를 초기화합니다. 조건이 바뀌면 다시 불러오기 전까지 저장을 막습니다. 다른 기기에서의 JSON 복원·다중 사용자 공동 저장은 제공하지 않습니다.

## 모델 교체와 별도 검증

AI 기본 모델은 `gemma-4-26b-a4b-it`입니다. `AI_MODEL`로 명시적으로 바꿀 수 있으며, `AI_PROVIDER=openai-compatible`와 서버 전용 연결주소·키로 자체 모델 서버를 사용할 수 있습니다. 세부 설정은 [AI_PANEL.md](AI_PANEL.md)를 참고하세요.

공간 계산, 원자료 식별자, 검토 기록과 보고서 계산은 모델과 분리합니다. 모의 호환 서버 시험을 실제 정부 공통기반이나 서로 다른 실제 모델 두 종의 구동 실증으로 계산하지 않습니다.

상단에서는 미세먼지 표시와 자동 요청을 제거했습니다. 기온·1시간 강수·재난자료만 표시합니다. 기존 환경 분석 도구의 수동 대기질 조회 및 API 진단 코드는 유지합니다.
