# 다섯 검토 관점과 조정 결과

실제 별도 자율 에이전트 다섯 개가 병렬 실행됐다는 기록이 아니라, 본 작업에 적용한 다섯 검토 관점입니다.

| 검토 관점 | 쟁점 | 반영 결과 |
|---|---|---|
| 지도 경험·카메라 | 고정 높이는 동마다 너무 멀거나 가까움. 다음 클릭이 앞 비행과 충돌 | 도형 크기·화면비율 기반 프레이밍, 상승 경로, 최신 요청 우선, 수동 중단 |
| 공간자료 | 대표좌표를 넓혀 면을 만들면 공원 경계처럼 오인 | 별도로 수신한 OSM94도형, 점87목록과 구분, 구멍/교차 절단, 전수 주장 금지 |
| 행정·안전 해석 | 색상 픽셀과 자의적 점수를 실제 위험으로 오해 | 원본 위험지도와 조회상태, 과거사고 연도, 응급의료 기본정보 구분 |
| API·보안 | 샘플키/범용 프록시/개인CCTV/무한 호출 | 서버 환경변수, 고정서비스만 허용, public ITS영상1개, 응답크기·시간·페이지 제한 |
| 통합·검증 | 조작과 데이터가 다른 지역을 가리킴. 테스트모형을 실구동으로 오인 | 공통 scope, 목록CSV일치, UI46/단위190와 WebGL·인증 미검증을 분리 |

절충: 기반건물은 브이월드가 제공하는 원본 스타일을 유지합니다. 게임형 탐색을 더하되, 도시원본을 임의로 다시 만들거나 전부 정밀한 건물높이로 간주하지 않습니다. 화면이 그럴듯하다는 이유로 데이터 신뢰도나 분석 정확도가 올라간 것으로 설명하지 않습니다.
