## 실현 범위 밖이지만 숨기지 않은 항목

브이월드 원본 도시 전체를 자체 편집 가능한 게임 자산으로 다운로드하는 기능, 서구 모든 공식 공원의 지정 면 전수확보, 실시간 소방센서 연결, 풍환경 유체 해석, 실제 홍수 예측, 교통영향평가 모델, 법적 건축 적합성 판단은 포함되지 않습니다. 샘플 HTML을 합친 것만으로 이러한 검증 모델이 생기지 않습니다.

본 버전의 자료/화면/검토 기능은 이런 분석모형을 추후 연결할 기반입니다. 전문모형을 추가할 때는 경계조건·해상도·입력 기준일·검증/불확실성을 별도 관리해야 합니다.
