# 제공받은 활용모델 검토 기록

첨부 HTML의 UI뿐 아니라 API 주소, 좌표, 페이지 수집, 실제 계산식을 읽었습니다. 원본 HTML 자체는 공개 배포에 포함하지 않았습니다. 아래 줄 번호는 사용자 첨부 원본 기준입니다.

## 1. 침수·홍수 지점 위험도 분석기 / 붙여넣은 코드

두 파일은 같은 1321행 예제 계열입니다. 459–503행의 네 WMS와 지점 조회 흐름을 반영했습니다. 1169–1225행은 PNG 색/불투명도 픽셀을 검사하고, 1263–1302행은 정해진 가중치를 합쳐 등급을 만듭니다. 이는 검증된 홍수 확률 모형이라는 근거가 첨부에 없습니다.

따라서 새 앱은 원본 WMS 이미지와 조회/실패 상태를 보존하고, 픽셀색으로 ‘낮은 위험/안전’을 판정하지 않습니다. 좌표는 서구 선택 구역으로 제한하고, 서버가 키를 사용해 PNG만 수신합니다. 원문의 전국 rectangle은 사용하지 않습니다.

## 2. 전국 무더위쉼터 생활안전 지도

원본은 Leaflet2D(535–542,1032–1043행)입니다. 쉼터·응급의료·KMA 자료 연결과 3km 인접기관 기능을 하나의 VWorld 장면으로 옮겼습니다. 원본의 전국버튼·내위치 이동은 서구18동 탐색으로 대체했습니다. 위치 권한을 요청하지 않습니다.

LA/LO, RSTR_FCLTY_NO, 야간/주말 및 운영시간 필드를 유지했습니다. 응급의료 기본정보는 실제 빈 병상·현재 입실 가능 여부가 아닙니다. 전국 수집 후 구역 필터 방식의 호출량을 제한하고, 실패/부분수집을 보존합니다.

## 3. 실시간 교통정보·교통안전 지도

원문의 ITS WMS, eventInfo, TAAS frequentzoneLg 구조를 반영했습니다. 실시간 사건과 2024년 사고다발구역을 분리했습니다. 기준연도와 행정코드는 서버 설정으로 두며, 조회된 위치/도형은 실제 서구 경계와 교차시킵니다.

원문의 즉시 ws3d.viewer 참조, 여러 피킹 이벤트, HTML 직접 삽입을 대체했습니다. 초기화 대기·단일 클릭처리·HTML 이스케이프·MultiPolygon/내부구멍 처리를 적용했습니다. ITS WMS의 현재 서비스 제공/CRS 수신은 배포 검증 대상입니다.

## 4. 화면 내 CCTV 조회

첨부 143–144행에서 별도 상대경로 hls.js와 index.js를 요청하지만 해당 파일은 첨부되지 않았습니다. 따라서 첨부만으로 원래 CCTV 실행 로직 전체를 확인할 수 없습니다.

새 앱은 ITS 공개 CCTV 목록 어댑터와 별도 영상 재생기를 작성했습니다. hls.js1.6.13을 버전 고정해 포함하며, 영상은 사용자가 선택한 한 개만 재생하고 닫으면 해제합니다. 기관 내부/방범 CCTV나 비공개 스트림은 연결하지 않습니다.

## 5. 날씨 & 미세먼지 — 3D 통합

원본151–152행은 위도/경도를 정수화해 nx/ny로 사용하는데, KMA의 투영 격자 변환과 다릅니다. 242–257행은 시군구 이름으로 측정소명을 추정하고, 262–264행은 값이 없을 때도 ‘보통’ 아이콘을 선택합니다.

새 앱은 KMA5km Lambert 변환·KST 발표시간을 사용합니다. 실황과 예보를 구분하고, 예보값은 같은 발표/유효시각별로만 묶습니다. AirKorea 실제 측정소 좌표→관측자료 순서로 조회합니다. 결측은 0이나 보통으로 대체하지 않습니다.

## 6. 건축부지 입지분석 프로토타입

주소검색, 필지도형, getLandCharacteristics/getLandUseAttr/getBuildingUse 속성 연결, GLB 배치·편집·제거, 선택건물 숨김, 경사도·지형단면의 사용자 흐름을 참조했습니다.

새 경사 검토는 실제 지형표본7×7의 수치미분이고, 원본 외부 확장 스크립트가 생성하는 DOM을 읽어 결과를 추정하지 않습니다. 종단면과 중점 횡단면을 직접 계산하며 결측 구간을 연결하지 않습니다.

원본의 임의 점수/가중치·규제명 문자열 등급은 사용하지 않습니다. 토지·건물 속성은 참고조회일 뿐 법정 상한이나 건축 가능 판정이 아닙니다. 현재 코드의 토지특성은 현재연도 조회이며, 과거연도 자동 대체는 하지 않습니다. 누락은 제공범위/권한/연도 확인 필요로 남깁니다.

원본의 private _primitives/_tileset 배열, 추정 초기화 메서드 목록을 순회하는 방식, 전역 fetch/XMLHttpRequest/Image 수정은 사용하지 않습니다. GLB는 스스로 추가한 객체만 관리하고, public Cesium3DTileFeature가 제공되는 건물만 숨깁니다.
