## 검증하지 못한 것

이 제작환경에서 독립 Cesium1.121로 GPU 초기화를 시도했으나 `The browser supports WebGL, but initialization failed.` 오류가 발생했습니다. 새 VWorld SDK의 실GPU 렌더링·실제 건물제공·실DEM·GLB 실렌더링·사용자 키인증을 통과했다고 주장하지 않습니다.

제공기관의 실제 신규 API 응답/승인, ITS 영상/CORS/코덱, WMS 이미지제공 및 CRS, Vercel 서버함수 번들/새배포는 운영 도메인에서 검증해야 합니다. API 단위시험은 정상/실패 fixture를 넣어 작성한 코드를 시험한 것입니다.

## 실제 자료 수신 증거

GitHub Actions에서 공개 Overpass/정적 라이브러리를 수신했고, 반환된 OSM 요소773개 중 서구 경계에 걸치는 실제공원면94개를 추출했습니다. 원자료 timestamp는2026-09-26T23:56:06Z이며 공식공원 전수/지정경계가 아닙니다. 세부처리/PARK_GEOMETRY_AUDIT.json, 공개요청/PUBLIC_RETRIEVAL_MANIFEST.json.

조사 시점의 Production `/api/config`는 v0.1.0과 vworld3d/rest/publicData=false를 반환했습니다. 같은 작업에서 GitHub main의 package.json은0.2.0이었습니다. 이를 근거로 미배포/다른배포 가능성을 점검할 수 있으나, 계정 설정 원인을 확정한 것은 아닙니다. v0.3 운영주소는 이번 작업으로 변경하지 않았습니다.
