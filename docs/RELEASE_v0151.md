# 서구온 v0.15.1

2026-10-28 요청한 순서에 맞춰 서구 전체와 18개 행정동 선택을 왼쪽 메뉴 맨 위로 옮겼습니다. 그 아래에 돌봄·생활안전, 계절 안심 도보 내비게이션, 재난안전지도 순으로 서비스를 제공합니다.

도보경로는 밝은 하늘색, 선택한 경유길은 자홍색으로 표시합니다. 선택 경로의 본선은 화면 기준 10px, 흰 테두리는 양쪽 3px이며, 직접 경로를 비교용으로 남길 때는 본선을 6px로 줄입니다. 계절별 평가선은 4px로 그려 전체 길안내 선을 덮지 않게 했습니다. 브이월드 3D·도시모형, 경량 입체지도와 경계도에 같은 굵기 기준을 적용했습니다.

JavaScript 구문 검사, 도보·지도 관련 검사 30개, 로컬 전체 검사 884개와 빌드가 통과했습니다. Windows에서 symlink 권한이 필요한 검사는 제외했으며 Linux CI는 전체 검사를 실행합니다.
