# v0.2 구조

기존 vanilla JavaScript / Node22 / Vercel 구성을 유지합니다. React·Unity로 바꾼 프로젝트가 아닙니다.

## 브라우저

`app.js`가 공통 조회상태를 관리합니다. `admin.js`는 18개 행정동 도형·좌표 포함·공간 범위를 검사하고, `source-store.js`는 서로 독립된 자료층의 정상본·상태·갱신을 관리합니다. `geo.js`의 동일 필터 결과를 지도·표·내보내기에 전달합니다.

`map.js`는 MapLibre / VWorld iframe / 명시적 가상 시연을 분리합니다. `vworld-frame.js`는 같은 출처 메시지만 처리하고 준비 전 경계·카메라를 대기시킵니다. 지도는 분석값이나 실제 건물 높이를 창작하지 않습니다. `importers.js`는 공개 시설 CSV, 사업 도형 GeoJSON, 행정동별 통계를 검사합니다.

## 데이터

`public/data/admin-dongs.geojson`은 2026-07-01 SGIS 가공 경계 18개입니다. `source-catalog.json`과 `layers/*.geojson`은 출처·기준일·조회범위가 있는 325개 공개자료 항목입니다. `address-records.json`의 32개 공개 주소는 위치 검수 전 지도 건수에 포함하지 않습니다. 제공받은 파일은 브라우저 메모리에만 있고 새로고침 시 사라집니다.

## 서버

`api/config`는 비밀 없는 설정 bool만 반환합니다. `api/layers`는 `server/catalog.js`에 선언된 공개 API만 호출하고 다중 페이지를 검증합니다. `api/weather`는 승인된 기상청 초단기실황, `api/geocode`는 등록된 공개 주소 ID에 한해서 좌표 후보를 요청합니다. `api/vworld`는 검색과 선택적으로 설정된 시군구 경계를 제공하며 기본18동 경계의 공급원이 아닙니다.

서버는 키를 환경변수에서 읽습니다. 브라우저 SDK용 키는 서비스 특성상 브라우저에 공개됩니다. `server/`가 정적 dist에 복사되지 않도록 빌드합니다. Vercel은 루트 api 함수를 별도로 배포합니다.

## 범위

정기 자동수집·공동 데이터베이스·주민 내부자료·AI 자유문답·침수/일조/교통 예측은 포함하지 않습니다. 갱신 버튼과 실패 시 마지막 정상본 유지가 구현되어 있으나, 서버 인스턴스 캐시는 영구 저장소가 아닙니다. 실제 운영형은 인증·정책·보안·데이터 품질을 별도로 검토해야 합니다.
