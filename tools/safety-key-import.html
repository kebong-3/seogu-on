Vercel → seogu-on → Settings → Environment Variables
변수 이름: SAFETYDATA_KEYS_JSON
아래에서 만든 JSON 하나를 값에 붙여넣고 Production에 저장한 뒤 새로 배포합니다.

1. 발급 내역 붙여넣기

플랫폼에서 복사한 서비스 주소와 키가 들어 있는 내역을 붙여넣으세요. 항목별로 직접 입력해도 됩니다.

2. 9개 서비스키 확인·직접 입력

3. 통합값 복사

정리한 값은 비밀입니다. GitHub·공개 HTML·보고서·스크린샷에 올리지 마세요. 사용 후 입력값을 지우고 탭을 닫으세요. 공유 클립보드를 사용하는 PC에서는 복사값도 삭제하세요.

허용 IP 오류(32)가 반환되면 등록 IP와 Vercel 서버의 출발 IP 조건을 제공기관에 확인해야 합니다. JSON을 저장했다는 것만으로 인증 성공이 되지는 않습니다.
