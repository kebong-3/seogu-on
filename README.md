# SEO:ON · 서구온 0.4.1

**광주 서구 18개 행정동 · 인프라 단독 선택 · 브이월드/밝은 도시모형 · 기후·그늘 · 공개 제설기록**

v0.4를 다시 점검한 마감 수정본입니다. 기능을 더 나열하는 대신 지도 갱신, 초기화, 그늘 시각, 관측값 보존, 제설기록 작성·저장·복원, 업로드 누락 방지를 수정했습니다. 인터넷용 공개자료 시제품이며 기관의 공인 운영지도·시설 전수대장·정밀 재난 예측모형이 아닙니다.

## 처음 적용하기

[적용 순서](docs/v041/DEPLOY.md) · [API 설정](docs/v041/API_SETUP.md) · [수정·역할별 검토](docs/v041/FINAL_REVIEW.md) · [자료 범위](docs/v041/DATA_STATUS.md) · [실제 시험 결과](docs/v041/TEST_REPORT.md)

기존 `kebong-3/seogu-on`과 Vercel 프로젝트를 유지합니다. ZIP을 풀어 안의 파일과 폴더를 저장소 최상위에 반영합니다. 특히 **`vendor/` 폴더의 SDK 압축파일을 빼지 마세요.** 빌드가 SHA-256을 확인한 뒤 로컬 파일에서 SDK를 복원합니다. 빌드용 외부 패키지 다운로드는 필요하지 않습니다. 지도·API 이용에는 인터넷 및 별도 서비스 승인이 필요합니다.

```bash
npm run verify
npm run dev
```

Node.js 22 환경에서 실행합니다. Vercel 설정은 Framework **Other**, Build **npm run build**, Output **dist**입니다. 실제 인증키가 들어 있는 `.env.local`은 업로드하지 않습니다. `.env.example`은 빈 입력 양식입니다.

배포 후 `/api/city-config`와 `/data/release.json`의 버전이 **0.4.1**인지 확인합니다. 환경변수가 인식되어도 인증·3D 화면·실제 API 수신이 모두 성공한 것은 아닙니다. 화면의 ‘분석 도구 → 적용·자료 연결 점검’에서도 구분합니다.

## 이번 수정

- 바뀌지 않은 도형은 다시 만들지 않고 표시 상태만 동기화합니다. 지도 준비 중에는 마지막 선택과 필요한 명령을 보존합니다.
- ‘그래픽’에서 브이월드 상세/기본 모델 요청, 렌더링 품질, 실제 렌더 진단을 제공합니다. SDK가 상세 레이어를 지원하지 않으면 원래 건물을 유지합니다.
- 34개 인프라 분류와 18개 동의 단독/복수 선택, 점·선·면 구분, 상세 출처, 목록·CSV 연동을 유지합니다.
- 제설구간·검토구간·적사함·한파쉼터·그늘시설을 지도에 직접 작성하고 시각/상태를 검수한 뒤 반영할 수 있습니다.
- 공개 관리기록을 명시적으로 현재 브라우저에 저장·복원하거나 JSON/GeoJSON으로 내보냅니다. 공동 서버에 자동 게시하지 않습니다.
- 그늘 재생 시각과 계산 도형의 시각을 맞추고, 기상/PM 갱신 실패 시 원래 관측시각과 이전값을 보존합니다.
- 행정복지센터 점11·면7이 서로 다른 18개 동 명칭에 대응하는 대조표와 공개주소 검수 목록33건을 제공합니다. 현장·이전 여부 검수와는 별개입니다.

## 검증과 한계

**278개 단위시험, 59개 기존 화면 회귀시험, 22개 신규 화면시험, 12개 배포물 점검, 28개 로컬 HTTP 점검을 통과했습니다.** 서로 다른 시험 범위이므로 이 숫자를 실지도·실API 성공 수로 합산하지 마세요.

화면시험은 실제 앱/포함자료/2D BoundaryView를 사용하고 통신은 시험 응답으로 대체했습니다. 신규 저장 시험은 저장소도 명시적으로 대체했습니다. 이 환경의 Chromium에서 WebGL·WebGL2 컨텍스트가 생성되지 않아 실제 3D 화질·프레임률·브이월드 건물/지형·라이브 인증은 확인하지 못했습니다. 생성한 PNG는 3D 화질 비교 화면이 아닙니다.

브이월드와 별도의 밝은 도시모형은 OSM 부분자료이며 지형 높낮이가 없습니다. 5,779개 건물 중 높이미상 건물의 표시용6m는 그늘 계산에서 제외합니다. 그늘은 수직 건물과 평탄한 지면을 가정한 근사입니다. 최신 한파쉼터·제설 현황·적사함 좌표·그늘막 전수·영유아/복지 전수자료는 별도 연결이 필요합니다.

`/classic.html`에 이전 업무 화면을 보존했습니다. `docs/v03`, `docs/v04`는 과거 기록이고 이번 마감 검증은 `docs/v041`을 기준으로 읽습니다. 앱 코드와 외부 지도·데이터·SDK의 이용조건은 서로 다릅니다. [외부 고지](THIRD_PARTY_NOTICES.md)와 [보안 안내](SECURITY.md)를 확인하세요.
