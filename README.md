# 서구:온 · v0.6.1

**서구의 오늘을 한눈에 · AI 행정 디지털트윈**

기존 v0.6.0의 지도·공공자료·API·5분 그림자 제어를 유지하고 한글 브랜드와 화면을 다듬은 UI 수정본입니다. 새 AI 분석모형이나 새 재난 예측모형을 추가한 버전은 아닙니다.

## 이번 화면 변경

한글 ‘서구:온’ 워드마크와 자체 도시 심벌을 사용합니다. 파랑·청록 계열, 옅은 푸른 패널, 하이라이트와 그림자로 깊이감을 더했습니다. 정당 로고나 정부 공인 서비스 마크를 만들거나 사용한 것이 아닙니다.

큰 지역 설명창은 동 이름과 공식 BI만 보이는 작은 카드로 바꿨습니다. ‘DISTRICT VIEW’, ‘가까이’, 위치·면·선 건수와 탐색 상태는 해당 카드에서 제거했습니다. 건수·상태는 내부 진단과 실제 자료 목록에서 필요한 곳에만 유지합니다.

지도 위의 긴 출처 띠는 제거했습니다. 전체 출처는 하단 ‘지도 출처’에서 확인하며 작은 © OpenStreetMap 링크와 지도 SDK 자체의 크레디트는 유지합니다. 출처·이용조건을 없앤 버전은 아닙니다.

‘화면 설정’에서 시그니처 블루 / 스카이 블루 / 야간 네이비와 입체형 / 담백한 평면형, 영상 밝기와 동 BI 표시를 선택합니다. v0.6의 저장된 설정을 이어서 사용합니다.

## 적용과 실행

기존 v0.6.0에는 업데이트 ZIP을 같은 경로에 추가·교체합니다. 폴더를 삭제하지 마세요. `vendor/`와 공개자료, 기존 환경변수는 보존합니다. 빈 저장소에는 전체 프로젝트가 필요합니다.

Node.js 22에서 `npm run dev`, 빌드는 `npm run build`, 검사는 `npm run verify`입니다. Vercel 설정은 기존대로 Root 최상위 / Other / Build `npm run build` / Output `dist`입니다.
