# SEO:ON · 서구온 v0.6.0

밝은 파란색 화면, 공식 18개 동 BI, 서구 공개자료, 재난안전 9종 API와 5분 시각 재생을 연결한 공간행정 웹 구현본입니다. 기존 v0.5.0에서 이어서 수정했습니다.

## 이번 변경

밝은 블루 / 스카이 블루 / 야간 네이비와 지도 영상 밝기를 선택합니다. 왼쪽 메뉴는 ‘18개 동 / 표시 정보’와 독립 스크롤로 재구성했습니다. 자료 목록·분석 도구·검토 기록 기능은 유지합니다.

18개 동 BI 원본, 사용자 서구 CI 2개를 표시합니다. 실제 그늘막 199행, 쿨링포그 7행, 과거 침수피해 468행을 추가했습니다. 새 674행은 시설 674개나 독립 사건 674건이 아닙니다.

재난안전데이터공유플랫폼 9종 어댑터는 서버에서 `SAFETYDATA_KEYS_JSON` 하나를 읽습니다. 키 없는 로컬 정리 도우미는 `tools/safety-key-import.html`입니다. 5분 단위 시뮬레이션은 렌더 프레임 응답을 기다리며 재생 자체로 외부 API를 호출하지 않습니다.

## 실행

Node.js 22에서 `npm run dev`, 정적 빌드는 `npm run build`, 문법·단위·배포물 검사는 `npm run verify`입니다. `vendor/`의 해시 고정 SDK 압축파일을 보존하세요. Vercel은 루트의 `api/*.js`를 별도 서버 함수로 처리합니다. `.env.local` 같은 비밀값 파일은 저장소에 넣지 않습니다.

## 전달과 실제 운영은 다릅니다

앱 코드는 이번 전달 ZIP 안에 있습니다. GitHub 조사 브랜치에는 공개자료 회수 워크플로만 있으며, main 앱 소스 반영이나 Vercel 키 저장·배포는 이번 작업에서 하지 않았습니다. 새 SafetyData 9종 실데이터 수신, 실제 브이월드 영상 밝기·3D 그림자, 허용 IP와 기관 위치 연결은 운영 환경에서 확인해야 합니다. 로고는 공식 미표출 옵션을 사용하며 별도 지도 출처 텍스트를 유지합니다.
