- **행정자료 입력**: 시설 CSV/GeoJSON, 동별 통계 CSV, 사업 Point/LineString/Polygon/MultiPolygon. 시간축·반경·검토표에 연결합니다. 없는 인구·예산·월별 실적을 생성하지 않습니다.
- **오류 시 보존**: 자료층별 마지막 정상본을 유지하고 갱신 실패·부분수집·0건 급변을 표시합니다. 공개본과 사용자 임시 자료를 구분합니다.

## ‘3D’의 의미

기본 OSM 지도는 건물 도형을 공급 타일의 높이값으로 입체화합니다. 측량 모델이 아니며 누락·추정 높이가 있습니다. 브이월드는 원본 지형·건물 SDK 경로이지만 **환경변수 존재 → SDK 준비 → 실제 타일·건물 수신**은 서로 다른 확인 단계입니다. 통계기둥은 별도의 행정값 표현이므로 기본 OFF입니다.

`/?preview=1`만 합성 디자인 시연으로 시작합니다. 지도 연결 실패 시 합성 화면으로 자동 바꾸지 않습니다. `docs/screenshots`의 기존 v0.1 화면은 합성 디자인 참고이며 실제 현황으로 사용하면 안 됩니다.

## 공개자료의 한계

시설자료 수는 출처에 공개된 항목을 정리한 수치입니다. 전수 현황·현재 운영·현장 정확성을 보증하지 않습니다. 공공시설은 회의실 등 공간별 항목이므로 같은 건물에 여러 건이 있습니다. 지진대피 학교 30개는 **학교명과 도로명주소가 모두 일치한 학교의 대표좌표**입니다. 실제 운동장 범위나 출입구 좌표가 아닙니다. 지정 기준일은 미제공이며 학교 위치자료 기준일(2026-03-20)을 대신 넣지 않았습니다.

무더위쉼터는 수신한 252행이 2019년 운영자료여서 현재 지도에서 제외했습니다. 최신자료를 확보하기 전 ‘현재 이용 가능’으로 표시하지 않습니다. `docs/DATA_QUALITY_REPORT.json`에 중복·좌표 누락·경계 밖 제외 내역을 남겼습니다.

사용자 입력자료는 이 브라우저 메모리 전용입니다. API 캐시는 이 브라우저의 localStorage와 서버 인스턴스 메모리이며 공동 데이터베이스·영구 저장·전 사용자 실시간 동기화가 아닙니다. 검수한 공통자료는 저장소 공개 파일에 반영·재배포해야 합니다.
