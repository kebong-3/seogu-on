# 서구:온 · v0.7.0

**서구의 오늘을 한눈에 · AI 행정 디지털트윈**

광주 서구 18개 행정동의 공개 공간자료, 생활시설, 재난 관련 지도층과 시간별 3D 그림자를 한 화면에서 검토합니다.

## 이번 변경

- 18개 동 카드에 동 이름과 공식 마을 BI를 크게 표시하고, 카드의 글자 대비와 스크롤을 개선했습니다. 선택 동의 지도 위 BI도 키웠습니다.
- 상단에 기상청 격자의 기온·1시간 강수, 서구 안에서 조회된 가까운 에어코리아 측정소의 PM10, 재난 관련 지도층의 수신 종류 수를 표시합니다. 관측시각과 갱신 실패를 구분하며 값이 없으면 ‘미수신/미관측’으로 표시합니다.
- 18개 동 자동 둘러보기를 추가했습니다. 동을 직접 선택하거나 Esc를 누르면 중지합니다.
- 기존의 계절·시간별 3D 그림자 5분 단위 재생과 재난 상황판, 66종 공식 주제도 후보, 자료 기록 기능을 유지합니다.

## 실행·배포

Node.js 22에서 `npm run check`, `npm test`, `npm run build`로 검사합니다. 기존 Vercel 프로젝트의 Root 최상위 / Framework Other / Build `npm run build` / Output `dist`를 사용합니다. 기존 브이월드·기상청·에어코리아 환경변수를 유지합니다.

관측값은 외부 API가 실제 정상 응답할 때만 표시합니다. 서구 전체는 대표위치 기상 격자와 실제 측정소 하나의 값으로, 동 전체의 실측을 뜻하지 않습니다. 지도층 수신 종류 수는 위험도나 실시간 재난경보가 아닙니다. OSM 도로망은 보행 가능성과 그늘이 검증된 경로가 아니므로 자동 폭염 회피 경로로 안내하지 않습니다.
